## 痛点引入
***
你复习“算法”时，是不是经常看到这种话：  
“算法是解决特定问题的一组指令”“数据结构是组织和存储数据的方式”。  
每个字都认识，但合在一起就有点懵：**这俩到底干嘛的？为什么总被放一起？为什么又简称“算法”？**

先别急着背定义。  
咱们从一个特别小的问题开始：**给你一堆学生成绩，怎么找最高分？**

你可能会说：一个个看，看到更高的就记下来。  
恭喜，你刚刚已经描述了一个算法。  
而且你会发现，很多算法并不涉及复杂数学，更多依赖基本逻辑。

<br><br>

## 知识点 1：算法是什么？
***
### 问题
<br>
你手里有一堆成绩：`{78, 92, 85, 99, 67}`。  
你要让计算机告诉你最高分是多少。  
计算机不会“一眼看出来”，它需要你给它一套明确步骤。  
这套步骤，就是算法要解决的问题。

### 方案
<br>
算法不是玄学，它得满足几个硬条件：

- **问题明确**：输入是什么、输出是什么，要说清楚。
- **有穷性**：在有限时间内能结束，不能无限跑下去。
- **可行性**：每一步都能实际执行，并且在有限步骤、空间和时间下能完成。
- **确定性**：每个步骤含义确定，不能有歧义。

所以，算法可以理解成：  
**在有限时间内解决特定问题的一组明确指令。**

### 最小示例
<br>
```cpp
#include <iostream>
#include <vector>
using namespace std;

int findMax(const vector<int>& scores) {
    if (scores.empty()) {
        return -1; // 约定 -1 表示没有成绩
    }

    int maxScore = scores[0];
    for (int s : scores) {
        if (s > maxScore) {
            maxScore = s;
        }
    }
    return maxScore;
}

int main() {
    vector<int> scores = {78, 92, 85, 99, 67};
    int result = findMax(scores);
    cout << "最高分： " << result << endl;
    return 0;
}
```

### 输出
<br>
```text
最高分： 99
```

### 易错点
<br>
这里有个坑：**“有限时间”不是“很快”，而是保证有限步之后一定结束。**  
如果你写了一个死循环，那它就不是算法，至少不是一个合格算法。  
另外，算法不是代码本身。代码是算法的一种实现方式，同一个算法可以用不同语言写。  
在 C++ 里还要特别注意：`vector` 为空时不能直接 `scores[0]`，否则就是越界访问，程序可能直接崩掉。

### 一句话总结
<br>
**算法就是把输入变成输出的有限、明确、可执行的步骤。**

### 自测
<br>
你能用大白话描述“从 10 个数里找最小值”的算法步骤吗？  
要求：说清楚输入、输出、每一步做什么。

## 知识点 2：数据结构是什么？
***
### 问题
<br>
刚才找最高分，数据是放在一个 `vector` 里的：`{78, 92, 85, 99, 67}`。  
但如果我想按姓名查成绩呢？  
比如“小红考了多少分？”  
你再用一个纯 `vector` 就不太方便了，因为 `vector` 主要表达“顺序”，不直接表达“姓名 → 成绩”的对应关系。

这时候问题就变成了：**数据该怎么组织，才能让后面的操作更方便？**

### 方案
<br>
数据结构就是来解决这个问题的。  
它是**组织和存储数据的方式**，而且不只是存数据本身，还包括：

- 数据内容：比如成绩、姓名。
- 数据之间的关系：比如谁排在谁前面，或者姓名和成绩怎么对应。
- 数据操作方法：比如插入、删除、查找、遍历。

所以，数据结构不是“把数据随便塞进某个容器”，而是要考虑：  
**数据怎么放，关系怎么表达，操作怎么方便。**

### 最小示例
<br>
```cpp
#include <iostream>
#include <vector>
#include <map>
#include <string>
using namespace std;

int main() {
    // vector：按顺序存成绩
    vector<int> scoresList = {78, 92, 85, 99, 67};

    // map：按姓名存成绩，表达“姓名 -> 成绩”的关系
    map<string, int> scoresDict = {
        {"小明", 78},
        {"小红", 92},
        {"小刚", 85}
    };

    // 操作：按姓名查成绩
    string name = "小红";
    cout << "小红的成绩： " << scoresDict[name] << endl;

    return 0;
}
```

### 输出
<br>
```text
小红的成绩： 92
```

### 易错点
<br>
常见误解：**“数据结构就是存数据的东西。”**  
不对。`vector`、`list`、`stack`、`queue`、`map`、`set`，它们不只是存储方式不同，更重要的是它们支持的操作和效率不同。  
比如 `vector` 适合按位置访问，`map` 适合按键快速查找。  
另外，C++ 的 `map` 用 `operator[]` 查询时，如果键不存在，它会自动插入一个默认值 0。  
所以查字典更安全的写法是用 `find` 或 `at`。

### 一句话总结
<br>
**数据结构就是数据的组织方式，它决定了数据之间有什么关系、能做什么操作。**

<br>

## 知识点 3：数据结构和算法到底是什么关系？
***
### 问题
<br>
现在你知道了：算法是步骤，数据结构是组织方式。  
那为什么它们总被放在一起？  
更具体一点：**同一个问题，换了数据结构，算法会不会变？**

会。  
比如“找最高分”和“按姓名查成绩”，一个更适合遍历 `vector`，一个更适合查 `map`。  
数据结构不同，算法操作方式就不同。

### 方案
<br>
它们的关系可以这样理解：

- **数据结构为算法提供结构化存储的数据，以及操作数据的方法。**
- **数据结构本身只存信息，结合算法才能解决特定问题。**
- 算法要操作数据，而数据怎么组织，会决定算法怎么设计。

原文里有一个很形象的积木类比：

| 积木类比 | 对应概念 | 说明 |
|---|---|---|
| 未拼装的积木 | 输入数据 | 原始材料 |
| 积木组织形式，包括形状、大小、连接方式等 | 数据结构 | 决定积木怎么摆、怎么连 |
| 把积木拼成目标形态的一系列操作步骤 | 算法 | 决定怎么一步步拼出结果 |
| 积木模型 | 输出数据 | 最终结果 |

### 最小示例
<br>
```cpp
#include <iostream>
#include <vector>
#include <map>
#include <string>
using namespace std;

int main() {
    vector<int> scores = {78, 92, 85, 99, 67};

    // 用 vector：找最高分，需要遍历
    int maxScore = scores[0];
    for (int s : scores) {
        if (s > maxScore) {
            maxScore = s;
        }
    }
    cout << "vector 找最高分： " << maxScore << endl;

    // 用 map：想按姓名查分，直接查键
    map<string, int> scoresDict = {
        {"小明", 78},
        {"小红", 92},
        {"小刚", 85}
    };
    cout << "map 按姓名查分： " << scoresDict["小红"] << endl;

    return 0;
}
```

### 输出
<br>
```text
vector 找最高分： 99
map 按姓名查分： 92
```

### 易错点
<br>
别把“数据结构”和“算法”当成一回事。  
数据结构更像“怎么放”，算法更像“怎么算”。  
另外，约定俗成地，我们常把“数据结构与算法”简称为“算法”。但正式场合要注意：**狭义算法只指解题步骤，广义“算法”可能指整个数据结构与算法课程。** 考试和面试里，最好根据语境区分。

### 一句话总结
<br>
**数据结构负责把数据组织好，算法负责把问题解决掉，两者配合才能干活。**

### 自测
<br>
为什么“按姓名查成绩”用 `map` 通常比用 `vector` 更方便？  
从数据关系和操作方式两个角度说说。

## 完整可运行示例
***
下面把前面的知识点串起来：  
用 `vector` 找最高分，用 `map` 按姓名查成绩，并且处理“查无此人”的边界情况。

```cpp
#include <iostream>
#include <vector>
#include <map>
#include <string>
using namespace std;

int findMaxScore(const vector<int>& scores) {
    if (scores.empty()) {
        return -1; // 约定 -1 表示没有成绩
    }

    int maxScore = scores[0];
    for (int s : scores) {
        if (s > maxScore) {
            maxScore = s;
        }
    }
    return maxScore;
}

string getScoreByName(const map<string, int>& scoresDict, const string& name) {
    auto it = scoresDict.find(name);
    if (it == scoresDict.end()) {
        return "查无此人";
    }
    return to_string(it->second);
}

int main() {
    vector<int> scoresList = {78, 92, 85, 99, 67};
    map<string, int> scoresDict = {
        {"小明", 78},
        {"小红", 92},
        {"小刚", 85}
    };

    cout << "全班最高分： " << findMaxScore(scoresList) << endl;
    cout << "小红的成绩： " << getScoreByName(scoresDict, "小红") << endl;
    cout << "小强的成绩： " << getScoreByName(scoresDict, "小强") << endl;

    return 0;
}
```

### 输出/现象/结论
<br>
```text
全班最高分： 99
小红的成绩： 92
小强的成绩： 查无此人
```

这个例子里：

- `scoresList` 是 `vector` 结构，适合按顺序遍历找最大值。
- `scoresDict` 是 `map` 结构，适合按姓名快速查成绩。
- `findMaxScore` 和 `getScoreByName` 是算法步骤。
- `scoresDict.find(name)` 是处理边界情况，避免查不到时自动插入默认值。
