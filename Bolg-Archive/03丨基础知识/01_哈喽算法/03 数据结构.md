## 痛点引入
***
你写 C++ 时肯定用过 `int`、`double`、`char`，也用过 `数组`、`vector`、`链表`。  
但有没有想过：

- 为什么数组按下标访问很快，但中间插入很慢？
- 为什么链表插入很快，但按下标访问很慢？
- `int` 和 `float` 在内存里到底长什么样？
- `char` 为什么既能存字母，又能当小整数用？

这些问题背后，其实都指向同一件事：**数据在逻辑上怎么组织，在物理上怎么存放。**  
这篇文章就带你从“数据结构分类”和“基本数据类型”出发，把这些问题一个个拆开。

<br><br>

## 知识点 1：逻辑结构——线性与非线性
***
### 问题
<br>
你面前有两个容器：

- 一个数组 `[10, 20, 30, 40]`
- 一棵树，根节点下面挂两个子节点

它们都能存数据，但操作方式完全不同。  
数组可以按位置一个个数过去，树却要按层级往下找。  
为什么会有这种差别？

### 方案
<br>
因为它们的**逻辑结构**不同。  
逻辑结构描述的是数据元素之间的逻辑关系，和内存怎么存没关系。

常见分类：

- **线性结构**：数据在逻辑上排成一条线，元素之间是一对一关系。  
  比如数组、链表、栈、队列。
- **非线性结构**：数据不是简单一条线。  
  其中又分：
  - **树形结构**：一对多，比如树、堆。
  - **网状结构**：多对多，比如图。

注意：哈希表在有些教材里归为非线性，因为它通过哈希函数把键映射到位置，逻辑上不是简单的一对一线性关系。  
原笔记里同时把哈希表放进线性和非线性，这里存在矛盾。**更准确的说法是：哈希表属于散列结构，通常不按线性/非线性简单归类，或者归入非线性。**

### 最小示例
<br>
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    // 线性结构：数组，元素一个接一个
    vector<int> arr = {10, 20, 30, 40};
    cout << "数组元素：";
    for (int x : arr) cout << x << " ";
    cout << endl;

    // 非线性结构：简单二叉树
    struct TreeNode {
        int val;
        TreeNode* left;
        TreeNode* right;
        TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
    };

    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);

    cout << "树根：" << root->val
         << "，左子：" << root->left->val
         << "，右子：" << root->right->val << endl;

    delete root->left;
    delete root->right;
    delete root;
    return 0;
}
```

### 输出
<br>
```text
数组元素：10 20 30 40 
树根：1，左子：2，右子：3
```

### 易错点
<br>
别把逻辑结构和物理结构搞混。  
数组逻辑上是线性的，但它在内存里是连续存放的；链表逻辑上也是线性的，但内存里是分散的。  
**逻辑结构看“关系”，物理结构看“存放”。**

### 一句话总结
<br>
**逻辑结构就是数据之间的逻辑关系，线性是一对一，树是一对多，图是多对多。**

## 知识点 2：物理结构——连续与分散
***
### 问题
<br>
你写了一个数组 `int arr[5]`，又写了一个链表。  
数组可以 `arr[2]` 直接跳到第三个元素，链表却要从头节点一个个 `next` 过去。  
为什么数组访问这么快，链表却这么慢？

### 方案
<br>
因为它们在内存里的**物理结构**不同。

计算机内存可以想象成一个巨大的表格，每个格子有唯一地址。  
程序通过内存地址访问数据。

物理结构一般分两种：

- **连续空间存储**：数据放在一块连续内存里，比如数组。  
  优点：按下标访问快，因为地址可以直接算出来。  
  缺点：中间插入/删除要挪动后面所有元素。
- **分散空间存储**：数据分散在内存各处，通过指针连起来，比如链表。  
  优点：插入/删除只需要改指针。  
  缺点：按下标访问慢，必须从头遍历。

**所有数据结构，本质上都是基于数组、链表或两者组合实现的。**

- 基于数组可实现：栈、队列、哈希表、树、堆、图、矩阵等。
- 基于链表可实现：栈、队列、哈希表、树、堆、图等。

### 最小示例
<br>
```cpp
#include <iostream>
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int v) : val(v), next(nullptr) {}
};

int main() {
    // 连续存储：数组
    vector<int> arr = {10, 20, 30, 40};
    cout << "数组 arr[2] = " << arr[2] << endl; // 直接算地址

    // 分散存储：链表
    ListNode* head = new ListNode(10);
    head->next = new ListNode(20);
    head->next->next = new ListNode(30);

    // 访问第 3 个元素，必须从头走
    ListNode* cur = head;
    for (int i = 0; i < 2; i++) {
        cur = cur->next;
    }
    cout << "链表第 3 个元素 = " << cur->val << endl;

    // 释放链表
    while (head) {
        ListNode* tmp = head;
        head = head->next;
        delete tmp;
    }
    return 0;
}
```

### 输出
<br>
```text
数组 arr[2] = 30
链表第 3 个元素 = 30
```

### 易错点
<br>
数组越界不会自动报错，可能读到垃圾数据或直接崩溃。  
链表操作要小心指针丢失，比如 `head = head->next` 之前要先保存原节点，否则内存泄漏。  
另外，链表访问第 k 个元素的时间复杂度是 O(k)，不是 O(1)。

### 一句话总结
<br>
**物理结构决定数据在内存里是连续还是分散，连续适合随机访问，分散适合频繁插入删除。**

## 知识点 3：基本数据类型——CPU 能直接运算的类型
***
### 问题
<br>
你写 `int a = 10;`，又写 `float b = 3.14;`。  
它们都存进内存了，但 CPU 处理它们的方式一样吗？  
为什么 `int` 和 `float` 不能随便混用？

### 方案
<br>
因为它们是不同的**基本数据类型**。  
基本数据类型是 CPU 可以直接进行运算的类型，C++ 里主要有：

- 整数类型：`short`、`int`、`long`、`long long`（还有无符号版本）
- 浮点类型：`float`、`double`
- 字符类型：`char`
- 布尔类型：`bool`

它们都以二进制形式存储在计算机中。  
一个二进制位是 1 比特（bit），大多数系统里 1 字节（byte）= 8 比特。

**基本数据类型提供数据的“内容类型”，数据结构提供数据的“组织方式”。**

### 最小示例
<br>
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    float b = 3.14f;
    double c = 2.71828;
    char d = 'A';
    bool e = true;

    cout << "int 大小：" << sizeof(a) << " 字节" << endl;
    cout << "float 大小：" << sizeof(b) << " 字节" << endl;
    cout << "double 大小：" << sizeof(c) << " 字节" << endl;
    cout << "char 大小：" << sizeof(d) << " 字节" << endl;
    cout << "bool 大小：" << sizeof(e) << " 字节" << endl;

    cout << "char 'A' 的 ASCII 码：" << (int)d << endl;
    return 0;
}
```

### 输出
<br>
```text
int 大小：4 字节
float 大小：4 字节
double 大小：8 字节
char 大小：1 字节
bool 大小：1 字节
char 'A' 的 ASCII 码：65
```

### 易错点
<br>
`float` 精度有限，不要用来存精确金额。  
`char` 是有符号还是无符号，取决于编译器，可能影响比较结果。  
`bool` 大小通常是 1 字节，不是 1 比特。  
整数溢出是常见 bug，比如 `int` 存不下超大数时会回绕。

### 一句话总结
<br>
**基本数据类型是 CPU 直接运算的原子类型，决定了数据的内容和基本操作。**

## 知识点 4：数字编码与字符编码——二进制怎么表示世界
***
### 问题
<br>
计算机只认识 0 和 1。  
那 `10`、`-3.14`、`'A'`、`"你好"` 这些是怎么变成二进制的？  
为什么 `char c = 'A';` 输出成整数是 65？

### 方案
<br>
这就涉及**数字编码**和**字符编码**。

- **整数编码**：常用补码表示，正数就是普通二进制，负数用补码。  
  比如 `int` 通常 4 字节，能表示约 -21 亿到 +21 亿。
- **浮点数编码**：遵循 IEEE 754 标准，把符号、指数、尾数分开存。  
  所以 `float` 和 `int` 虽然都是 4 字节，但能表示的范围完全不同。
- **字符编码**：`char` 本质上存的是整数，通过编码表对应到字符。  
  最早是 ASCII，比如 `'A'` 是 65，`'a'` 是 97。  
  后来为了支持各国文字，有了 Unicode、UTF-8 等。

原笔记里“数字编码”和“字符编码”只写了“提高”和“跳过”，但作为 C++ 程序员，至少要知道：  
**`char` 可以当小整数用，整数和浮点数的内存布局不同。**

### 最小示例
<br>
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = -1;
    unsigned int b = 4294967295u;

    cout << "int -1 的十六进制：" << hex << a << endl;
    cout << "unsigned int 最大值：" << dec << b << endl;

    char c = 'A';
    cout << "字符 'A' 的编码：" << (int)c << endl;

    char c2 = 66;
    cout << "编码 66 对应的字符：" << c2 << endl;

    return 0;
}
```

### 输出
<br>
```text
int -1 的十六进制：ffffffff
unsigned int 最大值：4294967295
字符 'A' 的编码：65
编码 66 对应的字符：B
```

### 易错点
<br>
`char` 的符号性不确定，做数值运算时最好显式转成 `signed char` 或 `unsigned char`。  
浮点数比较不要直接用 `==`，因为精度问题。  
中文等多字节字符不能用单个 `char` 存，要用 `string` 或 `wchar_t`。

### 一句话总结
<br>
**数字用补码和 IEEE 754 编码，字符用 ASCII/Unicode 编码，char 本质是小整数。**

## 完整可运行示例：数组、链表与基本类型大小
***
下面把逻辑结构、物理结构、基本类型串起来。

```cpp
#include <iostream>
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int v) : val(v), next(nullptr) {}
};

int main() {
    // 逻辑结构：线性数组
    vector<int> arr = {10, 20, 30, 40};
    cout << "数组第 3 个元素：" << arr[2] << endl;

    // 物理结构：链表分散存储
    ListNode* head = new ListNode(10);
    head->next = new ListNode(20);
    head->next->next = new ListNode(30);

    ListNode* cur = head;
    for (int i = 0; i < 2; i++) cur = cur->next;
    cout << "链表第 3 个元素：" << cur->val << endl;

    // 基本类型大小
    cout << "int 大小：" << sizeof(int) << " 字节" << endl;
    cout << "char 大小：" << sizeof(char) << " 字节" << endl;
    cout << "bool 大小：" << sizeof(bool) << " 字节" << endl;

    // 字符编码
    char c = 'A';
    cout << "字符 'A' 的 ASCII：" << (int)c << endl;

    // 释放链表
    while (head) {
        ListNode* tmp = head;
        head = head->next;
        delete tmp;
    }
    return 0;
}
```

### 输出/现象/结论
<br>
```text
数组第 3 个元素：30
链表第 3 个元素：30
int 大小：4 字节
char 大小：1 字节
bool 大小：1 字节
字符 'A' 的 ASCII：65
```

关键结论：

- **数组是连续存储，支持随机访问；链表是分散存储，访问要遍历。**
- **逻辑结构看关系，物理结构看内存。**
- **基本类型是 CPU 直接运算的类型，char 本质是小整数。**
- **数字编码和字符编码决定了二进制怎么对应到实际值。**
