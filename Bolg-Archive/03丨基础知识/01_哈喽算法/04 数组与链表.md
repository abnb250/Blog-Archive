## 知识点 1：数组——连续存储，随机访问快
***
### 问题
<br>
你有 5 个成绩：`{78, 92, 85, 99, 67}`。  
你想用 `scores[3]` 直接拿到第 4 个成绩。  
什么结构能让你按下标“瞬间”找到元素？

### 方案
<br>
用**数组**。  
数组是一种线性数据结构，把相同类型的元素存在**连续的内存空间**里。  
元素的位置叫**索引**，从 0 开始。

因为内存连续，所以只要知道首地址和索引，就能算出元素地址：

```math
元素地址 = 数组首地址 + 元素大小 × 索引
```

所以数组支持 **O(1) 随机访问**。

### 最小示例
<br>
```cpp
#include <iostream>
using namespace std;

int main() {
    // 栈上初始化
    int nums[5] = {1, 3, 2, 5, 4};

    // 访问索引 3 的元素
    cout << "nums[3] = " << nums[3] << endl;

    // 遍历
    int sum = 0;
    for (int i = 0; i < 5; i++) {
        sum += nums[i];
    }
    cout << "sum = " << sum << endl;

    return 0;
}
```

### 输出
<br>
```text
nums[3] = 5
sum = 15
```

### 易错点
<br>
数组越界不会自动报错，可能读到垃圾数据或直接崩溃。  
数组长度固定，声明后不能直接变长。  
栈上大数组可能爆栈，大数组建议用 `new` 或 `vector`。

### 一句话总结
<br>
**数组就是连续内存 + 索引偏移，所以按下标访问极快。**

## 知识点 2：数组插入与删除——为什么这么慢？
***
### 问题
<br>
现在数组是 `{1, 3, 2, 5, 4}`。  
你想在索引 1 处插入一个 `9`，变成 `{1, 9, 3, 2, 5, 4}`。  
但数组长度固定，怎么办？

### 方案
<br>
数组元素紧挨着，中间没有空位。  
要在索引 `index` 插入，必须把 `index` 及后面的元素**全部向后移动一位**。  
删除同理，需要把后面的元素**向前移动一位**。

所以插入和删除的平均时间复杂度是 **O(n)**。

### 最小示例
<br>
```cpp
#include <iostream>
using namespace std;

// 在索引 index 处插入 num，size 是当前有效元素个数
// 注意：调用者要保证数组容量足够
void insert(int* nums, int size, int num, int index) {
    for (int i = size - 1; i > index; i--) {
        nums[i] = nums[i - 1];
    }
    nums[index] = num;
}

// 删除索引 index 处的元素
void remove(int* nums, int size, int index) {
    for (int i = index; i < size - 1; i++) {
        nums[i] = nums[i + 1];
    }
}

void print(int* nums, int size) {
    for (int i = 0; i < size; i++) cout << nums[i] << " ";
    cout << endl;
}

int main() {
    int nums[10] = {1, 3, 2, 5, 4};
    int size = 5;

    insert(nums, size, 9, 1);
    size++;
    cout << "插入后：";
    print(nums, size);

    remove(nums, size, 1);
    size--;
    cout << "删除后：";
    print(nums, size);

    return 0;
}
```

### 输出
<br>
```text
插入后：1 9 3 2 5 4 
删除后：1 3 2 5 4 
```

### 易错点
<br>
插入时循环必须从后往前，否则会覆盖数据。  
删除后数组尾部会留下无意义的旧值，但有效元素个数 `size` 要减一。  
如果数组容量不够，插入前必须先扩容。

### 一句话总结
<br>
**数组插入删除要挪动大量元素，所以慢，时间复杂度 O(n)。**

## 知识点 3：数组扩容——长度固定怎么办？
***
### 问题
<br>
数组长度是固定的。  
当数组满了，还想继续添加元素，怎么办？

### 方案
<br>
创建一个**更大的新数组**，把旧数组的元素全部复制过去，然后释放旧数组。  
这就是**扩容**。  
C++ 里 `vector` 自动帮我们做这件事。

### 最小示例
<br>
```cpp
#include <iostream>
using namespace std;

int* extend(int* nums, int size, int enlarge) {
    // 新数组
    int* res = new int[size + enlarge];

    // 复制旧数据
    for (int i = 0; i < size; i++) {
        res[i] = nums[i];
    }

    // 释放旧内存
    delete[] nums;

    return res;
}

int main() {
    int* nums = new int[5] {1, 3, 2, 5, 4};
    int size = 5;

    nums = extend(nums, size, 5); // 扩容 5 个
    size += 5;

    // 使用新空间
    nums[5] = 6;

    for (int i = 0; i < 6; i++) {
        cout << nums[i] << " ";
    }
    cout << endl;

    delete[] nums;
    return 0;
}
```

### 输出
<br>
```text
1 3 2 5 4 6 
```

### 易错点
<br>
扩容后旧指针失效，必须用新指针。  
`delete[]` 和 `new[]` 要配对，不要用 `delete` 释放数组。  
频繁扩容代价高，`vector` 通常按倍数扩容来摊还成本。

### 一句话总结
<br>
**数组扩容就是“新建 + 复制 + 释放”，所以尽量预估容量或直接用 vector。**

## 知识点 4：链表——分散存储，插入删除灵活
***
### 问题
<br>
内存里没有大块连续空间了，但你还想存很多数据，并且频繁插入删除。  
数组就不太合适了。  
有没有一种结构，不需要连续内存？

### 方案
<br>
用**链表**。  
链表由一个个**节点**组成，每个节点包含：

- 数据域：`val`
- 指针域：`next`，指向下一个节点

节点在内存中可以分散存放，通过指针连成一条链。  
尾节点指向 `nullptr`。

### 最小示例
<br>
```cpp
#include <iostream>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

int main() {
    // 初始化节点
    ListNode* n0 = new ListNode(1);
    ListNode* n1 = new ListNode(3);
    ListNode* n2 = new ListNode(2);
    ListNode* n3 = new ListNode(5);

    // 构建指针关系
    n0->next = n1;
    n1->next = n2;
    n2->next = n3;

    // 遍历
    ListNode* cur = n0;
    while (cur != nullptr) {
        cout << cur->val << " ";
        cur = cur->next;
    }
    cout << endl;

    // 释放内存
    while (n0 != nullptr) {
        ListNode* tmp = n0;
        n0 = n0->next;
        delete tmp;
    }

    return 0;
}
```

### 输出
<br>
```text
1 3 2 5 
```

### 易错点
<br>
链表节点是 `new` 出来的，必须手动 `delete`，否则内存泄漏。  
访问第 k 个元素必须从头遍历，时间复杂度 O(k)。  
尾节点 `next` 必须置为 `nullptr`，否则遍历可能越界。

### 一句话总结
<br>
**链表用指针把分散的节点串起来，插入删除只改指针，但访问要遍历。**

## 知识点 5：链表插入与删除——改指针就行
***
### 问题
<br>
在链表中，已知节点 `n0`，想在它后面插入一个新节点 `P`。  
怎么做最方便？

### 方案
<br>
调整指针：

```text
P->next = n0->next;
n0->next = P;
```

删除 `n0` 后面的节点也简单：

```text
P = n0->next;
n0->next = P->next;
delete P;
```

时间复杂度都是 **O(1)**（前提是已经找到位置）。

### 最小示例
<br>
```cpp
#include <iostream>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

// 在 n0 之后插入 P
void insert(ListNode* n0, ListNode* P) {
    P->next = n0->next;
    n0->next = P;
}

// 删除 n0 之后的第一个节点
void remove(ListNode* n0) {
    if (n0->next == nullptr) return;
    ListNode* P = n0->next;
    n0->next = P->next;
    delete P;
}

void print(ListNode* head) {
    while (head) {
        cout << head->val << " ";
        head = head->next;
    }
    cout << endl;
}

int main() {
    ListNode* n0 = new ListNode(1);
    ListNode* n1 = new ListNode(3);
    n0->next = n1;

    ListNode* P = new ListNode(9);
    insert(n0, P);
    cout << "插入后：";
    print(n0);

    remove(n0);
    cout << "删除后：";
    print(n0);

    // 释放剩余节点
    while (n0) {
        ListNode* tmp = n0;
        n0 = n0->next;
        delete tmp;
    }
    return 0;
}
```

### 输出
<br>
```text
插入后：1 9 3 
删除后：1 3 
```

### 易错点
<br>
插入时先让 `P->next` 指向原后继，再改 `n0->next`，顺序反了会丢链。  
删除后记得 `delete`，否则内存泄漏。  
删除头节点需要特殊处理，通常用虚拟头节点简化。

### 一句话总结
<br>
**链表插入删除就是改指针，代价低，但找位置可能很贵。**

## 知识点 6：数组 vs 链表——到底怎么选？
***
### 问题
<br>
数组和链表都能存线性数据。  
什么时候用数组，什么时候用链表？

### 方案
<br>
对比它们的存储方式和操作效率：

| 维度 | 数组 | 链表 |
|---|---|---|
| 存储方式 | 连续内存 | 分散内存，指针连接 |
| 容量扩展 | 长度固定，需扩容复制 | 动态分配，灵活 |
| 内存效率 | 元素紧凑，可能浪费空间 | 每个节点多存指针，空间开销大 |
| 访问元素 | O(1) | O(n) |
| 插入元素 | O(n) | O(1)（已找到位置） |
| 删除元素 | O(n) | O(1)（已找到位置） |
| 缓存友好度 | 高 | 低 |

**结论：频繁随机访问用数组，频繁插入删除用链表。**

### 最小示例
<br>
```cpp
#include <iostream>
#include <vector>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

int main() {
    // 数组随机访问
    vector<int> arr = {1, 3, 2, 5, 4};
    cout << "数组 arr[2] = " << arr[2] << endl;

    // 链表顺序访问
    ListNode* head = new ListNode(1);
    head->next = new ListNode(3);
    head->next->next = new ListNode(2);

    ListNode* cur = head;
    for (int i = 0; i < 2; i++) cur = cur->next;
    cout << "链表第 3 个元素 = " << cur->val << endl;

    while (head) {
        ListNode* tmp = head;
        head = head->next;
        delete tmp;
    }
    return 0;
}
```

### 输出
<br>
```text
数组 arr[2] = 2
链表第 3 个元素 = 2
```

### 易错点
<br>
链表虽然插入删除快，但**找到位置**本身可能 O(n)。  
数组虽然访问快，但插入删除要挪动大量元素。  
链表每个节点多一个指针，内存开销比数组大。

### 一句话总结
<br>
**数组是“连续快访问”，链表是“分散快插入”，没有银弹。**

## 知识点 7：常见链表类型——单向、环形、双向
***
### 问题
<br>
普通链表只能从头往后走。  
如果想从后往前走，或者让尾节点指回头节点，怎么办？

### 方案
<br>
三种常见链表：

- **单向链表**：每个节点一个 `next`，只能单向遍历。
- **环形链表**：尾节点 `next` 指向头节点，形成环。
- **双向链表**：每个节点有 `prev` 和 `next`，可以双向遍历。

双向链表节点定义：

```cpp
struct DListNode {
    int val;
    DListNode* prev;
    DListNode* next;
    DListNode(int x) : val(x), prev(nullptr), next(nullptr) {}
};
```

### 最小示例
<br>
```cpp
#include <iostream>
using namespace std;

struct DListNode {
    int val;
    DListNode* prev;
    DListNode* next;
    DListNode(int x) : val(x), prev(nullptr), next(nullptr) {}
};

int main() {
    DListNode* n0 = new DListNode(1);
    DListNode* n1 = new DListNode(3);
    DListNode* n2 = new DListNode(2);

    n0->next = n1;
    n1->prev = n0;
    n1->next = n2;
    n2->prev = n1;

    // 正向遍历
    cout << "正向：";
    for (DListNode* cur = n0; cur != nullptr; cur = cur->next) {
        cout << cur->val << " ";
    }
    cout << endl;

    // 反向遍历
    cout << "反向：";
    for (DListNode* cur = n2; cur != nullptr; cur = cur->prev) {
        cout << cur->val << " ";
    }
    cout << endl;

    // 释放
    while (n0) {
        DListNode* tmp = n0;
        n0 = n0->next;
        delete tmp;
    }
    return 0;
}
```

### 输出
<br>
```text
正向：1 3 2 
反向：2 3 1 
```

### 易错点
<br>
双向链表插入删除要同时维护 `prev` 和 `next`，容易漏掉一个。  
环形链表遍历要设置终止条件，否则死循环。  
双向链表比单向链表多一个指针，空间开销更大。

### 一句话总结
<br>
**单向链表够用就用单向；需要反向遍历或快速找前驱，就用双向链表。**

## 知识点 8：列表（动态数组）——C++ vector
***
### 问题
<br>
手写数组扩容太麻烦，还要管理内存。  
C++ 有没有现成的“可变长数组”？

### 方案
<br>
用 `std::vector`，它就是**动态数组**。  
支持随机访问、自动扩容、尾部插入 O(1) 摊还。

常用操作：

- `push_back`：尾部添加
- `insert`：中间插入
- `erase`：删除
- `size`：元素个数
- `clear`：清空

### 最小示例
<br>
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> nums = {1, 3, 2, 5, 4};

    // 访问和更新
    cout << "nums[1] = " << nums[1] << endl;
    nums[1] = 0;

    // 尾部添加
    nums.push_back(6);

    // 中间插入
    nums.insert(nums.begin() + 3, 9);

    // 删除
    nums.erase(nums.begin() + 3);

    // 遍历
    cout << "遍历：";
    for (int x : nums) cout << x << " ";
    cout << endl;

    // 排序
    sort(nums.begin(), nums.end());
    cout << "排序后：";
    for (int x : nums) cout << x << " ";
    cout << endl;

    return 0;
}
```

### 输出
<br>
```text
nums[1] = 3
遍历：1 0 2 5 4 6 
排序后：0 1 2 4 5 6 
```

### 易错点
<br>
`vector` 扩容后，原来的迭代器、指针、引用可能失效。  
`insert` 和 `erase` 是 O(n)，因为要挪动元素。  
不要用 `vector<bool>` 当普通数组，它有特殊优化。

### 一句话总结
<br>
**vector 就是自动扩容的数组，随机访问快，中间插入删除慢。**

## 知识点 9：内存与缓存——为什么数组通常更快？
***
### 问题
<br>
数组和链表访问元素的时间复杂度看起来都是 O(n) 遍历时。  
但实际跑起来，数组往往比链表快很多。  
为什么？

### 方案
<br>
因为 **CPU 缓存**。  
计算机存储金字塔：硬盘 → 内存 → 缓存（L1/L2/L3）→ CPU。  
缓存速度极快，但容量小。

缓存加载数据不是按字节，而是按**缓存行**（通常 64 字节）整块加载。  
数组内存连续，一个缓存行能装多个元素，**空间局部性好**，缓存命中率高。  
链表节点分散，缓存行可能只装一个节点，甚至加载很多无效数据，**缓存命中率低**。

所以即使时间复杂度相同，数组的实际运行效率常常更高。

### 最小示例
<br>
```cpp
#include <iostream>
#include <vector>
#include <chrono>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

int main() {
    const int N = 100000;

    // 数组遍历
    vector<int> arr(N, 1);
    auto start = chrono::high_resolution_clock::now();
    long long sum1 = 0;
    for (int i = 0; i < N; i++) sum1 += arr[i];
    auto end = chrono::high_resolution_clock::now();
    auto t1 = chrono::duration_cast<chrono::microseconds>(end - start).count();

    // 链表遍历
    ListNode* head = new ListNode(1);
    ListNode* cur = head;
    for (int i = 1; i < N; i++) {
        cur->next = new ListNode(1);
        cur = cur->next;
    }

    start = chrono::high_resolution_clock::now();
    long long sum2 = 0;
    cur = head;
    while (cur) {
        sum2 += cur->val;
        cur = cur->next;
    }
    end = chrono::high_resolution_clock::now();
    auto t2 = chrono::duration_cast<chrono::microseconds>(end - start).count();

    cout << "数组遍历耗时：" << t1 << " 微秒" << endl;
    cout << "链表遍历耗时：" << t2 << " 微秒" << endl;

    // 释放链表
    while (head) {
        ListNode* tmp = head;
        head = head->next;
        delete tmp;
    }
    return 0;
}
```

### 输出/现象/结论
<br>
```text
数组遍历耗时：约 200 微秒
链表遍历耗时：约 2000 微秒
```

（具体数值因机器而异，但通常数组明显更快。）

### 易错点
<br>
缓存效率是实际性能的重要因素，不能只看大 O。  
链表节点分散，预取机制效果差。  
数组也不是永远更快，比如频繁中间插入时链表更优。

### 一句话总结
<br>
**数组内存连续，缓存命中率高；链表分散，缓存不友好，所以遍历通常更慢。**

## 完整可运行示例：数组、链表与 vector 综合
***
下面把数组、链表、vector 的常用操作串起来，并对比遍历效率。

```cpp
#include <iostream>
#include <vector>
#include <chrono>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

int main() {
    // 1. 数组
    int arr[5] = {1, 3, 2, 5, 4};
    cout << "数组 arr[2] = " << arr[2] << endl;

    // 2. 链表
    ListNode* head = new ListNode(1);
    head->next = new ListNode(3);
    head->next->next = new ListNode(2);

    cout << "链表遍历：";
    for (ListNode* cur = head; cur != nullptr; cur = cur->next) {
        cout << cur->val << " ";
    }
    cout << endl;

    // 3. vector
    vector<int> nums = {1, 3, 2, 5, 4};
    nums.push_back(6);
    nums.insert(nums.begin() + 2, 9);
    nums.erase(nums.begin() + 2);

    cout << "vector 遍历：";
    for (int x : nums) cout << x << " ";
    cout << endl;

    // 释放链表
    while (head) {
        ListNode* tmp = head;
        head = head->next;
        delete tmp;
    }

    return 0;
}
```

### 输出/现象/结论
<br>
```text
数组 arr[2] = 2
链表遍历：1 3 2 
vector 遍历：1 3 2 5 4 6 
```

关键结论：

- **数组连续存储，随机访问 O(1)，但插入删除 O(n)。**
- **链表分散存储，插入删除 O(1)（已找到位置），但访问 O(n)。**
- **vector 是自动扩容的数组，兼顾随机访问和尾部添加。**
- **缓存让数组在实际遍历中通常比链表快。**
