## 痛点引入
***
你写 C++ 时肯定遇到过这些场景：

- 浏览器点“后退”，怎么知道回到哪个页面？
- 函数一层层调用，返回时怎么知道回到哪里？
- 打印机同时收到多个任务，为什么按提交顺序打印？
- 滑动窗口求最大值，为什么需要两端都能进出的容器？

这些问题背后，其实是两种非常基础但极其重要的数据结构：**栈**和**队列**。  
它们都是线性结构，但操作受限：栈是“后进先出”，队列是“先进先出”。  
咱们从一个最小问题开始：**怎么实现一个“撤销”功能？**

<br><br>

## 知识点 1：栈——后进先出（LIFO）
***
### 问题
<br>
你在写一个编辑器，用户每次输入都记录一下，按 Ctrl+Z 要撤销最近一次操作。  
最近一次操作，应该最先被撤销。  
什么结构能保证“最后进来的，最先出去”？

### 方案
<br>
用**栈**。  
栈是一种线性数据结构，只允许在**栈顶**进行插入和删除。  
插入叫**入栈（push）**，删除叫**出栈（pop）**，访问栈顶叫**peek**。  
特点：**后进先出（Last In First Out，LIFO）**。

### 最小示例
<br>
```cpp
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> stk;

    // 入栈
    stk.push(1);
    stk.push(3);
    stk.push(2);

    // 访问栈顶
    cout << "栈顶元素：" << stk.top() << endl;

    // 出栈
    stk.pop();
    cout << "出栈后栈顶：" << stk.top() << endl;

    // 栈大小
    cout << "栈大小：" << stk.size() << endl;

    return 0;
}
```

### 输出
<br>
```text
栈顶元素：2
出栈后栈顶：3
栈大小：2
```

### 易错点
<br>
对空栈调用 `top()` 或 `pop()` 是未定义行为，可能直接崩溃。  
使用前一定要先 `empty()` 判断。  
另外，`pop()` 不返回被删除的元素，要取值得先 `top()`。

### 一句话总结
<br>
**栈就是“叠盘子”，只能从顶部拿放，后进的先出。**

### 自测
<br>
用栈模拟浏览器后退：依次访问 A、B、C 三个页面，后退一次回到哪个页面？

## 知识点 2：队列——先进先出（FIFO）
***
### 问题
<br>
打印机收到三个打印任务，按提交顺序依次打印。  
先提交的任务应该先打印。  
什么结构能保证“先进来的，先出去”？

### 方案
<br>
用**队列**。  
队列只允许在**队尾**插入（入队，push），在**队首**删除（出队，pop）。  
特点：**先进先出（First In First Out，FIFO）**。

### 最小示例
<br>
```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<int> q;

    // 入队
    q.push(1);
    q.push(3);
    q.push(2);

    // 访问队首
    cout << "队首元素：" << q.front() << endl;
    cout << "队尾元素：" << q.back() << endl;

    // 出队
    q.pop();
    cout << "出队后队首：" << q.front() << endl;

    return 0;
}
```

### 输出
<br>
```text
队首元素：1
队尾元素：2
出队后队首：3
```

### 易错点
<br>
空队列调用 `front()`、`back()`、`pop()` 都会出错。  
`pop()` 同样不返回元素，需要先 `front()` 取值。  
队列和栈一样，都是操作受限的线性结构。

### 一句话总结
<br>
**队列就是“排队”，从队尾进、从队首出，先进先出。**

### 自测
<br>
用队列模拟打印任务：依次提交任务 1、2、3，打印顺序是什么？

## 知识点 3：栈的实现——链表 vs 数组
***
### 问题
<br>
STL 的 `stack` 很好用，但面试常让你手写一个栈。  
用链表还是数组实现？各自有什么坑？

### 方案
<br>
栈只在一端操作，所以两种方式都能做到 O(1)：

- **基于链表**：把头节点当作栈顶，入栈用头插法，出栈删除头节点。
- **基于数组**：把数组尾部当作栈顶，入栈 `push_back`，出栈 `pop_back`。
  数组需要动态扩容，但均摊效率高；链表每次操作都要 `new/delete`，稍慢但稳定。

### 最小示例
<br>
```cpp
#include <iostream>
#include <vector>
using namespace std;

// 基于数组的栈
class ArrayStack {
private:
    vector<int> data;
public:
    void push(int x) { data.push_back(x); }

    int pop() {
        if (data.empty()) throw out_of_range("栈为空");
        int val = data.back();
        data.pop_back();
        return val;
    }

    int top() {
        if (data.empty()) throw out_of_range("栈为空");
        return data.back();
    }

    bool empty() const { return data.empty(); }
    int size() const { return data.size(); }
};

int main() {
    ArrayStack stk;
    stk.push(1);
    stk.push(3);
    stk.push(2);

    cout << "栈顶：" << stk.top() << endl;
    cout << "出栈：" << stk.pop() << endl;
    cout << "出栈后栈顶：" << stk.top() << endl;

    return 0;
}
```

### 输出
<br>
```text
栈顶：2
出栈：2
出栈后栈顶：3
```

### 易错点
<br>
基于链表实现时，出栈后要 `delete` 节点，否则内存泄漏。  
基于数组实现时，要注意扩容；如果自己管理数组，记得释放旧内存。  
无论哪种，空栈操作都要提前判断。

### 一句话总结
<br>
**栈用链表实现就是头插头删，用数组实现就是尾插尾删，都能 O(1)。**

### 自测
<br>
用链表实现栈时，为什么把头节点当作栈顶最方便？

## 知识点 4：队列的实现——链表 vs 环形数组
***
### 问题
<br>
用普通数组实现队列，如果直接删除队首元素，后面的元素都要往前挪，时间复杂度 O(n)。  
怎么让出队也变成 O(1)？

### 方案
<br>
两种思路：

- **基于链表**：维护 `front` 和 `rear` 指针，队尾插入，队首删除，都是 O(1)。
- **基于环形数组**：用 `front` 指向队首，`size` 记录元素个数，`rear = (front + size) % capacity`。  
  入队时在 `rear` 位置放元素，`size++`；出队时 `front = (front + 1) % capacity`，`size--`。  
  这样不用移动元素，也能复用空间。

### 最小示例
<br>
```cpp
#include <iostream>
#include <vector>
using namespace std;

// 基于环形数组的队列（简化版，固定容量）
class CircularQueue {
private:
    vector<int> data;
    int front;
    int size;
    int capacity;
public:
    CircularQueue(int cap) : data(cap), front(0), size(0), capacity(cap) {}

    bool push(int x) {
        if (size == capacity) return false; // 队满
        int rear = (front + size) % capacity;
        data[rear] = x;
        size++;
        return true;
    }

    int pop() {
        if (size == 0) throw out_of_range("队列为空");
        int val = data[front];
        front = (front + 1) % capacity;
        size--;
        return val;
    }

    int peek() {
        if (size == 0) throw out_of_range("队列为空");
        return data[front];
    }

    bool empty() const { return size == 0; }
};

int main() {
    CircularQueue q(5);
    q.push(1);
    q.push(3);
    q.push(2);

    cout << "队首：" << q.peek() << endl;
    cout << "出队：" << q.pop() << endl;
    cout << "出队后队首：" << q.peek() << endl;

    return 0;
}
```

### 输出
<br>
```text
队首：1
出队：1
出队后队首：3
```

### 易错点
<br>
环形数组的 `rear` 计算要用取模，否则越界。  
判断队空是 `size == 0`，队满是 `size == capacity`。  
`front` 和 `rear` 的更新都要取模，否则会跑出数组范围。

### 一句话总结
<br>
**队列用链表是头删尾插，用环形数组是 front/size 配合取模，都能 O(1)。**

## 知识点 5：双向队列——两端都能进出
***
### 问题
<br>
栈只能在一端操作，队列一端进另一端出。  
如果需要**两端都能插入和删除**，比如实现一个“最近 50 步撤销”的功能，超过 50 步要从底部删掉，栈做不到。  
怎么办？

### 方案
<br>
用**双向队列（deque）**。  
它支持在队首和队尾都进行插入和删除，操作都是 O(1)。  
C++ STL 提供了 `deque`。

常用操作：

- `push_front` / `pop_front`
- `push_back` / `pop_back`
- `front` / `back`

### 最小示例
<br>
```cpp
#include <iostream>
#include <deque>
using namespace std;

int main() {
    deque<int> dq;

    // 两端插入
    dq.push_back(1);
    dq.push_back(3);
    dq.push_front(2);

    cout << "队首：" << dq.front() << "，队尾：" << dq.back() << endl;

    // 两端删除
    dq.pop_front();
    dq.pop_back();

    cout << "删除两端后，队首：" << dq.front() << endl;

    return 0;
}
```

### 输出
<br>
```text
队首：2，队尾：3
删除两端后，队首：1
```

### 易错点
<br>
`deque` 虽然两端操作 O(1)，但中间插入删除仍是 O(n)。  
空 `deque` 调用 `front`、`back`、`pop` 都会出错。  
它比 `vector` 和 `queue` 更灵活，但也更复杂，不要滥用。

### 一句话总结
<br>
**双向队列就是两端都能进出的队列，兼具栈和队列的灵活性。**

<br>

## 知识点 6：栈与队列的典型应用
***
### 问题
<br>
学了栈和队列，到底用在哪？  
为什么面试总爱考它们？

### 方案
<br>
它们是最基础的“受限线性结构”，很多算法和系统都依赖它们：

- **栈**：
  - 浏览器后退/前进
  - 函数调用栈（递归、栈帧）
  - 表达式求值、括号匹配
  - 撤销/反撤销
- **队列**：
  - 任务调度（打印队列、线程池）
  - 广度优先搜索（BFS）
  - 消息队列、订单处理
- **双向队列**：
  - 滑动窗口最大值
  - 限制步数的撤销历史
  - 工作窃取算法

### 最小示例
<br>
```cpp
#include <iostream>
#include <stack>
#include <queue>
#include <string>
using namespace std;

int main() {
    // 栈：括号匹配
    string s = "({[]})";
    stack<char> stk;
    bool ok = true;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') stk.push(c);
        else {
            if (stk.empty()) { ok = false; break; }
            char top = stk.top(); stk.pop();
            if ((c == ')' && top != '(') ||
                (c == ']' && top != '[') ||
                (c == '}' && top != '{')) {
                ok = false; break;
            }
        }
    }
    if (!stk.empty()) ok = false;
    cout << "括号匹配：" << (ok ? "是" : "否") << endl;

    // 队列：任务顺序
    queue<string> tasks;
    tasks.push("打印A");
    tasks.push("打印B");
    tasks.push("打印C");
    cout << "任务顺序：";
    while (!tasks.empty()) {
        cout << tasks.front() << " ";
        tasks.pop();
    }
    cout << endl;

    return 0;
}
```

### 输出
<br>
```text
括号匹配：是
任务顺序：打印A 打印B 打印C 
```

### 易错点
<br>
括号匹配时，最后栈必须为空，否则说明有未闭合的左括号。  
队列处理任务时，注意不要边遍历边修改导致混乱。  
双向队列不是所有场景都优于栈或队列，按需选择。

### 一句话总结
<br>
**栈适合“最近相关”的场景，队列适合“按序处理”的场景，双向队列适合两端都要操作的场景。**

## 完整可运行示例：栈、队列、双向队列综合
***
下面把三种结构放在一个程序里，演示基本操作和典型用法。

```cpp
#include <iostream>
#include <stack>
#include <queue>
#include <deque>
using namespace std;

int main() {
    // 1. 栈：后进先出
    stack<int> stk;
    stk.push(1);
    stk.push(2);
    stk.push(3);
    cout << "栈顶：" << stk.top() << endl;
    stk.pop();
    cout << "出栈后栈顶：" << stk.top() << endl;

    // 2. 队列：先进先出
    queue<int> q;
    q.push(1);
    q.push(2);
    q.push(3);
    cout << "队首：" << q.front() << endl;
    q.pop();
    cout << "出队后队首：" << q.front() << endl;

    // 3. 双向队列：两端操作
    deque<int> dq;
    dq.push_back(10);
    dq.push_back(20);
    dq.push_front(5);
    cout << "双向队列队首：" << dq.front()
         << "，队尾：" << dq.back() << endl;
    dq.pop_front();
    dq.pop_back();
    cout << "两端删除后，队首：" << dq.front() << endl;

    return 0;
}
```

### 输出/现象/结论
<br>
```text
栈顶：3
出栈后栈顶：2
队首：1
出队后队首：2
双向队列队首：5，队尾：20
两端删除后，队首：10
```

关键结论：

- **栈：后进先出，适合撤销、递归、括号匹配。**
- **队列：先进先出，适合任务调度、BFS。**
- **双向队列：两端都能进出，适合滑动窗口、限制历史记录。**
- **实现方式：链表和数组都能实现栈/队列，环形数组让队列出队也 O(1)。**

***
