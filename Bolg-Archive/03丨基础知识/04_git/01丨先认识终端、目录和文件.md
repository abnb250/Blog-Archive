## 00 本节目标
***
知道怎么打开终端，怎么进入目录，怎么创建文件。  
这些是学Git的地基。  

<br>

<br>

## 01 打开终端
***
Windows：安装 Git 后，开始菜单搜索 Git Bash。  
macOS：按 Command + 空格，搜索 Terminal。  
Linux：一般按 Ctrl + Alt + T。  

<br>

打开后你会看到一个可以输入命令的窗口。  
你输入命令，按回车，电脑执行。  

<br>

<br>

## 02 常用终端命令
***
查看当前在哪个目录：  
```bash
pwd
```

<br>

列出当前目录下的文件：  
```bash
ls
```

<br>

进入某个目录：  
```bash
cd 目录名
```

<br>

返回上一级目录：  
```bash
cd ..
```

<br>

创建新目录：  
```bash
mkdir git-study
```

<br>

进入刚刚创建的目录：  
```bash
cd git-study
```

<br>

创建新文件：  
```bash
echo "hello git" > a.txt
```

<br>

查看文件内容：  
```bash
cat a.txt
```

<br>

删除文件：  
```bash
rm a.txt
```

<br>

我们把他们串起来：  
```bash
pwd
mkdir git-study
cd git-study
echo "hello git" > a.txt
ls
cat a.txt
cd ..
```  

解释：
- pwd ：你现在在哪。
- mkdir git-study ：创建一个叫 git-study 的文件夹。
- cd git-study ：进入这个文件夹。
- echo "hello git" > a.txt ：把 hello git 写进 a.txt。
- ls ：看看目录里有什么。
- cat a.txt ：查看 a.txt 内容。
- cd .. ：回到上一级。

<br>

<br>
