## 00 本节目标
***
学会让 Git 不要跟踪某些文件。  

<br>

<br>

## 01 为什么需要忽略
***
因为有些文件不该提交：  
- 日志文件：*.log  
- 依赖目录：node_modules/
- 密码配置：.env
- 编译产物：dist/、build/

<br>

<br>

## 02 创建.gitignore
***
原理是将一些文件后缀，加入到.gitignore。  
```bash
echo "*.log" > .gitignore
echo "node_modules/" >> .gitignore
echo ".env" >> .gitignore
```

<br>

<br>

## 03 测试
***
我们尝试对.log文件进行编辑，  
然后看看Git能否追踪。  
```
echo "debug" > debug.log
git status
```
你会发现 debug.log 没有出现在 Git 提示里，因为它被忽略了。  

<br>

<br>

## 04 查看.gitignore
***
我们可以通过查看指令查看哪些文件被忽略：  
```bash
cat .gitignore
```
我们得到输出：  
```text
*.log
node_modules/
.env
```

<br>

<br>

## 05 提交.gitignore
***
直接提交：  
```bash
git add .gitignore
git commit -m "chore: 添加 .gitignore"
```
