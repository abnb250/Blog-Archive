## 00 本节目标
***
学会创建、切换、查看分支  

<br>

<br>

## 01 分支是什么
***
分支可以想成平行世界，  
main 是主线，  
你可以开一个新分支做功能，  
新分支不影响主线。  

<br>

<br>

## 02 查看分支
***
可以使用下面的命令查看分支：
```bash
git branch
```
可以得到输出：
```text
* main
```
这里的 * 表示当前所在的分支。  

<br>

<br>

## 03 创建并切换分支
***
创建分支feature/add-task：
```bash
git switch -c feature/add-task
```
-c 表示创建并切换过去。  

<br>

<br>

## 04 在新分支上开发
***
执行下列命令：
```bash
echo "1. 写代码" > tasks.txt
git add tasks.txt
git commit -m "feat: 添加任务文件"
```

<br>

<br>

## 05 切回main
我们切回main并查看所有文件：
```bash
git switch main
ls
```
你会发现 tasks.txt 不在 main 分支里，  
因为它在 feature/add-task 分支上。  

<br>

<br>

## 06 查看所有分支历史
使用下面命令查看：  
```bash
git log --oneline --graph --all
```

<br>

<br>

## 07 练习
***
1. 创建分支 feature/add-task。
2. 在新分支创建 tasks.txt 并提交。
3. 切回 main，确认文件不在。
4. 用 git log --oneline --graph --all 查看。
