## 00 本节目标
***
学会把一个分支合并到另一个分支，并解决冲突  

<br>

<br>

## 01 合并分支
***
我们先切回主分支main:  
```bash
git switch main
```  
合并feature/add-task：  
```bash
git merge feature/add-task
```  
现在tasks.txt出现在main了。  

<br>

<br>

## 02 删除已合并分支
***
使用下面命令删除：
```bash
git branch -d feature/add-task
```

<br>

<br>

## 03 冲突是怎么产生的
***
如果两个分支改了同一行，Git不知道听谁的，就会冲突。  
比如下面这些指令：  
首先是第一个分支：
```bash
git switch -c feature/change-title
echo "# Todo List" > README.md
git add README.md
git commit -m "docs: 修改标题为 Todo List"
```
然后是main分支
```bash
git switch main
echo "# My Todo App" > README.md
git add README.md
git commit -m "docs: 修改标题为 My Todo App"
```
两个分支都修改了README文件中的标题，如果合并就会提示冲突：
```bash
git merge feature/change-title
```
显示：
```text
$ git merge test
Auto-merging README.md
CONFLICT (content): Merge conflict in README.md
Automatic merge failed; fix conflicts and then commit the result.
```

<br>

<br>

## 04 解决冲突
***
打开README.md:
```bash
nano README.md
```
会看到：
```text
 <<<<<<< HEAD
# My Todo App
=======
# Todo List
 >>>>>>> feature/change-title
```
手动改成你需要的内容，然后删除<<<<<<<、=======、>>>>>>> 这些标记。   
使用ctrl+O保存，再使用ctrl+X退出。  
接着提交：
```bash
git add README.md
git commit -m "marge: 解决 README 标题冲突"
```
然后删除分支。  

<br>
