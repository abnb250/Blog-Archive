## 00 本节目标
***
学会和远程仓库同步

<br>

<br>

## 01 克隆仓库
***
把远程仓库下载到本地:
```bash
git clone https://github.com/你的用户名/todo-app.git
```
进入目录: 
```bash
cd todo-app
```

<br>

<br>

## 02 推送本次更新
***
在更改文件，加入暂存区，提交本地仓库之后，  
多一个推送至在线仓库：
```bash
echo "- 学习远程仓库" >> README.md
git add README.md
git commit -m "docs: 添加远程仓库笔记"
git push
```

<br>

<br>

## 03 拉取远程更新
***
如果别人改了远程仓库，那我们本地需要更新：
```bash
git pull
```
pull = fetch + merge  
- fetch ：只下载远程更新，不合并。
- pull ：下载并合并到当前分支。

<br>

因此我们也可以分开：
```bash
git fetch
git status
git merge origin/main
```

<br>

<br>

## 04 查看远程
***
查看远程所连接的仓库：
```bash
git remote -v
```

<br>

<br>

## 05 练习
***
1. 克隆自己的仓库。
2. 修改 README。
3. 提交并 git push。
4. 在 GitHub 网页上直接改 README。
5. 本地 git pull，看变化是否同步。
