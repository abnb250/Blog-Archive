## 00 本节目标
***
知道改错了怎么改

<br>

<br>

## 01 工作区改坏，还没add
***
使用
```bash
git restore README.md
```
README恢复到最后一次提交的状态。  

<br>

<br>

## 02 已经add，想取消暂存
***
使用：
```bash
git restore --staged README.md
```
文件内容还在，只是不再暂存。  

<br>

<br>

## 03 提交信息写错
***
使用：
```bash
git commit --amend -m "新的提交信息"
```
修改最近一次提交。  

<br>

<br>

## 04 撤销最近一次提交，但保留修改
***
使用：
```bash
git reset --soft HAED~1
```
提交没了，修改还在暂存区。  

<br>

<br>

## 05 撤销提交，取消暂存，但保留工作区修改
***
使用:
```bash
git reset HEAD~1
``` 

<br>

<br>

## 06 危险操作，丢弃提交和修改
***
使用：
```bash
git reset --hard HEAD~1
```
会丢代码，新手慎用。  

<br>

<br>

## 07 已经推送到公共分支，想撤销
***
使用：
```bash
git revert <commit-id>
```
revert会新建一个提交，抵消旧提交，比较安全。  

<br>

<br>

## 08 误操作后想看记录
***
使用：
```bash
git reflog
```
reflog是Git的飞行记录仪，  
可以帮你找回误删的提交。  

<br>

<br>

## 09 练习
***
1. 改坏 README，用 git restore 恢复。
2. git add 后用 git restore --staged 取消暂存。
3. 改最近一次提交信息。
