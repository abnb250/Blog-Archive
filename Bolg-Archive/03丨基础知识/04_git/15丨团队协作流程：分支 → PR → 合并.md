## 00 本节目标
***
走一遍真实团队常用流程

<br>

<br>

## 01 更新main
***
```bash
git switch main
git pull
```

<br>

<br>

## 02 创建功能分支
***
```bash
git switch -c feature/login
```

<br>

<br>

## 03 开发并提交
***
```bash
echo "登录页面" > login.txt
git add login.txt
git commit -m "feat: 添加登录页面"
```

<br>

<br>

## 04 推送分支
***
```bash
git push -u origin feature/login
```

<br>

<br>

## 05 在Github发起Pull Request
***
Pull Request 就是 pr。  
打开 GitHub，会看到提示 Compare & pull request。
填写说明，然后创建 PR。

<br>

<br>

## 06 代码审查与合并
***
队友审查后，点击 Merge 合并到 main。

<br>

<br>

## 07 本地更新
***
```bash
git switch main
git pull
```

<br>

<br>

## 08 删除本地功能分支
***
```bash
git branch -d feature/login
```

<br>

<br>

## 09 练习
***
模拟一次完整流程：

1. 新建分支。

2. 改文件并提交。

3. 推送。

4. 在 GitHub 发起 PR。

5. 合并。

6. 本地拉取最新 main。
