## 00 本节目标
***
遇到常见的错误知道如何解决。  

<br>

<br>

## 01 fatal:not a git repository
***
原因：你不在Git仓库目录里。  
解决：
```bash
pwd
ls -a
cd 目录
```
或者
```bash
git init
```

<br>

<br>

## 02 Please tell me who you are
***
原因：没配置用户名和邮箱
解决：
```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱@example.com"
```

<br>

<br>

## 03 nothing to commit
***
原因：没有新改动，或者改动已经提交。  
解决：
```bash
git status
```

<br>

<br>

## 04 failed to push some refs/rejected
***
原因：远程有你本地没有的提交  
解决：
```bash
git pull
```
解决冲突后再   
```bash
git push
```

<br>

<br>

## 05 合并冲突
*** 
看到：
```text
 <<<<<<< HEAD
=======
>>>>>>> branch
```
解决：手动改文件，删除标记，然后：
```bash
git add 文件
git commit -m ""
```

<br>

<br>

## 06 detached HEAD
***
你不在分支上，而是在某个提交上：
解决：
```bash
git switch main
```
或创建分支：
```bash
git switch -c 新分支
```

<br>

<br>

## 07 误用 reset --hard
***
先别慌，使用：
```bash
git reflog
```
找到之前的提交ID，然后
```bash
git reset --hard <commit-id>
```

<br>

<br>

## 08 万能求助
***
各个主要查看状态的命令：  
```bash
git status
git log --oneline --graph --all
git reflog
```
