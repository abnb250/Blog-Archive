## 知识点 1：C++ 到底是什么？——一个语言，多种写法

***
<br>

### 问题

<br>

你听说 C++ 有面向对象、有模板，又像 C 一样能写函数，感觉像三个语言硬塞在一起。它到底算什么？

<br>

### 方案

<br>

简单说，C++ 是多种编程方式的融合。经典说法是三种：

- **过程性编程**：像 C 一样，用函数一步步处理数据。
- **面向对象编程 OOP**：用类、对象、封装、继承、多态来组织代码。
- **泛型编程**：用模板写和具体类型无关的代码。

你不需要现在全懂，只要知道 C++ 能写函数、能写类、能写模板就行。后面会一个个学。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

// 过程式：普通函数
int add(int a, int b) {
    return a + b;
}

// 面向对象：简单类
class Printer {
public:
    void say(const char* text) {
        std::cout << text << std::endl;
    }
};

int main() {
    std::cout << add(1, 2) << std::endl;

    Printer p;
    p.say("Hello C++");
    return 0;
}
```

运行结果：

```text
3
Hello C++
```

模板后面再学，现在不用管。

<br>

### 一句话总结

<br>

**C++ 就是 C 的过程式 + 类 + 模板，先知道有这回事就行。**

## 知识点 2：代码怎么变成程序？——编译链接四步

***
<br>

### 问题

<br>

你写完代码，敲 `g++ main.cpp -o main`，它就变成了可执行文件。这中间到底发生了什么？为什么有时候会报“未定义引用”？

<br>

### 方案

<br>

不用记太细，知道有四步就行：

1. **预处理**：处理 `#include`、`#define` 等。
2. **编译**：把代码翻译成汇编。
3. **汇编**：把汇编翻译成目标代码（`.o` / `.obj`）。
4. **链接**：加入启动代码、库代码，把多个目标文件合成可执行文件。

“未定义引用”通常发生在链接阶段，意思是“你用了某个函数，但链接器找不到它的定义”。

<br>

### 最小示例

<br>

```cpp
// main.cpp
#include <iostream>

int main() {
    std::cout << "Hello C++" << std::endl;
    return 0;
}
```

编译运行：

```bash
g++ main.cpp -o main
./main
```

运行结果：

```text
Hello C++
```

<br>

### 一句话总结

<br>

**源码要经过预处理、编译、汇编、链接四步才变成可执行文件，链接器负责把缺失的定义找齐。**

<br>

## 知识点 3：第一个程序怎么写？——main、iostream、return 0

***
<br>

### 问题

<br>

网上有些代码写 `void main()`，还有人用 `#include <iostream.h>`。这些能行吗？标准写法到底是什么？

<br>

### 方案

<br>

C++ 标准支持的 `main` 是：

```cpp
int main()
```

或者：

```cpp
int main(int argc, char* argv[])
```

**不要写 `void main()`**，标准不支持。头文件用：

```cpp
#include <iostream>
```

不是 `iostream.h`。`std::cout` 里的 `std` 是命名空间，不能随便省。

另外，源文件扩展名要正确：`.cpp`、`.cxx`、`.cc` 等，告诉编译器这是 C++。

<br>

### 最小示例

<br>

```cpp
// main.cpp
#include <iostream>

int main() {
    std::cout << "Hello C++" << std::endl;
    return 0;
}
```

编译运行：

```bash
g++ main.cpp -o main
./main
```

运行结果：

```text
Hello C++
```

<br>

### 一句话总结

<br>

**标准入口是 `int main()`，标准头文件是 `<iostream>`，别写 `void main()` 和 `iostream.h`。**

<br>

## 完整可运行代码
***

下面这个程序把本章几个点串了一遍：标准 `main`、`iostream`、函数、简单类。

```cpp

int add(int a, int b) {
    return a + b;

public:
    void say(const char* text) {
        std::cout << text << std::endl;
    }

int main() {
    std::cout << add(1, 2) << std::endl;

    Printer p;
    p.say("Hello C++");

    return 0;
}
```

编译运行：

```bash
g++ main.cpp -o main
./main
```

运行结果：

```text
3
Hello C++
```
