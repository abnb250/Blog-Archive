## 一句话概括
***
**一句话**：C++ 是过程性编程、面向对象编程、泛型编程的融合；程序从源码到可执行文件要经过预处理、编译、汇编、链接。  

<br>

<br>

## 核心概念
***
- C++ 融合 4 种编程方式：C 的过程性、类代表的 OOP、模板支持的泛型编程。
- OOP 核心：类、对象、封装、继承、多态、信息隐藏、代码重用。
- 泛型编程：编写独立于具体类型的代码，C++ 用模板实现。
- 可移植性：ISO C++ 标准保证不同平台行为一致，但类型宽度等仍可能不同。

<br>

<br>

## 编译链接过程
***
```text
源代码(.cpp) → 预处理器 → 编译器 → 目标代码(.o/.obj) → 链接器(加入启动代码、库代码) → 可执行文件
```

<br>

<br>

## 最小代码
***
```cpp
// main.cpp
#include <iostream>

int main() {
    std::cout << "Hello C++" << std::endl;
    return 0;
}
```

<br>

编译：
```bash
g++ main.cpp -o main
```

<br>

<br>

## 易错点
***
- 源文件扩展名要正确：`.cpp`、`.cxx`、`.cc` 等，告诉编译器这是 C++。
- `main` 函数标准形式：`int main()` 或 `int main(int argc, char* argv[])`。
- 不要写 `void main()`，C++ 标准不支持。
- 头文件用 `#include <iostream>`，不是 `iostream.h`。

<br>
