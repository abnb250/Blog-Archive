## 知识点 1：main 函数——程序从哪开始？

***
<br>

### 问题

<br>

你写了一个 `add` 函数，又写了一个 `main` 函数。程序跑起来，为什么先从 `main` 开始？`return 0` 又是给谁看的？

<br>

### 方案

<br>

`main()` 是程序的入口。操作系统启动程序时，会调用启动代码，启动代码再调用 `main()`。`main` 的返回值返回给操作系统，**0 表示成功**，非 0 通常表示出错。

C++ 标准支持两种 `main` 形式：

```cpp
int main()
int main(int argc, char* argv[])
```

**不要写 `void main()`**，C++ 标准不支持。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    std::cout << "Hello C++" << std::endl;
    return 0;
}
```

运行结果：

```text
Hello C++
```

<br>

### 一句话总结

<br>

**`main` 是程序入口，`return 0` 告诉操作系统“正常结束”。**

## 知识点 2：注释、预处理器和头文件——代码怎么组织？

***
<br>

### 问题

<br>

你看到别人代码开头写 `#include <iostream>`，还有 `//` 和 `/* */`。这些东西是干嘛的？为什么 C++ 用 `<iostream>` 而不是 `<iostream.h>`？

<br>

### 方案

<br>

- **注释**：`//` 单行注释，`/* */` 多行注释。给人和编译器看的，编译器会忽略。
- **预处理器**：`#include` 是预处理指令，在编译前把文件内容插入源文件。`#include <iostream>` 就是把标准输入输出头文件的内容插进来。
- **头文件命名**：
  - C++ 新式：`<iostream>`、`<cmath>`，**没有 `.h`**，使用 `std` 命名空间。
  - C 旧式：`<math.h>`，**有 `.h`**。

<br>

### 最小示例

<br>

```cpp
#include <iostream>   // C++ 新式头文件，无 .h
#include <cmath>      // 数学函数

int main() {
    // 单行注释
    /* 多行
       注释 */
    double x = 9.0;
    std::cout << std::sqrt(x) << std::endl;
    return 0;
}
```

运行结果：

```text
3
```

<br>

### 一句话总结

<br>

**`#include` 在编译前把头文件内容插进来；C++ 新式头文件无 `.h`，用 `std` 命名空间；C 旧式头文件有 `.h`。**

<br>

## 知识点 3：cout 和 cin——怎么输出、怎么输入？

***
<br>

### 问题

<br>

你想在屏幕上打印一句话，或者让用户输入两个数字。`cout` 和 `cin` 到底是什么？`<<` 和 `>>` 又是什么？

<br>

### 方案

<br>

- **`cout`**：`ostream` 类的对象，代表标准输出。`<<` 是插入运算符，把数据“插入”到输出流。
- **`cin`**：`istream` 类的对象，代表标准输入。`>>` 是提取运算符，从输入流“提取”数据。读取时会跳过前导空白（空格、换行、制表符）。

**注意**：`cout` 显示 `char` 变量时显示字符，显示 `int` 时显示数字。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int x;
    std::cout << "请输入一个数字: ";
    std::cin >> x;
    std::cout << "你输入的是: " << x << std::endl;

    char c = 'A';
    int n = 65;
    std::cout << "char: " << c << ", int: " << n << std::endl;
    return 0;
}
```

运行结果（假设输入 `42`）：

```text
请输入一个数字: 42
你输入的是: 42
char: A, int: 65
```

<br>

### 一句话总结

<br>

**`cout` 配 `<<` 输出，`cin` 配 `>>` 输入；`cout` 显示 `char` 是字符，显示 `int` 是数字。**

<br>

## 知识点 4：endl 和 \n 的区别——换行还要刷新？

***
<br>

### 问题

<br>

你有时候写 `std::endl`，有时候写 `"\n"`。它们都是换行，有什么区别？为什么有人说 `\n` 更快？

<br>

### 方案

<br>

- **`std::endl`**：换行**并刷新缓冲区**。刷新会强制把缓冲区内容写到屏幕或文件，有性能开销。
- **`"\n"`**：只换行，**不刷新**。通常更快。

如果你在调试，希望立刻看到输出，可以用 `std::endl`。如果只是普通换行，用 `"\n"`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    std::cout << "第一行" << std::endl;   // 换行并刷新
    std::cout << "第二行" << "\n";        // 只换行
    std::cout << "第三行" << std::endl;
    return 0;
}
```

运行结果：

```text
第一行
第二行
第三行
```

<br>

### 一句话总结

<br>

**`endl` 换行并刷新缓冲区，`\n` 只换行；普通换行用 `\n`，调试想立刻看到用 `endl`。**

<br>

## 知识点 5：函数三要素——原型、定义、调用

***
<br>

### 问题

<br>

你写了一个 `add` 函数，放在 `main` 后面。结果编译器报错：`'add' was not declared in this scope`。为什么？怎么办？

<br>

### 方案

<br>

C++ 要求**函数使用前必须要有声明**。函数三要素：

- **原型（声明）**：`double sqrt(double);` 告诉编译器函数名、参数类型、返回类型。
- **定义**：包含函数体，真正实现功能。
- **调用**：使用函数，必须带括号，即使无参数：`rand()`。

如果函数定义在调用之后，就必须在前面写原型。**无返回值函数用 `void`**，不能用在赋值表达式中。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int add(int a, int b);   // 函数原型

int main() {
    int x = 3, y = 4;
    std::cout << "sum = " << add(x, y) << std::endl;
    return 0;
}

int add(int a, int b) {  // 函数定义
    return a + b;
}
```

运行结果：

```text
sum = 7
```

**易错点**：函数调用必须带括号，即使无参数，比如 `rand()`。不要混淆原型和定义：原型只描述接口，定义包含代码。

<br>

### 一句话总结

<br>

**函数使用前要有原型，原型告诉编译器“长什么样”，定义告诉链接器“怎么实现”，调用必须带括号。**

<br>

## 知识点 6：命名空间——为什么是 std::cout？using 放哪？

***
<br>

### 问题

<br>

你写 `cout` 报错，必须写 `std::cout`。`std` 是什么？能不能写 `using namespace std;` 省事？为什么有人说别在头文件里写？

<br>

### 方案

<br>

`std` 是 C++ 标准库的命名空间。`cout`、`cin`、`endl` 都在 `std` 里。命名空间用来避免名字冲突。

- 可以写 `std::cout`，最明确。
- 可以在函数内写 `using namespace std;`，只影响这个函数。
- **尽量不要在头文件里写 `using namespace std;`**，因为头文件会被很多源文件包含，会污染所有包含者的命名空间。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    using namespace std;   // 只影响 main 函数内部
    cout << "Hello" << endl;
    return 0;
}
```

运行结果：

```text
Hello
```

<br>

### 一句话总结

<br>

**`std` 是标准库命名空间，`std::cout` 最安全；`using namespace std;` 尽量放函数内，别放头文件里。**

<br>

## 完整可运行代码
***

下面这个程序把本章知识点串了一遍：`main`、注释、`#include`、`cout`/`cin`、`endl`/`\n`、函数原型与定义、`using namespace std;` 放在函数内。

```cpp
#include <iostream>
#include <cmath>      // C++ 新式头文件，无 .h

// 函数原型
int add(int a, int b);
double square_root(double x);

int main() {
    using namespace std;   // 只影响 main 内部

    // 注释：单行
    /* 多行
       注释 */

    cout << "请输入两个整数: ";
    int x, y;
    cin >> x >> y;

    cout << "和: " << add(x, y) << "\n";          // 用 \n 换行
    cout << "平方根: " << square_root(x) << endl; // 用 endl 换行并刷新

    char c = 'A';
    int n = 65;
    cout << "char: " << c << ", int: " << n << endl;

    return 0;
}

// 函数定义
int add(int a, int b) {
    return a + b;
}

double square_root(double x) {
    return std::sqrt(x);
}
```

运行结果（假设输入 `9 16`）：

```text
请输入两个整数: 9 16
和: 25
平方根: 3
char: A, int: 65
```
