## 一句话概括
***
**一句话**：`main` 是程序入口；`cout/cin` 是流对象；函数使用前要有原型；命名空间用于避免名字冲突。

<br>

<br>


## 核心概念
***
- `main()` 由启动代码调用，返回值返回给操作系统，0 表示成功。
- 注释：`//` 单行，`/* */` 多行。
- 预处理器：`#include` 在编译前把文件内容插入源文件。
- 头文件命名：
  - C++ 新式：`<iostream>`、`<cmath>`，无 `.h`，使用 `std` 命名空间。
  - C 旧式：`<math.h>`，有 `.h`。
- `cout`：`ostream` 类对象，`<<` 插入运算符，可输出字符串、数字、字符。
- `cin`：`istream` 类对象，`>>` 提取运算符，读取时跳过前导空白。
- `endl`：换行并刷新缓冲区；`\n`：只换行，通常更快。
- 函数三要素：原型、定义、调用。
- 函数原型：`double sqrt(double);`，告诉编译器参数和返回类型。
- 函数定义：包含函数体。
- 参数是传给函数的信息，返回值是从函数返回的信息。
- `using namespace std;` 的位置：尽量放在函数内，或使用 `std::cout`，避免头文件污染。

<br>

<br>

## 最小代码
***
```cpp
#include <iostream>

int add(int a, int b); // 函数原型

int main() {
    using namespace std;
    int x = 3, y = 4;
    cout << "sum = " << add(x, y) << endl;
    return 0;
}

int add(int a, int b) { // 函数定义
    return a + b;
}
```

<br>

<br>

## 易错点
***
- 函数调用必须带括号，即使无参数：`rand()`。
- 无返回值函数用 `void`，不能用在赋值表达式中。
- 不要混淆函数原型和函数定义：原型只描述接口，定义包含代码。
- `using namespace std;` 写在头文件中会污染所有包含者。
- `cout` 显示 `char` 变量时显示字符，显示 `int` 时显示数字。

<br>

<br>

## 项目用途
***
- 每个项目都会拆成多个函数，原型和定义分离是基本能力。
- `cout/cin` 用于调试输出和简单交互；项目后期多用日志库。
