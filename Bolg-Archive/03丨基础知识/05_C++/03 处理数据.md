## 知识点 1：变量命名——名字能随便起吗？

***
<br>

### 问题

<br>

你写 `int __x = 1;` 或者 `int _X = 2;`，编译器可能不报错，但这是好习惯吗？变量名到底有什么规则？

<br>

### 方案

<br>

C++ 变量命名规则：

- 只能用字母、数字、下划线。
- 首字符不能是数字。
- 区分大小写。
- 不能用关键字（如 `int`、`return`）。
- **以 `__` 或 `_大写字母` 开头的标识符保留给实现**，别自己用。
- **以 `_` 开头的标识符保留给全局标识符**，也别乱用。

推荐用有含义的变量名，比如 `student_count` 而不是 `sc`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int student_count = 42;      // 合法，有意义
    int _local = 10;             // 合法，但下划线开头尽量少用
    // int 2fast = 1;            // 错误：首字符不能是数字
    // int __reserved = 1;       // 不推荐：双下划线保留给实现
    // int class = 5;            // 错误：class 是关键字

    std::cout << student_count << std::endl;
    std::cout << _local << std::endl;
    return 0;
}
```

运行结果：

```text
42
10
```

<br>

### 一句话总结

<br>

**变量名要合法、有意义，别碰保留标识符，别用关键字。**

## 知识点 2：整型家族——int 到底能存多大？

***
<br>

### 问题

<br>

你写 `int x = 10000000000;`，编译器警告溢出。`int` 到底能存多大？`unsigned` 又有什么坑？

<br>

### 方案

<br>

C++ 基本整型：`char`、`short`、`int`、`long`、`long long`（C++11）。宽度不是固定的：

- `short` 至少 16 位。
- `int` 至少和 `short` 一样长。
- `long` 至少 32 位。
- `long long` 至少 64 位。

`unsigned` 修饰后范围从 0 开始。用 `<climits>` 里的 `INT_MAX`、`SHRT_MAX` 等查看范围。`sizeof` 返回字节数。

**无符号溢出会回绕**（比如 `unsigned char` 255 + 1 变 0）。**有符号溢出是未定义行为（UB）**，不要依赖回绕。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <climits>

int main() {
    std::cout << "sizeof(int) = " << sizeof(int) << std::endl;
    std::cout << "INT_MAX = " << INT_MAX << std::endl;
    std::cout << "SHRT_MAX = " << SHRT_MAX << std::endl;

    unsigned char uc = 255;
    uc = uc + 1;   // 回绕到 0
    std::cout << "uc = " << static_cast<int>(uc) << std::endl;

    // int overflow = INT_MAX + 1;  // 未定义行为，别写
    return 0;
}
```

运行结果（常见 64 位平台）：

```text
sizeof(int) = 4
INT_MAX = 2147483647
SHRT_MAX = 32767
uc = 0
```

<br>

### 一句话总结

<br>

**整型宽度不固定，无符号溢出回绕，有符号溢出是 UB；跨平台要固定宽度就用 `<cstdint>` 的 `int32_t` 等。**

<br>

## 知识点 3：初始化——哪种写法更安全？

***
<br>

### 问题

<br>

你看到 `int a = 5;`、`int b(5);`、`int c{5};` 三种写法，它们有什么区别？哪种更安全？

<br>

### 方案

<br>

- `int a = 5;`：C 风格，可能发生窄化转换。
- `int b(5);`：直接初始化。
- `int c{5};`：C++11 列表初始化（统一初始化），**禁止窄化转换**，更安全。
- `int d = {5};`：也是列表初始化。
- `int e{};`：初始化为 0。

**列表初始化 `{}` 能防止窄化**，比如 `int x{3.14};` 会编译错误，而 `int x = 3.14;` 只会警告或截断。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int a = 5;
    int b(5);
    int c{5};
    int d = {5};
    int e{};

    std::cout << a << " " << b << " " << c << " " << d << " " << e << std::endl;

    // int bad{3.14};   // 错误：窄化转换，列表初始化不允许
    int ok = 3.14;      // 合法，但会截断为 3
    std::cout << ok << std::endl;

    return 0;
}
```

运行结果：

```text
5 5 5 5 0
3
```

<br>

### 一句话总结

<br>

**列表初始化 `{}` 更安全，能防止窄化转换；`int e{};` 直接初始化为 0。**

<br>

## 知识点 4：进制字面量——042 和 0x42 是什么？

***
<br>

### 问题

<br>

你写 `int a = 042;`，打印出来是 34，不是 42。为什么？`0x42` 又是什么？

<br>

### 方案

<br>

- 十进制：`42`
- 八进制：`042`（以 0 开头）
- 十六进制：`0x42`（以 0x 或 0X 开头）

输出时可以用 `std::dec`、`std::hex`、`std::oct` 控制格式。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int dec = 42;
    int oct = 042;    // 八进制，十进制 34
    int hex = 0x42;   // 十六进制，十进制 66

    std::cout << "dec = " << dec << std::endl;
    std::cout << "oct = " << oct << std::endl;
    std::cout << "hex = " << hex << std::endl;

    std::cout << std::hex << "hex format: " << hex << std::endl;
    std::cout << std::oct << "oct format: " << oct << std::endl;
    std::cout << std::dec << "back to dec: " << dec << std::endl;

    return 0;
}
```

运行结果：

```text
dec = 42
oct = 34
hex = 66
hex format: 42
oct format: 42
back to dec: 42
```

<br>

### 一句话总结

<br>

**0 开头是八进制，0x 开头是十六进制；用 `std::dec`、`std::hex`、`std::oct` 控制输出格式。**

<br>

## 知识点 5：char 和 bool——字符本质是小整数

***
<br>

### 问题

<br>

`char c = 'A';` 和 `char c = 65;` 有什么区别？`bool` 怎么转换？

<br>

### 方案

<br>

- `char` 通常存字符，本质是小整数。`'A'` 是字符常量，`"A"` 是字符串。
- `bool` 只有 `true` 和 `false`，非零转 `true`，零转 `false`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    char c1 = 'A';
    char c2 = 65;
    std::cout << "c1 = " << c1 << ", c2 = " << c2 << std::endl;
    std::cout << "c1 as int = " << static_cast<int>(c1) << std::endl;

    bool b1 = true;
    bool b2 = false;
    bool b3 = 42;    // 非零转 true
    bool b4 = 0;     // 零转 false

    std::cout << std::boolalpha;
    std::cout << "b1 = " << b1 << ", b2 = " << b2
              << ", b3 = " << b3 << ", b4 = " << b4 << std::endl;

    return 0;
}
```

运行结果：

```text
c1 = A, c2 = A
c1 as int = 65
b1 = true, b2 = false, b3 = true, b4 = false
```

<br>

### 一句话总结

<br>

**`char` 本质是小整数，`'A'` 和 65 在 `char` 里是一回事；`bool` 非零即真。**

<br>

## 知识点 6：const——为什么比 #define 好？

***
<br>

### 问题

<br>

你写 `const int Months;` 然后 `Months = 12;`，编译器报错。为什么？`const` 和 `#define` 哪个好？

<br>

### 方案

<br>

`const` 必须在声明时初始化。它比 `#define` 更好：有类型、有作用域、可用于复杂类型。`#define` 只是文本替换，容易出问题。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

const int Months = 12;   // 全局常量

int main() {
    // const int toes;       // 错误：const 必须初始化
    // toes = 10;

    const double Pi = 3.14159;
    std::cout << "Months = " << Months << std::endl;
    std::cout << "Pi = " << Pi << std::endl;

    return 0;
}
```

运行结果：

```text
Months = 12
Pi = 3.14159
```

<br>

### 一句话总结

<br>

**`const` 必须在声明时初始化，有类型、有作用域，比 `#define` 更安全。**

<br>

## 知识点 7：浮点——为什么 0.1 + 0.2 != 0.3？

***
<br>

### 问题

<br>

你写 `if (0.1 + 0.2 == 0.3)`，结果是 `false`。为什么？`float`、`double`、`long double` 怎么选？

<br>

### 方案

<br>

浮点类型有精度限制，大数加小数可能丢失，小数比较不要直接用 `==`，用误差范围。默认浮点常量是 `double`；`f` 后缀表示 `float`，`L` 后缀表示 `long double`。科学计数法：`3.45e6`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <cmath>

int main() {
    double a = 0.1;
    double b = 0.2;
    double c = 0.3;

    std::cout << std::boolalpha;
    std::cout << "0.1 + 0.2 == 0.3: " << (a + b == c) << std::endl;

    double eps = 1e-9;
    std::cout << "fabs((a+b)-c) < eps: " << (std::fabs((a + b) - c) < eps) << std::endl;

    float f = 3.14f;
    long double ld = 3.14L;
    std::cout << "float: " << f << ", long double: " << ld << std::endl;

    return 0;
}
```

运行结果：

```text
0.1 + 0.2 == 0.3: false
fabs((a+b)-c) < eps: true
float: 3.14, long double: 3.14
```

<br>

### 一句话总结

<br>

**浮点有精度限制，不要直接用 `==` 比较，用误差范围；默认浮点常量是 `double`，后缀 `f` 是 `float`，`L` 是 `long double`。**

<br>

## 知识点 8：运算符与类型转换——9 / 5 为什么是 1？

***
<br>

### 问题

<br>

`9 / 5` 结果是 1，不是 1.8。`9.0 / 5` 才是 1.8。混合类型怎么转换？强制转换怎么写？

<br>

### 方案

<br>

- 整数除法丢弃小数：`9 / 5 == 1`。
- 至少一个浮点操作数时，结果为浮点：`9.0 / 5 == 1.8`。
- 类型转换规则：有 `long double` 转 `long double`；否则有 `double` 转 `double`；否则有 `float` 转 `float`；否则整型提升，再按级别转换。
- 强制转换：`(int)3.14`、`int(3.14)`，推荐 `static_cast<int>(3.14)`。
- **强制转换不会改变原变量，只产生新值。**

**易错点**：`int *p1, p2;` 中只有 `p1` 是指针，`p2` 是 `int`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int a = 9, b = 5;
    std::cout << "9 / 5 = " << a / b << std::endl;
    std::cout << "9.0 / 5 = " << 9.0 / b << std::endl;

    double d = 3.99;
    int i1 = (int)d;
    int i2 = int(d);
    int i3 = static_cast<int>(d);
    std::cout << "i1 = " << i1 << ", i2 = " << i2 << ", i3 = " << i3 << std::endl;
    std::cout << "d still = " << d << std::endl;   // 原变量不变

    int *p1, p2;   // p1 是指针，p2 是 int
    p1 = &a;
    p2 = 10;
    std::cout << "*p1 = " << *p1 << ", p2 = " << p2 << std::endl;

    return 0;
}
```

运行结果：

```text
9 / 5 = 1
9.0 / 5 = 1.8
i1 = 3, i2 = 3, i3 = 3
d still = 3.99
*p1 = 9, p2 = 10
```

<br>

### 一句话总结

<br>

**整数除法丢小数，混合类型按规则提升；强制转换推荐 `static_cast`，不改变原变量；`int *p1, p2;` 只有 `p1` 是指针。**

<br>

## 知识点 9：auto——让编译器推导类型

***
<br>

### 问题

<br>

你写 `std::vector<int>::iterator it = v.begin();` 太长了。有没有办法让编译器自己推导类型？

<br>

### 方案

<br>

用 **`auto`**（C++11）。它从初始化表达式推导类型。比如 `auto d = 3.14;` 推导为 `double`。**不要滥用**，类型不明显时写清楚更好。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <vector>

int main() {
    auto d = 3.14;          // double
    auto i = 42;            // int
    auto c = 'A';           // char

    std::cout << "d = " << d << ", i = " << i << ", c = " << c << std::endl;

    std::vector<int> v = {1, 2, 3};
    for (auto it = v.begin(); it != v.end(); ++it) {
        std::cout << *it << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

运行结果：

```text
d = 3.14, i = 42, c = A
1 2 3 
```

<br>

### 一句话总结

<br>

**`auto` 让编译器从初始化表达式推导类型，简化长类型书写，但别滥用，类型不明显时写清楚更好。**

<br>

## 完整可运行代码
***

下面把本章知识点串一遍：变量命名、整型、初始化、进制、`char`/`bool`、`const`、浮点、类型转换、`auto`。

```cpp
#include <iostream>
#include <climits>
#include <cmath>

const int Months = 12;   // const 常量

int main() {
    using namespace std;

    // 变量命名与整型
    int student_count = 42;
    unsigned char uc = 255;
    uc = uc + 1;   // 回绕到 0
    cout << "student_count = " << student_count << endl;
    cout << "uc after +1 = " << static_cast<int>(uc) << endl;
    cout << "INT_MAX = " << INT_MAX << endl;

    // 初始化
    int a = 5;
    int b(5);
    int c{5};
    int e{};
    cout << "a=" << a << ", b=" << b << ", c=" << c << ", e=" << e << endl;

    // 进制
    int oct = 042;
    int hex = 0x42;
    cout << "oct = " << oct << ", hex = " << hex << endl;
    cout << hex << "hex format: " << hex << dec << endl;

    // char 和 bool
    char ch = 'A';
    bool flag = 42;
    cout << "ch = " << ch << ", flag = " << boolalpha << flag << noboolalpha << endl;

    // const
    cout << "Months = " << Months << endl;

    // 浮点
    double x = 0.1, y = 0.2, z = 0.3;
    cout << "0.1 + 0.2 == 0.3: " << boolalpha << (x + y == z) << noboolalpha << endl;
    cout << "fabs((x+y)-z) < 1e-9: " << boolalpha << (fabs((x + y) - z) < 1e-9) << noboolalpha << endl;

    // 类型转换
    int i1 = 9, i2 = 5;
    cout << "9 / 5 = " << i1 / i2 << endl;
    cout << "9.0 / 5 = " << 9.0 / i2 << endl;
    double d = 3.99;
    int i3 = static_cast<int>(d);
    cout << "static_cast<int>(3.99) = " << i3 << ", d still = " << d << endl;

    // auto
    auto ad = 3.14;
    auto ai = 42;
    cout << "auto ad = " << ad << ", auto ai = " << ai << endl;

    return 0;
}
```

运行结果示例：

```text
student_count = 42
uc after +1 = 0
INT_MAX = 2147483647
a=5, b=5, c=5, e=0
oct = 34, hex = 66
hex format: 42
ch = A, flag = true
Months = 12
0.1 + 0.2 == 0.3: false
fabs((x+y)-z) < 1e-9: true
9 / 5 = 1
9.0 / 5 = 1.8
static_cast<int>(3.99) = 3, d still = 3.99
auto ad = 3.14, auto ai = 42
```
