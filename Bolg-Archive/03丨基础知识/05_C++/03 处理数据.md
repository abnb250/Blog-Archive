## 一句话概括
***
**一句话**：C++ 提供多种整型和浮点类型；`const` 定义常量；类型转换规则决定表达式结果；`auto` 让编译器推导类型。

<br>

<br>

## 核心概念
***
### 变量与命名
- 命名规则：字母、数字、下划线；首字符不能是数字；区分大小写；不能用关键字。
- 以 `__` 或 `_大写字母` 开头保留给实现；以 `_` 开头保留给全局标识符。
- 推荐有含义的变量名。

<br>

### 整型
- 基本整型：`char`、`short`、`int`、`long`、`long long`（C++11）。
- 宽度：`short` 至少 16 位，`int` 至少与 `short` 一样长，`long` 至少 32 位，`long long` 至少 64 位。
- 无符号：`unsigned` 修饰，范围从 0 开始。
- `sizeof` 返回类型或变量的字节数。
- `<climits>` 定义 `INT_MAX`、`SHRT_MAX` 等符号常量。
- 无符号溢出会回绕；有符号溢出是未定义行为（UB）。

<br>

### 初始化
```cpp
int a = 5;      // C 风格
int b(5);       // 直接初始化
int c{5};       // C++11 统一初始化
int d = {5};    // C++11
int e{};        // 初始化为 0
```

<br>

### 进制字面量
- 十进制：`42`
- 八进制：`042`
- 十六进制：`0x42`
- 输出格式控制：`std::dec`、`std::hex`、`std::oct`。

<br>

### `char` 与 `bool`
- `char` 通常存字符，本质是小整数；`'A'` 是字符常量，`"A"` 是字符串。
- `bool`：`true`/`false`，非零转 `true`，零转 `false`。

<br>

### `const`
```cpp
const int Months = 12;
```
- 必须在声明时初始化。
- 比 `#define` 更好：有类型、有作用域、可用于复杂类型。

<br>

### 浮点
- `float`、`double`、`long double`。
- 默认浮点常量是 `double`；`f` 后缀表示 `float`，`L` 后缀表示 `long double`。
- 浮点有精度限制，大数加小数可能丢失。
- 科学计数法：`3.45e6`。

<br>

### 运算符与类型转换
- 算术运算符：`+ - * / %`。
- 整数除法丢弃小数：`9 / 5 == 1`。
- 至少一个浮点操作数时，结果为浮点：`9.0 / 5 == 1.8`。
- 类型转换规则：
  1. 有 `long double` → 转 `long double`
  2. 否则有 `double` → 转 `double`
  3. 否则有 `float` → 转 `float`
  4. 否则整型提升，再按级别转换。
- 强制类型转换：
```cpp
(int) 3.14;          // C 风格
int(3.14);           // C++ 函数风格
static_cast<int>(3.14); // 推荐
```
- `auto`：C++11 让编译器从初始化表达式推导类型。

<br>

<br>

## 最小代码
***
```cpp
#include <iostream>
#include <climits>

int main() {
    using namespace std;
    const int Months = 12;
    int a = 042;      // 八进制，十进制 34
    int b = 0x42;     // 十六进制，十进制 66
    double c = 9.0 / 5;
    auto d = 3.14;    // double

    cout << "Months=" << Months << endl;
    cout << "a=" << a << ", b=" << b << ", c=" << c << endl;
    cout << "INT_MAX=" << INT_MAX << endl;
    return 0;
}
```

<br>

<br>

## 易错点
***
- `const int toes; toes = 10;` 错误：`const` 必须初始化。
- 有符号整型溢出是 UB，不要依赖回绕。
- 浮点比较不要直接用 `==`，用误差范围。
- `int *p1, p2;` 中只有 `p1` 是指针，`p2` 是 `int`。
- 强制类型转换不会改变原变量，只产生新值。

<br>

<br>

## 项目用途
***
- 用 `const` 或 `constexpr` 定义常量。
- 用 `auto` 简化类型书写，但不要滥用。
- 注意整型宽度，跨平台时用 `<cstdint>` 的 `int32_t` 等。
