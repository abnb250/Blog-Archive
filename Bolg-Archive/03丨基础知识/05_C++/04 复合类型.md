## 一句话概括
***
**一句话**：数组、字符串、结构、指针、`new/delete` 是 C++ 复合类型基础；现代项目优先用 `std::string`、`std::vector`、`std::array`、智能指针。

<br>

<br>

## 核心概念
***
### 数组
- 存储多个同类型值，内存连续。
- 声明：`int a[10];`
- 索引从 0 开始，编译器不检查越界。
- 初始化：
```cpp
int a[3] = {1, 2, 3};
int b[5] = {1, 2};   // 其余为 0
int c[] = {1, 2, 3}; // 编译器计算长度
```
- C++11：可省略 `=`：`int d[3]{1,2,3};`
- 数组名在多数表达式中是首元素地址。
- `sizeof(数组名)` 得到整个数组字节数。

<br>

### C 风格字符串
- `char` 数组，以 `'\0'` 结尾。
- 字符串字面量：`"hello"`，末尾自动加 `'\0'`。
- `strlen()` 返回可见字符数，不含 `'\0'`。
- `strcpy()`、`strcat()` 可能越界，不安全；可用 `strncpy()`、`strncat()`，但仍需小心。
- `cin >> name` 只读一个单词；`cin.getline(name, size)` 读一行并丢弃换行；`cin.get(name, size)` 读一行但保留换行。

<br>

### `std::string`
- 头文件 `<string>`，位于 `std`。
- 可赋值、拼接、自动管理内存。
```cpp
#include <string>
std::string s1 = "hello";
std::string s2 = "world";
std::string s3 = s1 + " " + s2;
s1 += "!";
```
- 读取一行：`getline(cin, str);`
- 长度：`str.size()`。

<br>

### 结构
```cpp
struct inflatable {
    char name[20];
    float volume;
    double price;
};

inflatable guest = {"Gloria", 1.88, 29.99};
inflatable pal {"Arthur", 3.12, 32.99}; // C++11
```
- 成员访问：`guest.name`、`guest.price`。
- 同类型结构可以整体赋值。
- 结构数组：`inflatable gifts[100];`
- 结构可包含 `std::string` 成员，但需确保包含 `<string>`。

<br>

### 共用体 `union`
- 同一内存可存储不同类型，但一次只能用一种。
- 常用于节省内存或底层数据结构。
```cpp
union one4all {
    int int_val;
    long long_val;
    double double_val;
};
```

<br>

### 枚举 `enum`
```cpp
enum spectrum { red, orange, yellow, green, blue };
spectrum band = blue;
```
- 默认从 0 开始递增。
- 可显式赋值：`enum bits { one = 1, two = 2, four = 4 };`
- 枚举量可提升为 `int`，但 `int` 不能自动转枚举。
- C++11 推荐 `enum class`，作用域更强、更安全。

<br>

### 指针
- 指针存储地址：`int *p = &a;`
- `*` 解除引用，取得地址处的值。
- `&` 取地址。
- 指针声明：`int *p1, *p2;` 每个都要 `*`。
- 未初始化指针危险，解引用前必须指向有效地址。
- 空指针：`nullptr`（C++11），不要用 `0` 或 `NULL` 表示指针。

<br>

### `new` 和 `delete`
```cpp
int *p = new int;       // 分配一个 int
*p = 10;
delete p;               // 释放

int *arr = new int[10]; // 动态数组
delete[] arr;           // 释放数组
```
- `new` 从堆/自由存储区分配。
- `delete` 释放 `new` 分配的内存。
- `new[]` 配 `delete[]`；`new` 配 `delete`。
- 不要重复释放；不要释放非 `new` 内存；空指针 `delete` 安全。
- 现代 C++ 优先用智能指针（`unique_ptr`、`shared_ptr`）避免手动 `delete`。

<br>

### 指针算术与数组
- 指针加 1，增加的是指向类型的大小。
- 数组名可当作首元素地址。
- `a[i]` 等价于 `*(a + i)`。
- 数组名是常量，不能 `a = a + 1`；指针可以。
- `sizeof(数组名)` 是整个数组大小；`sizeof(指针)` 是指针大小。

<br>

### 动态结构
```cpp
inflatable *ps = new inflatable;
ps->price = 29.99;      // 箭头运算符
(*ps).volume = 1.88;    // 点运算符
delete ps;
```

<br>

### 存储方式
- 自动存储：函数内局部变量，栈，函数结束销毁。
- 静态存储：全局变量、`static` 变量，程序整个生命周期。
- 动态存储：`new` 分配，堆/自由存储区，手动释放或智能指针管理。

<br>

### `vector` 和 `array`
```cpp
#include <vector>
#include <array>

std::vector<int> vi;      // 动态数组，可增长
std::vector<double> vd(n); // n 个元素

std::array<int, 5> ai;    // 固定长度，栈上，C++11
std::array<double, 4> ad = {1.2, 2.1, 3.4, 4.3};
```
- `vector` 在堆上，自动管理内存。
- `array` 在栈上，长度固定，可整体赋值。
- 两者都可用 `at()` 进行越界检查。
- 现代项目优先 `vector`，固定长度可用 `array`。

<br>

<br>

## 最小代码
***
```cpp
#include <iostream>
#include <string>
#include <vector>
#include <array>

struct Person {
    std::string name;
    int age;
};

int main() {
    // 数组
    int a[3] = {1, 2, 3};

    // C 风格字符串
    char name[10] = "Tom";
    std::cout << name << ", len=" << strlen(name) << std::endl;

    // string
    std::string s = "hello";
    s += " world";
    std::cout << s << std::endl;

    // 结构
    Person p = {"Alice", 20};
    std::cout << p.name << " " << p.age << std::endl;

    // 指针与 new
    int *pi = new int(42);
    std::cout << *pi << std::endl;
    delete pi;

    // 动态数组
    int *arr = new int[5]{1,2,3,4,5};
    std::cout << arr[2] << std::endl;
    delete[] arr;

    // vector
    std::vector<int> v = {1, 2, 3};
    v.push_back(4);
    std::cout << v[3] << std::endl;

    // array
    std::array<int, 3> ar = {7, 8, 9};
    std::cout << ar[1] << std::endl;

    return 0;
}
```

## 易错点
***
- 数组越界不报错，可能破坏数据或崩溃。
- `char name[5] = "hello";` 长度不够，忘记 `'\0'`。
- `cin >> charArray` 只读一个单词；读整行用 `cin.getline()`。
- `strcpy`、`strcat` 可能越界，优先 `std::string`。
- `delete` 与 `delete[]` 不匹配是 UB。
- 返回局部数组的指针是悬空指针。
- `int *p; *p = 5;` 未初始化就解引用，UB。
- 指针算术只在同一数组内有意义。

<br>

<br>

## 项目用途
***
- 用 `std::string` 代替 `char[]`。
- 用 `std::vector` 代替动态数组。
- 用 `std::array` 表示固定长度数组。
- 用智能指针代替裸 `new/delete`。
- 用 `enum class` 代替普通 `enum`。
- 用结构/类组织相关数据。
