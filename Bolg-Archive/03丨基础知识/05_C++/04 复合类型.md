## 知识点 1：数组——连续存储多个同类型值

***
<br>

### 问题

<br>

你想存 10 个整数，难道定义 `a0, a1, ..., a9`？有没有更简单的办法？

<br>

### 方案

<br>

用**数组**：`int a[10];`。数组在内存中连续存放，索引从 0 开始。**编译器不检查越界**，`a[100]` 可能破坏其他数据或崩溃。

初始化方式：

```cpp
int a[3] = {1, 2, 3};
int b[5] = {1, 2};    // 其余为 0
int c[] = {1, 2, 3};  // 编译器计算长度
int d[3]{1, 2, 3};    // C++11，可省略 =
```

**数组名在多数表达式中是首元素地址**，但 `sizeof(数组名)` 得到整个数组字节数。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int a[3] = {1, 2, 3};
    int b[5] = {1, 2};    // 其余为 0
    int c[] = {1, 2, 3, 4}; // 长度为 4

    std::cout << "a: ";
    for (int i = 0; i < 3; ++i) std::cout << a[i] << " ";
    std::cout << std::endl;

    std::cout << "b: ";
    for (int i = 0; i < 5; ++i) std::cout << b[i] << " ";
    std::cout << std::endl;

    std::cout << "sizeof(a) = " << sizeof(a) << std::endl;   // 12
    std::cout << "sizeof(c) = " << sizeof(c) << std::endl;   // 16

    // a[100] 越界，不报错但危险
    return 0;
}
```

运行结果：

```text
a: 1 2 3 
b: 1 2 0 0 0 
sizeof(a) = 12
sizeof(c) = 16
```

<br>

### 一句话总结

<br>

**数组就是连续存放的同类型值，索引从 0 开始，越界不报错，`sizeof(数组名)` 是整个数组大小。**

<br>

### 自测

<br>

## 知识点 2：C 风格字符串——'\0' 结尾的 char 数组

***
<br>

### 问题

<br>

你写 `char name[5] = "hello";`，长度不够，忘了 `'\0'`。`strlen` 和 `sizeof` 有什么区别？`cin >> name` 为什么只读一个单词？

<br>

### 方案

<br>

C 风格字符串是**以 `'\0'` 结尾的 char 数组**。字符串字面量 `"hello"` 末尾自动加 `'\0'`。

- `strlen()` 返回可见字符数，**不含 `'\0'`**。
- `strcpy()`、`strcat()` 可能越界，不安全；可用 `strncpy()`、`strncat()`，但仍需小心。
- `cin >> name` 只读一个单词；`cin.getline(name, size)` 读一行并丢弃换行；`cin.get(name, size)` 读一行但保留换行。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <cstring>

int main() {
    char name[10] = "Tom";
    std::cout << "name = " << name << std::endl;
    std::cout << "strlen(name) = " << std::strlen(name) << std::endl;   // 3
    std::cout << "sizeof(name) = " << sizeof(name) << std::endl;        // 10

    char buf[20];
    std::cout << "输入一行: ";
    std::cin.getline(buf, 20);   // 读一行，丢弃换行
    std::cout << "你输入: " << buf << std::endl;

    return 0;
}
```

运行结果（假设输入 `hello world`）：

```text
name = Tom
strlen(name) = 3
sizeof(name) = 10
输入一行: hello world
你输入: hello world
```

**易错点**：`char name[5] = "hello";` 长度不够，没有空间放 `'\0'`，是错误。`strcpy`、`strcat` 可能越界，优先用 `std::string`。

<br>

### 一句话总结

<br>

**C 风格字符串是以 `'\0'` 结尾的 char 数组，`strlen` 不算 `'\0'`，`sizeof` 算整个数组；读整行用 `cin.getline`。**

<br>

### 自测

<br>

## 知识点 3：std::string——别再手写 char[] 了

***
<br>

### 问题

<br>

C 风格字符串拼接怕越界，读整行还要小心换行符。有没有更省心的字符串类型？

<br>

### 方案

<br>

用 **`std::string`**。它自动管理内存，支持赋值、拼接、`+=`，读整行用 `getline(cin, str)`，长度用 `str.size()`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s1 = "hello";
    std::string s2 = "world";
    std::string s3 = s1 + " " + s2;
    s1 += "!";

    std::cout << "s3 = " << s3 << std::endl;
    std::cout << "s1 = " << s1 << std::endl;
    std::cout << "s3.size() = " << s3.size() << std::endl;

    std::string line;
    std::cout << "输入一行: ";
    std::getline(std::cin, line);
    std::cout << "你输入: " << line << std::endl;

    return 0;
}
```

运行结果（假设输入 `hello c++`）：

```text
s3 = hello world
s1 = hello!
s3.size() = 11
输入一行: hello c++
你输入: hello c++
```

<br>

### 一句话总结

<br>

**`std::string` 自动管理内存，拼接、赋值、读整行都方便，现代 C++ 优先用它，别手写 `char[]`。**

<br>

## 知识点 4：结构——把相关数据打包

***
<br>

### 问题

<br>

你想存一个人的姓名、年龄、价格，用三个独立变量太散。能不能打包成一个整体？

<br>

### 方案

<br>

用**结构 `struct`**。它把多个不同类型的数据打包在一起。成员访问用 `.`，同类型结构可以整体赋值。结构数组、结构里放 `std::string` 都可以。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <string>

struct Person {
    std::string name;
    int age;
    double height;
};

int main() {
    Person p1 = {"Alice", 20, 1.65};
    Person p2{"Bob", 22, 1.80};   // C++11

    std::cout << p1.name << ", " << p1.age << ", " << p1.height << std::endl;
    std::cout << p2.name << ", " << p2.age << ", " << p2.height << std::endl;

    Person p3 = p1;   // 整体赋值
    std::cout << "p3: " << p3.name << std::endl;

    Person people[2] = {p1, p2};
    for (const auto& p : people) {
        std::cout << p.name << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

运行结果：

```text
Alice, 20, 1.65
Bob, 22, 1.8
p3: Alice
Alice Bob 
```

<br>

### 一句话总结

<br>

**结构就是把相关数据打包成一个整体，用 `.` 访问成员，同类型结构可以整体赋值。**

<br>

## 知识点 5：共用体 union——同一内存存不同类型

***
<br>

### 问题

<br>

你想让一块内存有时存 `int`，有时存 `double`，节省空间。怎么办？

<br>

### 方案

<br>

用**共用体 `union`**。同一内存可存储不同类型，但**一次只能用一种**。常用于节省内存或底层数据结构。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

union One4All {
    int int_val;
    long long_val;
    double double_val;
};

int main() {
    One4All u;
    u.int_val = 42;
    std::cout << "int_val = " << u.int_val << std::endl;

    u.double_val = 3.14;
    std::cout << "double_val = " << u.double_val << std::endl;
    // 此时 int_val 已被覆盖，读它没有意义

    std::cout << "sizeof(One4All) = " << sizeof(One4All) << std::endl;
    return 0;
}
```

运行结果（常见平台）：

```text
int_val = 42
double_val = 3.14
sizeof(One4All) = 8
```

<br>

### 一句话总结

<br>

**`union` 让同一块内存可以存不同类型，但一次只能用一种，写了一个就覆盖了另一个。**

<br>

## 知识点 6：枚举 enum 与 enum class

***
<br>

### 问题

<br>

你想表示红、橙、黄、绿、蓝，用 `int` 容易搞混。有没有更清晰的类型？

<br>

### 方案

<br>

用**枚举 `enum`**。默认从 0 开始递增，可显式赋值。枚举量可提升为 `int`，但 `int` 不能自动转枚举。**C++11 推荐 `enum class`**，作用域更强、更安全。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

enum Spectrum { red, orange, yellow, green, blue };

enum class Color { Red, Green, Blue };

int main() {
    Spectrum band = blue;
    std::cout << "band = " << band << std::endl;   // 4

    Color c = Color::Red;
    if (c == Color::Red) {
        std::cout << "Color is Red" << std::endl;
    }

    // int x = Color::Red;   // 错误：enum class 不能隐式转 int
    int y = red;             // 普通 enum 可以隐式转 int
    std::cout << "y = " << y << std::endl;

    return 0;
}
```

运行结果：

```text
band = 4
Color is Red
y = 0
```

<br>

### 一句话总结

<br>

**`enum` 默认从 0 递增，普通 `enum` 能隐式转 `int`；`enum class` 更安全，必须写 `Color::Red`，不能隐式转 `int`。**

<br>

<br>

## 知识点 7：指针——存储地址的变量

***
<br>

### 问题

<br>

你想直接操作内存地址，或者让函数修改外部变量。怎么办？

<br>

### 方案

<br>

用**指针**。指针存储地址：`int *p = &a;`。`*` 解除引用，`&` 取地址。

**易错点**：

- `int *p1, *p2;` 每个都要 `*`，`int *p1, p2;` 中 `p2` 是 `int`。
- 未初始化指针危险，解引用前必须指向有效地址。
- 空指针用 `nullptr`（C++11），不要用 `0` 或 `NULL`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int a = 42;
    int *p = &a;          // p 指向 a
    std::cout << "*p = " << *p << std::endl;
    *p = 100;             // 通过指针修改 a
    std::cout << "a = " << a << std::endl;

    int *p1, *p2;         // 两个都是指针
    int *p3, p4;          // p3 是指针，p4 是 int
    p1 = &a;
    p2 = nullptr;         // 空指针
    p3 = &a;
    p4 = 10;
    std::cout << "*p1 = " << *p1 << ", p4 = " << p4 << std::endl;

    return 0;
}
```

运行结果：

```text
*p = 42
a = 100
*p1 = 100, p4 = 10
```

<br>

### 一句话总结

<br>

**指针存地址，`*` 取值，`&` 取地址；声明时每个变量都要 `*`，空指针用 `nullptr`。**

<br>

### 自测

<br>

## 知识点 8：new 和 delete——动态分配内存

***
<br>

### 问题

<br>

你想在运行时决定数组大小，栈上数组做不到。怎么办？

<br>

### 方案

<br>

用 **`new`** 从堆/自由存储区分配内存，用 **`delete`** 释放。

- `new` 配 `delete`。
- `new[]` 配 `delete[]`。
- 不要重复释放；不要释放非 `new` 内存；空指针 `delete` 安全。
- 现代 C++ 优先用智能指针（`unique_ptr`、`shared_ptr`）避免手动 `delete`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int *p = new int;       // 分配一个 int
    *p = 10;
    std::cout << "*p = " << *p << std::endl;
    delete p;               // 释放

    int *arr = new int[10]; // 动态数组
    for (int i = 0; i < 10; ++i) arr[i] = i;
    std::cout << "arr[5] = " << arr[5] << std::endl;
    delete[] arr;           // 释放数组

    // delete p;            // 错误：重复释放
    // delete[] p;          // 错误：配对错误

    return 0;
}
```

运行结果：

```text
*p = 10
arr[5] = 5
```

<br>

### 一句话总结

<br>

**`new` 分配，`delete` 释放；`new[]` 配 `delete[]`，别重复释放，现代 C++ 优先用智能指针。**

<br>

## 知识点 9：指针算术与数组——a[i] 等价于 *(a + i)

***
<br>

### 问题

<br>

你看到 `*(a + i)` 和 `a[i]`，它们是一回事吗？指针加 1 加的是什么？

<br>

### 方案

<br>

**指针加 1，增加的是指向类型的大小。** 数组名可当作首元素地址。`a[i]` 等价于 `*(a + i)`。

- 数组名是常量，不能 `a = a + 1`；指针可以。
- `sizeof(数组名)` 是整个数组大小；`sizeof(指针)` 是指针大小。
- 指针算术只在同一数组内有意义。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int a[5] = {10, 20, 30, 40, 50};
    int *p = a;   // 指向首元素

    std::cout << "a[2] = " << a[2] << std::endl;
    std::cout << "*(a + 2) = " << *(a + 2) << std::endl;
    std::cout << "*(p + 2) = " << *(p + 2) << std::endl;

    std::cout << "sizeof(a) = " << sizeof(a) << std::endl;   // 20
    std::cout << "sizeof(p) = " << sizeof(p) << std::endl;   // 8（常见平台）

    ++p;
    std::cout << "*p after ++ = " << *p << std::endl;   // 20

    return 0;
}
```

运行结果（常见 64 位平台）：

```text
a[2] = 30
*(a + 2) = 30
*(p + 2) = 30
sizeof(a) = 20
sizeof(p) = 8
*p after ++ = 20
```

<br>

### 一句话总结

<br>

**`a[i]` 等价于 `*(a + i)`；指针加 1 增加一个元素大小；数组名不能改，指针可以。**

<br>

## 知识点 10：动态结构——用 new 创建结构

***
<br>

### 问题

<br>

你想在运行时动态创建一个结构对象，用 `.` 还是 `->`？

<br>

### 方案

<br>

用 `new` 创建结构，访问成员用 `->`，或者 `(*ps).price`。释放用 `delete`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <string>

struct Person {
    std::string name;
    int age;
};

int main() {
    Person *ps = new Person{"Alice", 20};

    std::cout << "ps->name = " << ps->name << std::endl;      // 箭头运算符
    std::cout << "(*ps).age = " << (*ps).age << std::endl;    // 点运算符

    delete ps;
    return 0;
}
```

运行结果：

```text
ps->name = Alice
(*ps).age = 20
```

<br>

### 一句话总结

<br>

**动态结构用 `new` 创建，成员访问用 `->` 或 `(*ps).`，释放用 `delete`。**

<br>

## 知识点 11：存储方式——自动、静态、动态

***
<br>

### 问题

<br>

局部变量、全局变量、`new` 出来的内存，它们分别存在哪？什么时候销毁？

<br>

### 方案

<br>

- **自动存储**：函数内局部变量，栈，函数结束销毁。
- **静态存储**：全局变量、`static` 变量，程序整个生命周期。
- **动态存储**：`new` 分配，堆/自由存储区，手动释放或智能指针管理。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int global_var = 100;          // 静态存储

void func() {
    int local_var = 10;        // 自动存储
    static int static_var = 20; // 静态存储
    std::cout << "local = " << local_var
              << ", static = " << static_var << std::endl;
    ++static_var;
}

int main() {
    func();
    func();
    func();

    int *p = new int(42);      // 动态存储
    std::cout << "dynamic = " << *p << std::endl;
    delete p;

    return 0;
}
```

运行结果：

```text
local = 10, static = 20
local = 10, static = 21
local = 10, static = 22
dynamic = 42
```

<br>

### 一句话总结

<br>

**自动存储随函数结束销毁，静态存储活到程序结束，动态存储手动管理或交给智能指针。**

<br>

## 知识点 12：vector 和 array——现代 C++ 的数组

***
<br>

### 问题

<br>

数组越界不报错，动态数组还要手动 `delete[]`。有没有更安全的数组？

<br>

### 方案

<br>

用 **`std::vector`**（动态数组，可增长）和 **`std::array`**（固定长度，栈上）。两者都可用 `at()` 进行越界检查。

- `vector` 在堆上，自动管理内存。
- `array` 在栈上，长度固定，可整体赋值。
- 现代项目优先 `vector`，固定长度可用 `array`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <vector>
#include <array>

int main() {
    std::vector<int> v = {1, 2, 3};
    v.push_back(4);
    std::cout << "v[3] = " << v[3] << std::endl;
    std::cout << "v.at(3) = " << v.at(3) << std::endl;

    std::array<int, 3> a = {7, 8, 9};
    std::cout << "a[1] = " << a[1] << std::endl;
    std::cout << "a.at(1) = " << a.at(1) << std::endl;

    // v.at(100) 会抛异常；v[100] 不检查
    return 0;
}
```

运行结果：

```text
v[3] = 4
v.at(3) = 4
a[1] = 8
a.at(1) = 8
```

<br>

### 一句话总结

<br>

**`vector` 是可增长的动态数组，`array` 是固定长度数组；两者都比裸数组安全，优先用它们。**

## 完整可运行代码
***

下面把本章知识点串一遍：数组、C 风格字符串、`std::string`、结构、`enum class`、指针、`new/delete`、指针算术、动态结构、`vector`、`array`。

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <array>
#include <cstring>

struct Person {
    std::string name;
    int age;
};

enum class Color { Red, Green, Blue };

int main() {
    // 数组
    int a[3] = {1, 2, 3};
    std::cout << "a[2] = " << a[2] << ", sizeof(a) = " << sizeof(a) << std::endl;

    // C 风格字符串
    char name[10] = "Tom";
    std::cout << name << ", strlen = " << std::strlen(name) << std::endl;

    // std::string
    std::string s = "hello";
    s += " world";
    std::cout << s << ", size = " << s.size() << std::endl;

    // 结构
    Person p = {"Alice", 20};
    std::cout << p.name << ", " << p.age << std::endl;

    // enum class
    Color c = Color::Red;
    if (c == Color::Red) std::cout << "Color is Red" << std::endl;

    // 指针与 new
    int *pi = new int(42);
    std::cout << "*pi = " << *pi << std::endl;
    delete pi;

    // 动态数组
    int *arr = new int[5]{1, 2, 3, 4, 5};
    std::cout << "arr[2] = " << arr[2] << std::endl;
    delete[] arr;

    // 指针算术
    int nums[5] = {10, 20, 30, 40, 50};
    int *p = nums;
    std::cout << "*(p+2) = " << *(p + 2) << std::endl;

    // 动态结构
    Person *ps = new Person{"Bob", 22};
    std::cout << "ps->name = " << ps->name << std::endl;
    delete ps;

    // vector
    std::vector<int> v = {1, 2, 3};
    v.push_back(4);
    std::cout << "v[3] = " << v[3] << std::endl;

    // array
    std::array<int, 3> ar = {7, 8, 9};
    std::cout << "ar[1] = " << ar[1] << std::endl;

    return 0;
}
```

```text
Tom, strlen = 3
hello world, size = 11
Alice, 20
Color is Red
*pi = 42
arr[2] = 3
*(p+2) = 30
ps->name = Bob
v[3] = 4
ar[1] = 8
```
