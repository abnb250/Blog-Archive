## 知识点 1：for 循环——知道要重复多少次

***
<br>

### 问题

<br>

你想让程序打印 0 到 4，一共 5 次。用 `while` 得先初始化、再判断、再递增，容易漏。有没有更紧凑的写法？

<br>

### 方案

<br>

用 **`for` 循环**。结构是：

```cpp
for (初始化; 测试表达式; 更新表达式) {
    循环体;
}
```

执行顺序：初始化 → 测试 → 循环体 → 更新 → 测试 → …。测试表达式为 0 停止，非 0 继续。C++ 允许在 `for` 初始化中声明变量，作用域仅限循环。

**易错点**：`for` 后面误加分号，循环体变成空语句，后面的语句只执行一次。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    for (int i = 0; i < 5; ++i) {
        std::cout << i << " ";
    }
    std::cout << std::endl;

    // 步长自定义
    for (int i = 0; i < 10; i += 2) {
        std::cout << i << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

运行结果：

```text
0 1 2 3 4 
0 2 4 6 8 
```

<br>

### 一句话总结

<br>

**`for` 把初始化、测试、更新写在一行，适合知道次数的循环；别在 `for` 后面误加分号。**

<br>

## 知识点 2：while 循环——不知道要重复多少次

***
<br>

### 问题

<br>

你想让用户不断输入数字，直到输入 0 才停止。你不知道用户会输几次，`for` 不好写。怎么办？

<br>

### 方案

<br>

用 **`while` 循环**。它是入口条件循环，先测试再执行。适合不知道循环次数的场景。

**易错点**：`while` 后面误加分号，同样变成空循环体。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int n;
    std::cout << "输入数字，输入 0 退出：" << std::endl;
    std::cin >> n;
    while (n != 0) {
        std::cout << "你输入了 " << n << std::endl;
        std::cin >> n;
    }
    std::cout << "退出循环" << std::endl;
    return 0;
}
```

运行结果（假设输入 `3 5 0`）：

```text
输入数字，输入 0 退出：
3
你输入了 3
5
你输入了 5
0
退出循环
```

<br>

### 一句话总结

<br>

**`while` 先判断后执行，适合不知道次数的循环；别在 `while` 后面误加分号。**

<br>

## 知识点 3：do-while 循环——至少执行一次

***
<br>

### 问题

<br>

你想让用户输入一个 1 到 7 之间的数字，如果输入不对就重新输入。不管怎样，至少得先让用户输一次。`while` 先判断，可能一次都不执行，怎么办？

<br>

### 方案

<br>

用 **`do-while` 循环**。它是出口条件循环，先执行一次再测试。适合至少执行一次的场景，比如用户输入验证。

**易错点**：`do-while` 末尾必须有分号。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int choice;
    do {
        std::cout << "输入 1-7 退出：";
        std::cin >> choice;
    } while (choice < 1 || choice > 7);

    std::cout << "你选择了 " << choice << std::endl;
    return 0;
}
```

运行结果（假设输入 `9` 然后 `3`）：

```text
输入 1-7 退出：9
输入 1-7 退出：3
你选择了 3
```

<br>

### 一句话总结

<br>

**`do-while` 先执行一次再判断，适合“至少做一次”的场景，末尾别忘了分号。**

<br>

## 知识点 4：范围 for——遍历数组和容器最省心

***
<br>

### 问题

<br>

你有一个数组，想遍历打印每个元素。用 `for (int i = 0; i < n; ++i)` 还得管下标，容易越界。有没有更简单的？

<br>

### 方案

<br>

用 **范围 `for`（C++11）**：

```cpp
for (int x : nums) { ... }
```

自动依次取每个元素。**修改元素需用引用**：`for (int &x : nums)`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int nums[5] = {1, 2, 3, 4, 5};

    std::cout << "只读遍历：";
    for (int x : nums) {
        std::cout << x << " ";
    }
    std::cout << std::endl;

    std::cout << "修改元素：";
    for (int &x : nums) {
        x *= 2;
    }
    for (int x : nums) {
        std::cout << x << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

运行结果：

```text
只读遍历：1 2 3 4 5 
修改元素：2 4 6 8 10 
```

<br>

### 一句话总结

<br>

**范围 `for` 自动遍历每个元素，想修改就用 `int &x`，不用管下标。**

<br>

### 自测

<br>

`for (int x : nums)` 和 `for (int &x : nums)` 有什么区别？什么时候必须用引用？

## 知识点 5：递增递减——++i 和 i++ 的区别

***
<br>

### 问题

<br>

你写 `int a = 5; int b = a++;`，`b` 是 5，`a` 是 6。写 `int c = ++a;`，`c` 是 7，`a` 是 7。为什么？指针的 `*p++` 和 `(*p)++` 又有什么区别？

<br>

### 方案

<br>

- `++i`（前缀）：先加 1，再返回新值。
- `i++`（后缀）：先返回旧值，再加 1。
- 效率上**前缀通常优于后缀**（后缀需复制副本）。
- 指针递增：`++p` 增加指向类型的大小。
- 优先级：后缀高于前缀；前缀与 `*` 同优先级，从右向左结合。
  - `*++p`：先递增指针，再解引用。
  - `(*p)++`：先解引用，再递增值。
  - `*p++`：先解引用，再递增指针。

**易错点**：不要在同一条语句中对同一变量多次递增/递减，如 `x = 2 * x++ * (3 - ++x);` 是未定义行为。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int a = 5;
    int b = a++;
    std::cout << "a = " << a << ", b = " << b << std::endl;   // a=6, b=5

    int c = ++a;
    std::cout << "a = " << a << ", c = " << c << std::endl;   // a=7, c=7

    int arr[3] = {10, 20, 30};
    int *p = arr;
    std::cout << "*p = " << *p << std::endl;      // 10
    std::cout << "*p++ = " << *p++ << std::endl;  // 10，然后 p 指向 arr[1]
    std::cout << "*p = " << *p << std::endl;      // 20

    (*p)++;
    std::cout << "arr[1] = " << arr[1] << std::endl; // 21

    return 0;
}
```

运行结果：

```text
a = 6, b = 5
a = 7, c = 7
*p = 10
*p++ = 10
*p = 20
arr[1] = 21
```

<br>

### 一句话总结

<br>

**前缀先加后用，后缀先用后加；`*p++` 先解引用再移动指针，`(*p)++` 先解引用再增加值。**

<br>

## 知识点 6：组合赋值与逗号运算符

***
<br>

### 问题

<br>

你写 `a = a + 5;`，能不能简写？`a = 1, 2;` 和 `a = (1, 2);` 结果为什么不一样？

<br>

### 方案

<br>

- **组合赋值运算符**：`+=`、`-=`、`*=`、`/=`、`%=`。`a += 5` 等价于 `a = a + 5`。
- **逗号运算符**：将两个表达式放到只允许一个表达式的地方，优先级最低。
  - `a = 1, 2;` → 先执行 `a = 1`，再执行 `2`，`a` 为 1。
  - `a = (1, 2);` → 先执行 `1`，再执行 `2`，整个括号值为 2，`a` 为 2。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int a = 10;
    a += 5;
    std::cout << "a += 5: " << a << std::endl;   // 15

    int b = (a = 1, 2);
    std::cout << "a = " << a << ", b = " << b << std::endl; // a=1, b=2

    int c = (a = 1, 2, 3);
    std::cout << "c = " << c << std::endl; // 3

    return 0;
}
```

运行结果：

```text
a += 5: 15
a = 1, b = 2
c = 3
```

<br>

### 一句话总结

<br>

**组合赋值让代码更短；逗号运算符从左到右执行，整个表达式的值是最后一个表达式的值。**

<br>

## 知识点 7：关系表达式与 = / == 的坑

***
<br>

### 问题

<br>

你写 `if (x = 5)`，想判断 `x` 是否等于 5，结果把 `x` 赋成了 5，条件永远为真。编译器可能只给个警告。怎么避免？

<br>

### 方案

<br>

关系运算符：`<`、`<=`、`>`、`>=`、`==`、`!=`。优先级低于算术运算符。

**不要混淆 `=` 和 `==`**。`=` 是赋值，`==` 是判断相等。有些风格写成 `5 == x`，这样写错成 `5 = x` 会直接编译错误。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int x = 3;

    if (x == 5) {
        std::cout << "x 是 5" << std::endl;
    } else {
        std::cout << "x 不是 5" << std::endl;
    }

    if (5 == x) {   // 推荐写法，写错会编译错误
        std::cout << "x 是 5" << std::endl;
    } else {
        std::cout << "x 不是 5" << std::endl;
    }

    return 0;
}
```

运行结果：

```text
x 不是 5
x 不是 5
```

<br>

### 一句话总结

<br>

**判断相等用 `==`，赋值用 `=`；写成 `5 == x` 可以防止手误。**

<br>

### 自测

<br>

## 知识点 8：C 风格字符串比较——为什么 == 不行

***
<br>

### 问题

<br>

你写 `char word[] = "mate"; if (word == "mate")`，结果永远是 `false`。为什么？

<br>

### 方案

<br>

`word == "mate"` 比较的是**地址**，不是内容。C 风格字符串比较用 **`strcmp(a, b)`**：

- 相等返回 0。
- `a > b` 返回正数。
- `a < b` 返回负数。

`std::string` 可以直接用 `==`、`!=` 等比较。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <cstring>
#include <string>

int main() {
    char word[] = "mate";
    std::cout << std::boolalpha;
    std::cout << "word == \"mate\": " << (word == "mate") << std::endl;   // 地址比较，通常 false

    if (std::strcmp(word, "mate") == 0) {
        std::cout << "strcmp: 内容相等" << std::endl;
    }

    std::string s = "mate";
    if (s == "mate") {
        std::cout << "std::string: 内容相等" << std::endl;
    }

    return 0;
}
```

运行结果：

```text
word == "mate": false
strcmp: 内容相等
std::string: 内容相等
```

<br>

### 一句话总结

<br>

**C 风格字符串比较用 `strcmp`，`==` 比较的是地址；`std::string` 可以直接用 `==`。**

<br>

## 知识点 9：简单文件 I/O——把数据存下来

***
<br>

### 问题

<br>

你算出一堆结果，想保存到文件，下次还能读。用 `cout` 只能打印到屏幕。怎么办？

<br>

### 方案

<br>

用 **`<fstream>`** 里的 `ofstream` 写文件，`ifstream` 读文件。

- 写：`ofstream outFile; outFile.open("file.txt"); outFile << ...; outFile.close();`
- 读：`ifstream inFile; inFile.open("file.txt"); if (!inFile.is_open()) exit(EXIT_FAILURE); while (inFile >> value) { ... } inFile.close();`
- `open()` 会创建新文件或清空原有内容。
- `is_open()` 检测是否成功打开。
- `eof()` 文件尾，`fail()` 类型错误，`bad()` 文件损坏，`good()` 一切正常。

**易错点**：文件打开失败不检查，后续读取会异常。`cin >> n` 遇到非数字输入会失败，需 `cin.clear()` 和清除缓冲区。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <fstream>
#include <string>

int main() {
    // 写文件
    std::ofstream outFile("demo.txt");
    if (!outFile.is_open()) {
        std::cerr << "无法打开文件" << std::endl;
        return 1;
    }
    outFile << "hello file" << std::endl;
    outFile << 42 << std::endl;
    outFile.close();

    // 读文件
    std::ifstream inFile("demo.txt");
    if (!inFile.is_open()) {
        std::cerr << "无法打开文件" << std::endl;
        return 1;
    }
    std::string line;
    while (std::getline(inFile, line)) {
        std::cout << line << std::endl;
    }
    inFile.close();

    return 0;
}
```

运行结果：

```text
hello file
42
```

<br>

### 一句话总结

<br>

**`ofstream` 写文件，`ifstream` 读文件，打开后必须检查 `is_open()`，读完记得 `close()`。**

<br>

## 完整可运行代码
***

下面把本章知识点串一遍：`for`、`while`、`do-while`、范围 `for`、递增递减、逗号运算符、字符串比较、文件 I/O。

```cpp
#include <iostream>
#include <fstream>
#include <string>
#include <cstring>

int main() {
    // for
    std::cout << "for: ";
    for (int i = 0; i < 3; ++i) std::cout << i << " ";
    std::cout << std::endl;

    // while
    std::cout << "while: ";
    int n = 3;
    while (n--) std::cout << n << " ";
    std::cout << std::endl;

    // do-while
    int choice;
    do {
        std::cout << "输入 7 退出: ";
        std::cin >> choice;
    } while (choice != 7);

    // 范围 for
    std::cout << "range for: ";
    int arr[] = {10, 20, 30};
    for (int x : arr) std::cout << x << " ";
    std::cout << std::endl;

    // 递增递减
    int a = 5;
    int b = a++;
    int c = ++a;
    std::cout << "a=" << a << ", b=" << b << ", c=" << c << std::endl;

    // 逗号运算符
    int d = (a = 1, 2, 3);
    std::cout << "d=" << d << std::endl;

    // 字符串比较
    char word[] = "mate";
    std::cout << std::boolalpha;
    std::cout << "word == \"mate\": " << (word == "mate") << std::endl;
    std::cout << "strcmp == 0: " << (std::strcmp(word, "mate") == 0) << std::endl;

    // 文件写
    std::ofstream out("demo.txt");
    out << "hello file" << std::endl;
    out << 42 << std::endl;
    out.close();

    // 文件读
    std::ifstream in("demo.txt");
    std::string line;
    if (in.is_open()) {
        while (std::getline(in, line)) {
            std::cout << line << std::endl;
        }
    }
    in.close();

    return 0;
}
```

运行结果示例（假设输入 `7`）：

```text
for: 0 1 2 
while: 2 1 0 
输入 7 退出: 7
range for: 10 20 30 
a=7, b=5, c=7
d=3
word == "mate": false
strcmp == 0: true
hello file
42
```
