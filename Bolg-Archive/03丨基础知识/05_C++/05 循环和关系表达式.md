## 一句话概括
***
**一句话**：`for`、`while`、`do-while`、范围 `for` 是四种循环；递增递减、逗号运算符、关系表达式是循环控制的基础。

<br>

<br>

## 核心概念
***
### for 循环
```cpp
for (初始化; 测试表达式; 更新表达式) {
    循环体;
}
```
- 执行顺序：初始化 → 测试 → 循环体 → 更新 → 测试 → …
- 测试表达式为 0 停止，非 0 继续。
- C++ 允许在 `for` 初始化中声明变量：`for (int i = 0; i < 5; ++i)`，变量 `i` 作用域仅限循环。
- 步长可自定义：`i += 2`。

<br>

### while 循环
```cpp
while (测试表达式) {
    循环体;
}
```
- 入口条件循环，先测试再执行。
- 适合不知道循环次数的场景。

<br>

### do-while 循环
```cpp
do {
    循环体;
} while (测试表达式);
```
- 出口条件循环，先执行一次再测试。
- 适合至少执行一次的场景，如用户输入验证。

<br>

### 范围 for（C++11）
```cpp
int nums[5] = {1, 2, 3, 4, 5};
for (int x : nums) {
    cout << x << endl;
}
```
- 遍历数组或容器，自动依次取每个元素。
- 修改元素需用引用：`for (int &x : nums)`。

<br>

### 递增 / 递减运算符
- `++i`（前缀）：先加 1，再返回新值。
- `i++`（后缀）：先返回旧值，再加 1。
- 效率上前缀通常优于后缀（后缀需复制副本）。
- 指针递增：`++p` 增加指向类型的大小。
- 优先级：后缀高于前缀；前缀与 `*` 同优先级，从右向左结合。
  - `*++p`：先递增指针，再解引用。
  - `(*p)++`：先解引用，再递增值。
  - `*p++`：先解引用，再递增指针。

<br>

### 组合赋值运算符
`+=`、`-=`、`*=`、`/=`、`%=`。

<br>

### 逗号运算符
- 将两个表达式放到只允许一个表达式的地方。
- 优先级最低。
- `a = 1, 2;` → `a` 为 1。
- `a = (1, 2);` → `a` 为 2。

<br>

### 关系表达式
- `<`、`<=`、`>`、`>=`、`==`、`!=`。
- 优先级低于算术运算符。
- 不要混淆 `=` 和 `==`。

<br>

### C 风格字符串比较
- `word == "mate"` 比较的是地址，不是内容。
- 用 `strcmp(a, b)`：相等返回 0，a > b 返回正数，a < b 返回负数。
- `std::string` 可直接用 `==`、`!=` 等比较。

<br>

### 简单文件 I/O
- 头文件 `<fstream>`。
- 写文件：`ofstream outFile; outFile.open("file.txt"); outFile << ...; outFile.close();`
- 读文件：`ifstream inFile; inFile.open("file.txt"); if (!inFile.is_open()) exit(EXIT_FAILURE); while (inFile >> value) { ... } inFile.close();`
- `open()` 会创建新文件或清空原有内容。
- `is_open()` 检测是否成功打开。
- `eof()` 文件尾，`fail()` 类型错误，`bad()` 文件损坏，`good()` 一切正常。

<br>

## 最小代码
***
```cpp
#include <iostream>
#include <fstream>
#include <string>

int main() {
    // for
    for (int i = 0; i < 3; ++i) std::cout << i << " ";
    std::cout << std::endl;

    // while
    int n = 3;
    while (n--) std::cout << n << " ";
    std::cout << std::endl;

    // do-while
    int choice;
    do {
        std::cout << "输入 7 退出: ";
        std::cin >> choice;
    } while (choice != 7);

    // 范围 for
    int arr[] = {10, 20, 30};
    for (int x : arr) std::cout << x << " ";
    std::cout << std::endl;

    // 文件写
    std::ofstream out("demo.txt");
    out << "hello file" << std::endl;
    out.close();

    // 文件读
    std::ifstream in("demo.txt");
    std::string line;
    if (in.is_open()) {
        while (std::getline(in, line)) {
            std::cout << line << std::endl;
        }
    }
    in.close();

    return 0;
}
```

## 易错点
***
- `for` 后误加分号：`for (...);` 变成空循环体。
- `while` 后误加分号同理。
- 不要在同一条语句中对同一变量多次递增/递减，如 `x = 2 * x++ * (3 - ++x);` 是未定义行为。
- `do-while` 末尾必须有分号。
- 文件打开失败不检查会导致后续读取异常。
- `cin >> n` 遇到非数字输入会失败，需 `cin.clear()` 和清除缓冲区。

<br>

<br>

## 项目用途
***
- 遍历容器、数组用范围 `for`。
- 读取配置、日志用文件流。
- 输入验证用 `do-while`。
- 循环控制中注意前缀递增效率。
