## 一句话概括
***
**一句话**：`if/else`、`switch`、逻辑运算符、`?:` 构成分支控制；`cctype` 简化字符判断；输入验证和文件 I/O 是项目常用技能。

<br>

<br>


## 核心概念
***
### if / else
```cpp
if (条件) {
    // ...
} else if (条件2) {
    // ...
} else {
    // ...
}
```
- 条件为 0 走 else，非 0 走 if。
- 代码块用花括号，即使只有一条语句也建议加。

<br>

### 逻辑运算符
- `||` 逻辑或：任一为真即真。
- `&&` 逻辑与：两者都真才真。
- `!` 逻辑非：取反。
- 优先级：`!` > `&&` > `||`。
- 短路求值：`&&` 左边为假则右边不计算；`||` 左边为真则右边不计算。
- 范围判断要写 `if (age > 17 && age < 35)`，不能写 `if (17 < age < 35)`。

<br>

### cctype 字符函数
- `isalpha()`、`isdigit()`、`isspace()`、`isupper()`、`islower()`、`ispunct()` 等。
- 返回非 0 表示真，0 表示假。

<br>

### ?: 运算符
```cpp
int c = a > b ? a : b;
```
- 唯一的三元运算符，可替代简单 if-else。

<br>

### switch 语句
```cpp
switch (整数表达式) {
    case 常量1:
        // ...
        break;
    case 常量2:
        // ...
        break;
    default:
        // ...
}
```
- 表达式必须是整型、char、枚举。
- 每个 case 后通常加 `break`，否则会继续执行下一个 case。
- `default` 可选。

<br>

### break 和 continue
- `break`：跳出当前循环或 switch。
- `continue`：跳过本次循环剩余部分，进入下一次循环（仍会执行更新表达式）。

<br>

### 读取数字的循环（输入验证）
```cpp
int n;
while (!(cin >> n)) {
    cin.clear();               // 清除错误标记
    while (cin.get() != '\n')  // 清除缓冲区
        continue;
    cout << "请输入数字: ";
}
```

## 最小代码
***
```cpp
#include <iostream>
#include <cctype>

int main() {
    char ch;
    std::cout << "输入一个字符: ";
    std::cin >> ch;

    if (std::isalpha(ch)) {
        std::cout << "字母" << std::endl;
    } else if (std::isdigit(ch)) {
        std::cout << "数字" << std::endl;
    } else {
        std::cout << "其他" << std::endl;
    }

    int a = 10, b = 20;
    int max = a > b ? a : b;
    std::cout << "max = " << max << std::endl;

    switch (ch) {
        case 'a':
        case 'A':
            std::cout << "A" << std::endl;
            break;
        default:
            std::cout << "not A" << std::endl;
    }
    return 0;
}
```

<br>

<br>

## 易错点
***
- `switch` 忘记 `break` 导致贯穿。
- `case` 只能是常量表达式，不能是变量。
- 逻辑运算符优先级低于关系运算符，注意加括号。
- `cin` 失败后必须 `clear()` 并清除缓冲区，否则后续输入全部失败。
- `continue` 不会跳过 `for` 的更新表达式。

<br>

<br>

## 项目用途
***
- 配置解析、命令行参数处理用分支。
- 输入验证用 `while (!(cin >> x))`。
- 字符分类用 `cctype`。
- 多分支用 `switch` 比 `if-else` 清晰。
