## 知识点 1：if/else 和逻辑运算符——范围判断别写错

***
<br>

### 问题

<br>

你想判断年龄是否在 18 到 35 之间，写了：

```cpp
if (17 < age < 35) { ... }
```

结果不管 `age` 是多少，条件都是真。为什么？

<br>

### 方案

<br>

因为 `17 < age` 先计算，结果是 `bool`（`true` 或 `false`）。然后这个 `bool` 再和 `35` 比较：`true` 转成 1，`false` 转成 0，都小于 35，所以整个表达式永远为真。

正确写法是用**逻辑与 `&&`**：

```cpp
if (age > 17 && age < 35) { ... }
```

逻辑运算符：

- `||` 逻辑或：任一为真即真。
- `&&` 逻辑与：两者都真才真。
- `!` 逻辑非：取反。
- 优先级：`!` > `&&` > `||`。
- **短路求值**：`&&` 左边为假则右边不计算；`||` 左边为真则右边不计算。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int age = 25;

    // 错误写法
    if (17 < age < 35) {
        std::cout << "错误写法：总是真" << std::endl;
    }

    // 正确写法
    if (age > 17 && age < 35) {
        std::cout << "正确写法：年龄在 18 到 34 之间" << std::endl;
    }

    // 短路求值
    int x = 0;
    if (x != 0 && 10 / x > 1) {   // x != 0 为假，右边不计算，不会除零
        std::cout << "不会执行" << std::endl;
    }

    return 0;
}
```

运行结果：

```text
错误写法：总是真
正确写法：年龄在 18 到 34 之间
```

<br>

### 一句话总结

<br>

**范围判断要用 `&&` 连接两个比较，不能写 `17 < age < 35`；短路求值能避免不必要的计算和错误。**

<br>

## 知识点 2：cctype——字符分类不用手写

***
<br>

### 问题

<br>

你想判断用户输入的是字母、数字还是空格，难道要写 `if ((ch >= 'a' && ch <= 'z') || (ch >= 'A' && ch <= 'Z'))`？太长了。

<br>

### 方案

<br>

用 **`<cctype>`** 里的字符函数：`isalpha()`、`isdigit()`、`isspace()`、`isupper()`、`islower()`、`ispunct()` 等。返回非 0 表示真，0 表示假。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <cctype>

int main() {
    char ch;
    std::cout << "输入一个字符: ";
    std::cin >> ch;

    if (std::isalpha(ch)) {
        std::cout << "字母" << std::endl;
    } else if (std::isdigit(ch)) {
        std::cout << "数字" << std::endl;
    } else if (std::isspace(ch)) {
        std::cout << "空白" << std::endl;
    } else {
        std::cout << "其他" << std::endl;
    }

    return 0;
}
```

运行结果（假设输入 `A`）：

```text
输入一个字符: A
字母
```

<br>

### 一句话总结

<br>

**`cctype` 提供现成的字符分类函数，别手写一堆范围判断。**

<br>

<br>

## 知识点 3：?: 三元运算符——简单分支的快捷方式

***
<br>

### 问题

<br>

你想求两个数的最大值，写了：

```cpp
int max;
if (a > b) {
    max = a;
} else {
    max = b;
}
```

占了好几行，能不能更简洁？

<br>

### 方案

<br>

用 **`?:` 三元运算符**：

```cpp
int max = a > b ? a : b;
```

它是唯一的三元运算符，可以替代简单的 if-else。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int a = 10, b = 20;
    int max = a > b ? a : b;
    std::cout << "max = " << max << std::endl;

    int score = 75;
    std::string result = score >= 60 ? "及格" : "不及格";
    std::cout << result << std::endl;

    return 0;
}
```

运行结果：

```text
max = 20
及格
```

<br>

### 一句话总结

<br>

**`?:` 就是简化的 if-else，条件 ? 真值 : 假值，适合简单赋值。**

<br>

### 自测

<br>

`a > b ? a : b` 的结果是什么？什么时候不适合用 `?:`？

## 知识点 4：switch——多分支比 if-else 清晰，但别忘 break

***
<br>

### 问题

<br>

你想根据用户输入的选项执行不同操作，写了很长的 `if-else if` 链。有没有更清晰的写法？

<br>

### 方案

<br>

用 **`switch` 语句**。表达式必须是整型、`char`、枚举。每个 `case` 后通常加 `break`，否则会**贯穿**到下一个 case。`default` 可选。

**易错点**：`case` 只能是常量表达式，不能是变量。忘记 `break` 会导致执行多个分支。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    char ch;
    std::cout << "输入 a 或 b: ";
    std::cin >> ch;

    switch (ch) {
        case 'a':
        case 'A':
            std::cout << "你选了 A" << std::endl;
            break;
        case 'b':
        case 'B':
            std::cout << "你选了 B" << std::endl;
            break;
        default:
            std::cout << "其他选项" << std::endl;
    }

    return 0;
}
```

运行结果（假设输入 `a`）：

```text
输入 a 或 b: a
你选了 A
```

<br>

### 一句话总结

<br>

**`switch` 适合多个离散值的分支，每个 case 后记得 `break`，否则会贯穿。**

<br>

## 知识点 5：break 和 continue——循环控制

***
<br>

### 问题

<br>

你在循环里想提前退出，或者跳过某次循环剩下的代码。怎么写？

<br>

### 方案

<br>

- **`break`**：跳出当前循环或 `switch`。
- **`continue`**：跳过本次循环剩余部分，进入下一次循环。在 `for` 循环中，`continue` 仍会执行更新表达式。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    // break：找到 5 就退出
    for (int i = 0; i < 10; ++i) {
        if (i == 5) {
            std::cout << "break at " << i << std::endl;
            break;
        }
        std::cout << i << " ";
    }
    std::cout << std::endl;

    // continue：跳过偶数
    for (int i = 0; i < 6; ++i) {
        if (i % 2 == 0) {
            continue;
        }
        std::cout << i << " ";
    }
    std::cout << std::endl;

    return 0;
}
```

运行结果：

```text
0 1 2 3 4 break at 5
1 3 5 
```

<br>

### 一句话总结

<br>

**`break` 直接跳出循环，`continue` 跳过本次剩余部分；`continue` 不会跳过 `for` 的更新表达式。**

<br>

## 知识点 6：输入验证——cin 失败后必须 clear

***
<br>

### 问题

<br>

你写 `int n; cin >> n;`，用户输入字母 `abc`，`cin` 进入失败状态，后续所有输入都失败，程序可能死循环。怎么办？

<br>

### 方案

<br>

用 `while (!(cin >> n))` 检测失败，然后：

1. `cin.clear();` 清除错误标记。
2. `while (cin.get() != '\n') continue;` 清除缓冲区里的错误输入。
3. 提示用户重新输入。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int main() {
    int n;
    std::cout << "请输入一个数字: ";
    while (!(std::cin >> n)) {
        std::cin.clear();                 // 清除错误标记
        while (std::cin.get() != '\n')    // 清除缓冲区
            continue;
        std::cout << "输入无效，请重新输入数字: ";
    }
    std::cout << "你输入了 " << n << std::endl;
    return 0;
}
```

运行结果（假设先输入 `abc` 再输入 `42`）：

```text
请输入一个数字: abc
输入无效，请重新输入数字: 42
你输入了 42
```

<br>

### 一句话总结

<br>

**`cin` 失败后要 `clear()` 清状态，再清空缓冲区，否则后续输入全失败。**

<br>

## 完整可运行代码
***

下面把本章知识点串一遍：`if/else`、逻辑运算符、`cctype`、`?:`、`switch`、`break/continue`、输入验证。

```cpp
#include <iostream>
#include <cctype>
#include <string>

int main() {
    // 1. if/else 和逻辑运算符
    int age = 25;
    if (age > 17 && age < 35) {
        std::cout << "年龄在 18 到 34 之间" << std::endl;
    }

    // 2. cctype
    char ch;
    std::cout << "输入一个字符: ";
    std::cin >> ch;
    if (std::isalpha(ch)) {
        std::cout << "字母" << std::endl;
    } else if (std::isdigit(ch)) {
        std::cout << "数字" << std::endl;
    } else {
        std::cout << "其他" << std::endl;
    }

    // 3. ?: 三元运算符
    int a = 10, b = 20;
    int max = a > b ? a : b;
    std::cout << "max = " << max << std::endl;

    // 4. switch
    switch (ch) {
        case 'a':
        case 'A':
            std::cout << "你选了 A" << std::endl;
            break;
        case 'b':
        case 'B':
            std::cout << "你选了 B" << std::endl;
            break;
        default:
            std::cout << "其他选项" << std::endl;
    }

    // 5. break 和 continue
    for (int i = 0; i < 10; ++i) {
        if (i == 5) break;
        if (i % 2 == 0) continue;
        std::cout << i << " ";
    }
    std::cout << std::endl;

    // 6. 输入验证
    int n;
    std::cout << "请输入一个数字: ";
    while (!(std::cin >> n)) {
        std::cin.clear();
        while (std::cin.get() != '\n')
            continue;
        std::cout << "输入无效，请重新输入数字: ";
    }
    std::cout << "你输入了 " << n << std::endl;

    return 0;
}
```

运行结果示例（假设输入 `a`，然后 `abc`，再 `42`）：

```text
年龄在 18 到 34 之间
输入一个字符: a
字母
max = 20
你选了 A
1 3 
请输入一个数字: abc
输入无效，请重新输入数字: 42
你输入了 42
```

***

**`if/else` 配逻辑运算符，范围判断用 `&&`；`cctype` 简化字符分类；`?:` 适合简单赋值；`switch` 多分支别忘 `break`；`break` 跳出循环，`continue` 跳过本次；`cin` 失败要 `clear()` 加清缓冲区——分支和逻辑搞清楚，程序才听你指挥。**
