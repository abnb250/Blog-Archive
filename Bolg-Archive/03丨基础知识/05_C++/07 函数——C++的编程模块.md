## 一句话概括
***
**一句话**：函数是 C++ 的基本模块；定义、原型、调用三要素；参数默认按值传递；数组作为参数传递的是地址。

<br>

<br>

## 核心概念
***
### 函数定义
```cpp
// 无返回值
void func(int n) {
    // ...
    return; // 可选
}

// 有返回值
int add(int a, int b) {
    return a + b;
}
```

<br>

### 函数原型
- 告诉编译器函数的返回类型和参数类型。
- 必须以分号结尾。
- 通常放在 `main` 之前或头文件中。
```cpp
int add(int, int);  // 原型
```

<br>

### 函数调用
```cpp
int sum = add(3, 4);
```

<br>

### 按值传递
- 实参的值被复制给形参。
- 函数内修改形参不影响实参。
- 形参是函数私有变量，函数结束时销毁。

<br>

### 多个参数
- 用逗号分隔，每个参数都要指定类型。
```cpp
void n_chars(char c, int n);
```

<br>

### 数组作为参数
- 数组名是首元素地址，传递的是地址。
- 函数原型中 `int arr[]` 和 `int *arr` 等价。
- 需额外传递数组长度。
```cpp
int sum_arr(int arr[], int n);
// 或
int sum_arr(int *arr, int n);
```
- 函数内使用原数组，可修改原数据。
- 不希望修改时用 `const`：
```cpp
int sum_arr(const int arr[], int n);
```

<br>

### 数组名与指针
- `arr[i]` 等价于 `*(arr + i)`。
- `&arr[i]` 等价于 `arr + i`。
- `sizeof(数组名)` 得到整个数组字节数；`sizeof(指针)` 得到指针大小。

<br>

## 最小代码
***
```cpp
#include <iostream>

// 原型
int sum_arr(const int arr[], int n);
void cheers(int n);

int main() {
    int nums[] = {1, 2, 3, 4, 5};
    int total = sum_arr(nums, 5);
    std::cout << "sum = " << total << std::endl;
    cheers(3);
    return 0;
}

int sum_arr(const int arr[], int n) {
    int total = 0;
    for (int i = 0; i < n; ++i) {
        total += arr[i];
    }
    return total;
}

void cheers(int n) {
    for (int i = 0; i < n; ++i) {
        std::cout << "Cheers! ";
    }
    std::cout << std::endl;
}
```

<br>

<br>

## 易错点
***
- 忘记函数原型，编译器可能进行隐式转换或报错。
- 数组参数传递的是地址，函数内修改会影响原数组。
- 返回局部数组的指针是悬空指针。
- 函数不能返回数组，但可以返回结构或指针。
- `const` 数组参数防止意外修改。

<br>

<br>

## 项目用途
***
- 将逻辑拆成函数，便于测试和复用。
- 数组参数用 `const` 保证安全。
- 函数原型放在头文件中，定义放在源文件中。
