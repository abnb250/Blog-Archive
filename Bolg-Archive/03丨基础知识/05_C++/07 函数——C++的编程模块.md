## 知识点 1：把一段逻辑抽成函数——定义和调用

***
<br>

### 问题

<br>

你在 `main` 里写了求和的代码，现在另一个地方也要用。复制粘贴？改一个 bug 得改两处。能不能把这段逻辑单独拎出来，起个名字，到处调用？

<br>

### 方案

<br>

用**函数**。函数定义包括返回类型、函数名、参数列表和函数体。调用时写函数名加括号，传入实参。多个参数用逗号分隔，每个参数都要指定类型。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

// 函数定义
int add(int a, int b) {
    return a + b;
}

void cheers(int n) {
    for (int i = 0; i < n; ++i) {
        std::cout << "Cheers! ";
    }
    std::cout << std::endl;
}

int main() {
    int sum = add(3, 4);   // 函数调用
    std::cout << "sum = " << sum << std::endl;
    cheers(3);
    return 0;
}
```

运行结果：

```text
sum = 7
Cheers! Cheers! Cheers! 
```

<br>

### 一句话总结

<br>

**函数就是把一段逻辑打包，起个名字，随用随调，不用复制粘贴。**

<br>

## 知识点 2：函数定义在后面，main 调用报错——函数原型

***
<br>

### 问题

<br>

你把 `add` 函数定义在 `main` 后面，`main` 里调用 `add(3, 4)`，编译器报错：`'add' was not declared in this scope`。为什么？

<br>

### 方案

<br>

C++ 要求**函数使用前必须要有声明**。如果定义在调用之后，就得在前面写**函数原型**。原型告诉编译器函数的返回类型和参数类型，以分号结尾。通常放在 `main` 之前或头文件中。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int add(int a, int b);   // 函数原型

int main() {
    int sum = add(3, 4);
    std::cout << "sum = " << sum << std::endl;
    return 0;
}

int add(int a, int b) {  // 函数定义
    return a + b;
}
```

运行结果：

```text
sum = 7
```

<br>

### 一句话总结

<br>

**函数使用前要有原型，原型告诉编译器“有这个函数，长这样”，定义可以放在后面。**

<br>

## 知识点 3：函数改了参数，外面没变——按值传递

***
<br>

### 问题

<br>

你写了一个函数，想把传进来的数加 1：

```cpp
void add_one(int x) {
    x = x + 1;
}
```

调用 `int a = 5; add_one(a);` 之后，`a` 还是 5。为什么？

<br>

### 方案

<br>

因为 C++ 默认是**按值传递**：实参的值被复制给形参。函数内修改的是形参（副本），不影响实参。形参是函数私有变量，函数结束时销毁。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

void add_one(int x) {
    x = x + 1;
    std::cout << "函数内 x = " << x << std::endl;
}

int main() {
    int a = 5;
    add_one(a);
    std::cout << "函数外 a = " << a << std::endl;
    return 0;
}
```

运行结果：

```text
函数内 x = 6
函数外 a = 5
```

<br>

### 一句话总结

<br>

**按值传递就是复印一份，函数改的是复印件，原件不动。**

<br>

## 知识点 4：数组传给函数，函数里改了外面也变了——数组参数传地址

***
<br>

### 问题

<br>

你把数组传给函数求和，函数里不小心改了某个元素，结果外面原数组也变了。为什么？不是按值传递吗？

<br>

### 方案

<br>

因为**数组名是首元素地址**。把数组传给函数时，传递的是地址，不是整个数组的副本。所以函数内操作的就是原数组。函数原型中 `int arr[]` 和 `int *arr` 等价。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int sum_arr(int arr[], int n) {
    int total = 0;
    for (int i = 0; i < n; ++i) {
        total += arr[i];
    }
    arr[0] = 999;   // 修改会影响原数组
    return total;
}

int main() {
    int nums[] = {1, 2, 3, 4, 5};
    int total = sum_arr(nums, 5);
    std::cout << "sum = " << total << std::endl;
    std::cout << "nums[0] = " << nums[0] << std::endl;
    return 0;
}
```

运行结果：

```text
sum = 15
nums[0] = 999
```

<br>

### 一句话总结

<br>

**数组传参传的是地址，函数里操作的就是原数组，修改会影响外面。**

<br>

### 自测

<br>

`int arr[]` 和 `int *arr` 作为函数参数有什么区别？函数内修改数组元素会影响原数组吗？

## 知识点 5：不想让函数改数组——const 数组参数

***
<br>

### 问题

<br>

求和函数本来不该改数组，但不小心写错了，改了原数据。能不能让编译器帮我拦住？

<br>

### 方案

<br>

在数组参数前加 **`const`**：

```cpp
int sum_arr(const int arr[], int n);
```

这样函数内不能修改数组元素，写 `arr[0] = 999;` 会编译报错。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int sum_arr(const int arr[], int n) {
    int total = 0;
    for (int i = 0; i < n; ++i) {
        total += arr[i];
    }
    // arr[0] = 999;   // 错误：不能修改 const 数组
    return total;
}

int main() {
    int nums[] = {1, 2, 3, 4, 5};
    int total = sum_arr(nums, 5);
    std::cout << "sum = " << total << std::endl;
    std::cout << "nums[0] = " << nums[0] << std::endl;
    return 0;
}
```

运行结果：

```text
sum = 15
nums[0] = 1
```

<br>

### 一句话总结

<br>

**`const` 就是告诉编译器“这个数组只读”，防止手滑改坏原数据。**

<br>

## 知识点 6：数组参数为什么还要传长度？int arr[] 和 int *arr 等价

***
<br>

### 问题

<br>

函数里写 `sizeof(arr)`，以为能得到数组字节数，结果得到的是指针大小。为什么？数组长度怎么传？

<br>

### 方案

<br>

因为数组传参时**退化成指针**，`sizeof(arr)` 得到的是指针大小，不是数组大小。所以必须**额外传递数组长度**。函数原型中 `int arr[]` 和 `int *arr` 完全等价。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int sum_arr(int *arr, int n) {
    std::cout << "sizeof(arr) = " << sizeof(arr) << std::endl;   // 指针大小
    int total = 0;
    for (int i = 0; i < n; ++i) {
        total += arr[i];
    }
    return total;
}

int main() {
    int nums[] = {1, 2, 3, 4, 5};
    std::cout << "sizeof(nums) = " << sizeof(nums) << std::endl; // 整个数组大小
    int total = sum_arr(nums, 5);
    std::cout << "sum = " << total << std::endl;
    return 0;
}
```

运行结果（常见 64 位平台）：

```text
sizeof(nums) = 20
sizeof(arr) = 8
sum = 15
```

<br>

### 一句话总结

<br>

**数组传参退化成指针，长度得自己传；`int arr[]` 和 `int *arr` 在参数里是一回事。**

<br>

## 知识点 7：函数不能返回数组，但可以返回结构或指针

***
<br>

### 问题

<br>

你想写一个函数返回一个数组，结果编译报错。函数到底能返回什么？

<br>

### 方案

<br>

C++ 中**函数不能直接返回数组**，但可以返回**结构**、**指针**，或者用 `std::array`、`std::vector`。返回局部数组的指针是悬空指针，危险。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

struct Pair {
    int a;
    int b;
};

Pair make_pair(int x, int y) {
    return {x, y};
}

int main() {
    Pair p = make_pair(3, 4);
    std::cout << "a = " << p.a << ", b = " << p.b << std::endl;
    return 0;
}
```

运行结果：

```text
a = 3, b = 4
```

<br>

### 一句话总结

<br>

**函数不能直接返回数组，但可以返回结构、指针或标准容器；返回局部数组的指针是悬空指针。**

<br>

## 完整可运行代码
***

下面把本章知识点串一遍：函数定义、原型、按值传递、数组参数、`const`、指针与数组、返回结构。

```cpp
#include <iostream>

// 函数原型
int add(int a, int b);
void cheers(int n);
int sum_arr(const int arr[], int n);

struct Pair {
    int a;
    int b;
};

Pair make_pair(int x, int y);

int main() {
    // 函数定义与调用
    int sum = add(3, 4);
    std::cout << "sum = " << sum << std::endl;
    cheers(3);

    // 按值传递
    int a = 5;
    std::cout << "a before = " << a << std::endl;

    // 数组参数
    int nums[] = {1, 2, 3, 4, 5};
    int total = sum_arr(nums, 5);
    std::cout << "sum_arr = " << total << std::endl;
    std::cout << "nums[0] = " << nums[0] << std::endl;

    // 返回结构
    Pair p = make_pair(3, 4);
    std::cout << "Pair: " << p.a << ", " << p.b << std::endl;

    return 0;
}

int add(int a, int b) {
    return a + b;
}

void cheers(int n) {
    for (int i = 0; i < n; ++i) {
        std::cout << "Cheers! ";
    }
    std::cout << std::endl;
}

int sum_arr(const int arr[], int n) {
    int total = 0;
    for (int i = 0; i < n; ++i) {
        total += arr[i];
    }
    return total;
}

Pair make_pair(int x, int y) {
    return {x, y};
}
```

运行结果：

```text
sum = 7
Cheers! Cheers! Cheers! 
sum_arr = 15
nums[0] = 1
Pair: 3, 4
```
