你是不是也干过这种事：写一个 `Swap` 函数交换两个 `int`，再写一个交换两个 `double`，再写一个交换两个 `std::string`……复制粘贴改类型，改到怀疑人生。更麻烦的是，如果还有个 `Job` 结构体，交换逻辑不一样，你只能在通用版本里写一堆 `if`。

这一章咱们就解决这个问题：**函数模板**让你写一遍，编译器为每种类型生成对应版本。但模板不是万能的，有些类型需要特殊处理，于是有了**显式具体化**；有些场景需要提前生成实例，于是有了**显式实例化**；多个版本同时存在时，编译器按**重载解析**规则选；返回类型依赖参数时，用 **`decltype` + 后置返回类型**。

<br>

## 知识点 1：Swap 写了一遍又一遍？用函数模板

***
<br>

### 问题

<br>

你写了 `Swap(int&, int&)`、`Swap(double&, double&)`、`Swap(std::string&, std::string&)`，逻辑一模一样，只是类型不同。能不能只写一遍？

<br>

### 方案

<br>

用**函数模板**。在函数前写 `template <typename T>`，把具体类型换成 `T`。**模板本身不生成函数**，调用时编译器按实参类型实例化出具体函数。

**易错点**：模板定义通常放在头文件中，因为编译器需要看到完整定义才能实例化。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <string>

template <typename T>
void Swap(T& a, T& b) {
    T temp = a;
    a = b;
    b = temp;
}

int main() {
    int i = 1, j = 2;
    Swap(i, j);
    std::cout << "i = " << i << ", j = " << j << std::endl;

    double x = 1.1, y = 2.2;
    Swap(x, y);
    std::cout << "x = " << x << ", y = " << y << std::endl;

    std::string s1 = "hello", s2 = "world";
    Swap(s1, s2);
    std::cout << "s1 = " << s1 << ", s2 = " << s2 << std::endl;

    return 0;
}
```

运行结果：

```text
i = 2, j = 1
x = 2.2, y = 1.1
s1 = world, s2 = hello
```

<br>

### 一句话总结

<br>

**函数模板就是写一遍逻辑，类型用 `T` 占位，编译器按调用类型生成对应函数。**

<br>

## 知识点 2：Swap 数组怎么办？重载模板

***
<br>

### 问题

<br>

你有了 `Swap(T&, T&)`，但现在想交换两个数组的前 n 个元素。参数不一样：两个指针加一个长度。能不能复用 `Swap` 这个名字？

<br>

### 方案

<br>

**重载模板**：像重载普通函数一样，写一个参数列表不同的模板版本。编译器会根据调用时的参数选择匹配的版本。

**易错点**：重载的模板特征标必须不同，否则编译报错。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

template <typename T>
void Swap(T& a, T& b) {
    T temp = a;
    a = b;
    b = temp;
}

template <typename T>
void Swap(T* a, T* b, int n) {
    for (int i = 0; i < n; ++i) {
        T temp = a[i];
        a[i] = b[i];
        b[i] = temp;
    }
}

int main() {
    int i = 1, j = 2;
    Swap(i, j);
    std::cout << "i = " << i << ", j = " << j << std::endl;

    int a[3] = {1, 2, 3};
    int b[3] = {4, 5, 6};
    Swap(a, b, 3);
    std::cout << "a: ";
    for (int x : a) std::cout << x << " ";
    std::cout << std::endl;
    std::cout << "b: ";
    for (int x : b) std::cout << x << " ";
    std::cout << std::endl;

    return 0;
}
```

运行结果：

```text
i = 2, j = 1
a: 4 5 6 
b: 1 2 3 
```

<br>

### 一句话总结

<br>

**重载模板就是同名模板，参数列表不同，编译器按调用选择匹配的版本。**

<br>

## 知识点 3：Job 结构体不能用通用 Swap？显式具体化

***
<br>

### 问题

<br>

你有一个 `Job` 结构体，里面有 `name` 和 `salary`。用通用 `Swap` 会交换整个结构体，但你想只交换 `salary`，保留 `name`。怎么办？

<br>

### 方案

<br>

用**显式具体化**：为特定类型提供专门定义，优先于通用模板。语法是 `template <> void Swap<Job>(Job&, Job&);`，或者省略 `<Job>` 让编译器推导。

**易错点**：显式具体化有 `template <>`，显式实例化没有 `<>`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <cstring>

struct Job {
    char name[20];
    double salary;
};

template <typename T>
void Swap(T& a, T& b) {
    T temp = a;
    a = b;
    b = temp;
}

// 显式具体化：只交换 salary
template <>
void Swap<Job>(Job& j1, Job& j2) {
    double t = j1.salary;
    j1.salary = j2.salary;
    j2.salary = t;
}

int main() {
    Job a = {"Alice", 1000};
    Job b = {"Bob", 2000};

    Swap(a, b);
    std::cout << a.name << ": " << a.salary << std::endl;
    std::cout << b.name << ": " << b.salary << std::endl;

    return 0;
}
```

运行结果：

```text
Alice: 2000
Bob: 1000
```

注意 `name` 没有被交换，只交换了 `salary`。

<br>

### 一句话总结

<br>

**显式具体化就是给特定类型开小灶，写一份专门版本，优先于通用模板。**

<br>

## 知识点 4：想提前生成某个类型的版本？显式实例化

***
<br>

### 问题

<br>

你有一个模板函数，想在某个 `.cpp` 文件里提前生成 `int` 版本的代码，这样其他文件用的时候不用再实例化。怎么写？

<br>

### 方案

<br>

用**显式实例化**：`template void Swap<int>(int&, int&);`。注意**没有 `<>`**。这和显式具体化 `template <> void Swap<int>(int&, int&);` 不同，后者有 `<>` 且提供专门定义。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

template <typename T>
void Swap(T& a, T& b) {
    T temp = a;
    a = b;
    b = temp;
}

// 显式实例化：命令编译器生成 int 版本
template void Swap<int>(int&, int&);

int main() {
    int i = 1, j = 2;
    Swap(i, j);   // 使用已生成的 int 版本
    std::cout << "i = " << i << ", j = " << j << std::endl;

    return 0;
}
```

运行结果：

```text
i = 2, j = 1
```

<br>

### 一句话总结

<br>

**显式实例化就是命令编译器“给我生成这个类型的版本”，语法是 `template void f<int>(...);`，没有 `<>`。**

<br>

## 知识点 5：多个版本同时存在，编译器选哪个？重载解析

***
<br>

### 问题

<br>

你有一个普通函数 `Swap(int&, int&)`，一个模板 `Swap(T&, T&)`，还有一个显式具体化 `Swap<Job>`。调用 `Swap(i, j)` 时，编译器到底选哪个？

<br>

### 方案

<br>

编译器按**重载解析**规则选择：

1. 创建候选函数列表（同名函数和模板）。
2. 创建可行函数列表（参数匹配）。
3. 确定最佳匹配：
   - 完全匹配 > 提升转换 > 标准转换 > 用户定义转换。
   - **非模板函数优先于模板函数**。
   - 更具体的模板优先。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

void show(int x) {
    std::cout << "普通函数: " << x << std::endl;
}

template <typename T>
void show(T x) {
    std::cout << "模板: " << x << std::endl;
}

int main() {
    int i = 42;
    show(i);      // 非模板优先
    show(3.14);   // 模板实例化
    show('A');    // 模板实例化
    return 0;
}
```

运行结果：

```text
普通函数: 42
模板: 3.14
模板: A
```

<br>

### 一句话总结

<br>

**重载解析先找完全匹配，非模板优先于模板，更具体的模板优先于通用的。**

<br>

## 知识点 6：不知道表达式类型，但需要声明变量？decltype

***
<br>

### 问题

<br>

你写 `int x = 10; double y = 20.5;`，想声明一个变量 `z`，让它的类型和 `x + y` 一样。手写 `double z` 可以，但如果表达式类型变了，你得手动改。能不能让编译器推导？

<br>

### 方案

<br>

用 **`decltype`**（C++11）。它让编译器推导表达式类型，但**不计算表达式**。

**易错点**：`decltype` 不计算表达式，只推导类型。`decltype(x + y)` 得到 `double`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <typeinfo>

int main() {
    int x = 10;
    double y = 20.5;

    decltype(x + y) z = x + y;
    std::cout << "z = " << z << std::endl;
    std::cout << "type of z: " << typeid(z).name() << std::endl;

    return 0;
}
```

运行结果（`typeid` 名称因编译器而异）：

```text
z = 30.5
type of z: d
```

<br>

### 一句话总结

<br>

**`decltype` 让编译器推导表达式类型，但不计算表达式，适合声明类型依赖表达式的变量。**

<br>

## 知识点 7：返回类型依赖参数？后置返回类型

***
<br>

### 问题

<br>

你写了一个模板函数 `gt(T1 x, T2 y)`，想返回 `x + y`，但返回类型是什么？`T1` 还是 `T2`？如果是 `int + double`，返回应该是 `double`。写 `T1` 可能截断，写 `T2` 可能不对。怎么办？

<br>

### 方案

<br>

用**后置返回类型**（C++11）：

```cpp
template <class T1, class T2>
auto gt(T1 x, T2 y) -> decltype(x + y) {
    return x + y;
}
```

`auto` 是占位符，真正的返回类型写在 `->` 后面。这样返回类型由 `x + y` 推导。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

template <class T1, class T2>
auto gt(T1 x, T2 y) -> decltype(x + y) {
    return x + y;
}

int main() {
    auto a = gt(3, 4.5);
    std::cout << "a = " << a << std::endl;

    auto b = gt(2.5, 3);
    std::cout << "b = " << b << std::endl;

    return 0;
}
```

运行结果：

```text
a = 7.5
b = 5.5
```

<br>

### 一句话总结

<br>

**后置返回类型用 `auto` 占位，`-> decltype(...)` 写真正的返回类型，解决返回类型依赖参数的问题。**

<br>

## 完整可运行代码
***

下面把本章知识点串一遍：函数模板、重载模板、显式具体化、显式实例化、重载解析、`decltype`、后置返回类型。

```cpp
#include <iostream>
#include <string>
#include <cstring>
#include <typeinfo>

// 通用模板
template <typename T>
void Swap(T& a, T& b) {
    T temp = a;
    a = b;
    b = temp;
}

// 重载模板：数组
template <typename T>
void Swap(T* a, T* b, int n) {
    for (int i = 0; i < n; ++i) {
        T temp = a[i];
        a[i] = b[i];
        b[i] = temp;
    }
}

// Job 结构体
struct Job {
    char name[20];
    double salary;
};

// 显式具体化
template <>
void Swap<Job>(Job& j1, Job& j2) {
    double t = j1.salary;
    j1.salary = j2.salary;
    j2.salary = t;
}

// 显式实例化
template void Swap<int>(int&, int&);

// 普通函数 vs 模板
void show(int x) {
    std::cout << "普通函数: " << x << std::endl;
}

template <typename T>
void show(T x) {
    std::cout << "模板: " << x << std::endl;
}

// 后置返回类型
template <class T1, class T2>
auto gt(T1 x, T2 y) -> decltype(x + y) {
    return x + y;
}

int main() {
    // 函数模板
    int i = 1, j = 2;
    Swap(i, j);
    std::cout << "i = " << i << ", j = " << j << std::endl;

    std::string s1 = "hello", s2 = "world";
    Swap(s1, s2);
    std::cout << "s1 = " << s1 << ", s2 = " << s2 << std::endl;

    // 重载模板
    int a[3] = {1, 2, 3};
    int b[3] = {4, 5, 6};
    Swap(a, b, 3);
    std::cout << "a[0] = " << a[0] << ", b[0] = " << b[0] << std::endl;

    // 显式具体化
    Job job1 = {"Alice", 1000};
    Job job2 = {"Bob", 2000};
    Swap(job1, job2);
    std::cout << job1.name << ": " << job1.salary << std::endl;

    // 重载解析
    show(42);
    show(3.14);

    // decltype
    int x = 10;
    double y = 20.5;
    decltype(x + y) z = x + y;
    std::cout << "z = " << z << std::endl;

    // 后置返回类型
    auto r = gt(3, 4.5);
    std::cout << "gt(3, 4.5) = " << r << std::endl;

    return 0;
}
```

运行结果示例：

```text
i = 2, j = 1
s1 = world, s2 = hello
a[0] = 4, b[0] = 1
Alice: 2000
普通函数: 42
模板: 3.14
z = 30.5
gt(3, 4.5) = 7.5
```

***
