## 一句话概括
***
**一句话**：函数模板用泛型编写一次，编译器为具体类型生成函数；重载、具体化、实例化决定调用哪个版本。

<br>

<br>

## 核心概念
***
### 函数模板
```cpp
template <typename T>
void Swap(T &a, T &b) {
    T temp = a;
    a = b;
    b = temp;
}
```
- `template` 和 `typename`（或 `class`）是关键字。
- `T` 是类型参数，可任意命名。
- 模板本身不生成函数，调用时编译器按类型实例化。
- 模板不能缩短可执行程序，只是让代码更简洁。

<br>

### 重载模板
- 可以像重载普通函数一样重载模板。
- 特征标必须不同。
```cpp
template <typename T>
void Swap(T &a, T &b);

template <typename T>
void Swap(T *a, T *b, int n);
```

<br>

### 显式具体化
- 为特定类型提供专门定义，优先于通用模板。
```cpp
template <>
void Swap<job>(job &j1, job &j2);  // 显式具体化
// 或简化
template <>
void Swap(job &j1, job &j2);
```

<br>

### 显式实例化
- 直接命令编译器创建特定类型的实例。
```cpp
template void Swap<int>(int &, int &);  // 显式实例化
```
- 显式具体化：`template <> void Swap<int>(int &, int &);` 有 `<>`。
- 显式实例化：`template void Swap<int>(int &, int &);` 无 `<>`。

<br>

### 重载解析
1. 创建候选函数列表（同名函数和模板）。
2. 创建可行函数列表（参数匹配）。
3. 确定最佳匹配：
   - 完全匹配 > 提升转换 > 标准转换 > 用户定义转换。
   - 非模板函数优先于模板函数。
   - 更具体的模板优先。

<br>

### decltype（C++11）
- 让编译器推导表达式类型。
```cpp
int x = 10;
double y = 20.5;
decltype(x + y) z;  // z 为 double
```

<br>

### 后置返回类型（C++11）
- 用于返回类型依赖参数的情况。
```cpp
template <class T1, class T2>
auto gt(T1 x, T2 y) -> decltype(x + y) {
    return x + y;
}
```

## 最小代码
***
```cpp
#include <iostream>

// 函数模板
template <typename T>
void Swap(T &a, T &b) {
    T temp = a;
    a = b;
    b = temp;
}

// 显式具体化
struct Job {
    char name[20];
    double salary;
};

template <>
void Swap<Job>(Job &j1, Job &j2) {
    double t = j1.salary;
    j1.salary = j2.salary;
    j2.salary = t;
}

int main() {
    int i = 1, j = 2;
    Swap(i, j);
    std::cout << i << " " << j << std::endl;

    double x = 1.1, y = 2.2;
    Swap(x, y);
    std::cout << x << " " << y << std::endl;

    Job a = {"A", 1000}, b = {"B", 2000};
    Swap(a, b);
    std::cout << a.salary << " " << b.salary << std::endl;

    return 0;
}
```

## 易错点
***
- 模板定义通常放在头文件中，因为编译器需要看到定义才能实例化。
- 显式具体化和显式实例化语法不同，注意 `<>`。
- 模板不能处理所有类型，如数组、结构需要特殊处理。
- `decltype` 不计算表达式，只推导类型。
- 后置返回类型中 `auto` 是占位符，不是自动推导。

<br>

<br>

## 项目用途
***
- 泛型算法、容器用模板实现。
- 需要为特定类型优化时用显式具体化。
- 返回类型依赖参数时用 `decltype` + 后置返回类型。
- 现代 C++ 中模板是 STL 的基础，理解模板有助于使用 STL。
