## 知识点 1：程序为什么要分成多个文件？单独编译

***
<br>

### 问题

<br>

你写了一个小项目，所有代码都塞在一个 `.cpp` 里。后来功能多了，文件越来越长，改一个函数得翻半天。能不能拆成多个文件？拆了之后，声明和定义分别放哪？

<br>

### 方案

<br>

C++ 支持**单独编译**。程序通常分为三部分：

- **头文件**（`.h`）：放函数原型、类声明、模板定义、内联函数、符号常量。
- **源代码文件**（`.cpp`）：放函数定义、类方法定义。
- **客户文件**（`main.cpp` 等）：使用这些功能。

头文件要加**头文件卫哨**，防止重复包含：

```cpp
#ifndef MYHEADER_H
#define MYHEADER_H
// ...
#endif
```

**易错点**：头文件中不要定义全局变量，否则多个源文件包含它时会导致多重定义。

<br>

### 最小示例

<br>

三个文件：

```cpp
// mymath.h
#ifndef MYMATH_H
#define MYMATH_H

namespace MyMath {
    int add(int a, int b);
    int sub(int a, int b);
}

#endif
```

```cpp
// mymath.cpp
#include "mymath.h"

namespace MyMath {
    int add(int a, int b) { return a + b; }
    int sub(int a, int b) { return a - b; }
}
```

```cpp
// main.cpp
#include <iostream>
#include "mymath.h"

int main() {
    std::cout << MyMath::add(1, 2) << std::endl;
    std::cout << MyMath::sub(5, 3) << std::endl;
    return 0;
}
```

编译运行：

```bash
g++ main.cpp mymath.cpp -o main
./main
```

运行结果：

```text
3
2
```

<br>

### 一句话总结

<br>

**头文件放声明，源文件放定义，客户文件负责用；头文件卫哨防止重复包含，头文件里别定义全局变量。**

<br>

## 知识点 2：变量能活多久？存储持续性

***
<br>

### 问题

<br>

你写了一个局部变量，函数结束它就没了。你又写了一个全局变量，程序跑完它才销毁。还有一个 `static` 局部变量，函数调用多次它还记得上次的值。这些变量到底存在哪？活多久？

<br>

### 方案

<br>

C++ 有四种存储持续性：

| 类型 | 关键字 | 生命周期 | 存储位置 |
|---|---|---|---|
| 自动 | 无 | 函数调用期间 | 栈 |
| 静态 | `static` / 全局 | 程序整个运行期 | 静态区 |
| 动态 | `new` | 手动释放前 | 堆/自由存储区 |
| 线程 | `thread_local` | 线程期间 | 线程存储区 |

```cpp
int global = 10;              // 静态存储期，外部链接
static int file_scope = 20;   // 静态存储期，内部链接

void func() {
    int local = 30;           // 自动存储期
    static int count = 0;     // 静态存储期，局部作用域
    count++;
}
```

<br>

### 最小示例

<br>

```cpp
#include <iostream>

int global = 100;              // 静态存储期

void func() {
    int local = 10;            // 自动存储期
    static int count = 0;      // 静态存储期，只初始化一次
    count++;
    std::cout << "local = " << local
              << ", count = " << count << std::endl;
}

int main() {
    func();
    func();
    func();

    int* p = new int(42);      // 动态存储期
    std::cout << "dynamic = " << *p << std::endl;
    delete p;

    std::cout << "global = " << global << std::endl;
    return 0;
}
```

运行结果：

```text
local = 10, count = 1
local = 10, count = 2
local = 10, count = 3
dynamic = 42
global = 100
```

<br>

### 一句话总结

<br>

**自动变量随函数结束销毁，静态变量活到程序结束，动态内存手动释放，线程变量跟线程走。**

<br>

## 知识点 3：名字能见多远？作用域与链接性

***
<br>

### 问题

<br>

你在 `file1.cpp` 里定义了一个全局变量 `x`，想在 `file2.cpp` 里用，怎么写？如果你不想让 `file2.cpp` 看到，又该怎么写？

<br>

### 方案

<br>

- **作用域**：名字在代码中可见的范围。
- **链接性**：名字能否在多个编译单元中共享。
  - **外部链接**：全局变量、普通函数，可被其他文件使用。
  - **内部链接**：`static` 全局变量/函数，仅限本文件。
  - **无链接**：局部变量、`static` 局部变量。

```cpp
// file1.cpp
int x = 10;                   // 外部链接，file2.cpp 可以用 extern int x;
static int y = 20;            // 内部链接，file2.cpp 看不到

// file2.cpp
extern int x;                 // 声明，引用 file1.cpp 的 x
// extern int y;              // 错误，y 是内部链接
```

**易错点**：`extern` 是声明，不是定义。不要重复定义。

<br>

### 最小示例

<br>

```cpp
// file1.cpp
int shared = 100;             // 外部链接
static int hidden = 200;      // 内部链接

// file2.cpp
#include <iostream>

extern int shared;            // 声明外部变量

int main() {
    std::cout << "shared = " << shared << std::endl;
    // std::cout << hidden << std::endl;  // 错误：hidden 不可见
    return 0;
}
```

编译运行：

```bash
g++ file1.cpp file2.cpp -o main
./main
```

运行结果：

```text
shared = 100
```

<br>

### 一句话总结

<br>

**外部链接大家都能用，内部链接只限本文件，无链接只限局部；`extern` 是声明不是定义。**

<br>

## 知识点 4：名字冲突怎么办？命名空间

***
<br>

### 问题

<br>

你写了一个 `log` 函数，结果和标准库的 `log` 冲突。或者两个库都有 `init` 函数，编译器不知道用哪个。怎么避免名字冲突？

<br>

### 方案

<br>

用**命名空间**。每个模块一个命名空间，调用时写 `命名空间::名字`。可以用别名简化，也可以用匿名命名空间隐藏文件内部实现。

```cpp
namespace MyProject {
    namespace Utils {
        void log(const std::string& msg);
    }
}

// 使用
MyProject::Utils::log("hello");

// 别名
namespace U = MyProject::Utils;
U::log("hello");

// 匿名命名空间：仅本文件可见
namespace {
    int file_local = 42;
}
```

**易错点**：不要用 `using namespace std;` 在头文件中。匿名命名空间可以替代 `static` 全局变量。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <string>

namespace MyProject {
    namespace Utils {
        void log(const std::string& msg) {
            std::cout << "[LOG] " << msg << std::endl;
        }
    }
}

namespace {
    int file_local = 42;   // 仅本文件可见
}

int main() {
    MyProject::Utils::log("hello");

    namespace U = MyProject::Utils;   // 别名
    U::log("world");

    std::cout << "file_local = " << file_local << std::endl;
    return 0;
}
```

运行结果：

```text
[LOG] hello
[LOG] world
file_local = 42
```

<br>

### 一句话总结

<br>

**命名空间就是给名字加个前缀，避免冲突；别名简化书写，匿名命名空间隐藏文件内部实现。**

<br>

## 完整可运行代码
***

下面把本章知识点串一遍：多文件编译、头文件卫哨、存储持续性、链接性、命名空间。

```cpp
// mymath.h
#ifndef MYMATH_H
#define MYMATH_H

namespace MyMath {
    int add(int a, int b);
    int sub(int a, int b);
}

#endif
```

```cpp
// mymath.cpp
#include "mymath.h"

namespace MyMath {
    int add(int a, int b) { return a + b; }
    int sub(int a, int b) { return a - b; }
}
```

```cpp
// main.cpp
#include <iostream>
#include <string>
#include "mymath.h"

// 匿名命名空间：仅本文件可见
namespace {
    int file_local = 42;
}

// 全局变量，外部链接
int global_var = 100;

// static 全局变量，内部链接
static int hidden_var = 200;

void func() {
    static int count = 0;   // 静态存储期，局部作用域
    count++;
    std::cout << "count = " << count << std::endl;
}

int main() {
    std::cout << "MyMath::add(1,2) = " << MyMath::add(1, 2) << std::endl;
    std::cout << "MyMath::sub(5,3) = " << MyMath::sub(5, 3) << std::endl;

    func();
    func();

    std::cout << "global_var = " << global_var << std::endl;
    std::cout << "hidden_var = " << hidden_var << std::endl;
    std::cout << "file_local = " << file_local << std::endl;

    return 0;
}
```

编译运行：

```bash
g++ main.cpp mymath.cpp -o main
./main
```

运行结果示例：

```text
MyMath::add(1,2) = 3
MyMath::sub(5,3) = 2
count = 1
count = 2
global_var = 100
hidden_var = 200
file_local = 42
```
