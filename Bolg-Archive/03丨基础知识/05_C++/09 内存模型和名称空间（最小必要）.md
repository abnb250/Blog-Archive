## 核心概念
***
### 单独编译
- 程序分为三部分：头文件（声明）、源代码文件（定义）、客户文件（使用）。
- 头文件放：函数原型、类声明、模板定义、内联函数、符号常量。
- 源文件放：函数定义、类方法定义。
- 头文件卫哨防止重复包含：
```cpp
#ifndef MYHEADER_H
#define MYHEADER_H
// ...
#endif
```

<br>

### 存储持续性
| 类型 | 关键字 | 生命周期 | 存储位置 |
|---|---|---|---|
| 自动 | 无 | 函数调用期间 | 栈 |
| 静态 | `static` / 全局 | 程序整个运行期 | 静态区 |
| 动态 | `new` | 手动释放前 | 堆/自由存储区 |
| 线程 | `thread_local` | 线程期间 | 线程存储区 |

```cpp
int global = 10;              // 静态存储期，外部链接
static int file_scope = 20;   // 静态存储期，内部链接

void func() {
    int local = 30;           // 自动存储期
    static int count = 0;     // 静态存储期，局部作用域
    count++;
}
```

<br>

### 作用域与链接性
- **作用域**：名字在代码中可见的范围。
- **链接性**：名字能否在多个编译单元中共享。
  - 外部链接：全局变量、普通函数，可被其他文件使用。
  - 内部链接：`static` 全局变量/函数，仅限本文件。
  - 无链接：局部变量、`static` 局部变量。

```cpp
// file1.cpp
int x = 10;                   // 外部链接，file2.cpp 可以用 extern int x;
static int y = 20;            // 内部链接，file2.cpp 看不到

// file2.cpp
extern int x;                 // 声明，引用 file1.cpp 的 x
// extern int y;              // 错误，y 是内部链接
```

<br>

### 命名空间
- 避免名字冲突，项目每个模块一个命名空间。
- 不要用 `using namespace std;` 在头文件中。
- 匿名命名空间替代 `static` 全局变量（C++ 推荐）。

```cpp
namespace MyProject {
    namespace Utils {
        void log(const std::string& msg);
    }
}

// 使用
MyProject::Utils::log("hello");

// 别名简化
namespace U = MyProject::Utils;
U::log("hello");

// 匿名命名空间：仅本文件可见
namespace {
    int file_local = 42;
}
```

## 最小代码
***
```cpp
// mymath.h
#ifndef MYMATH_H
#define MYMATH_H

namespace MyMath {
    int add(int a, int b);
    int sub(int a, int b);
}

#endif
```

```cpp
// mymath.cpp
#include "mymath.h"

namespace MyMath {
    int add(int a, int b) { return a + b; }
    int sub(int a, int b) { return a - b; }
}
```

```cpp
// main.cpp
#include <iostream>
#include "mymath.h"

int main() {
    std::cout << MyMath::add(1, 2) << std::endl;
    return 0;
}
```

编译：
```bash
g++ main.cpp mymath.cpp -o main
```

## 易错点
***
- 头文件中不要定义全局变量（多重定义）。
- `static` 全局变量和匿名命名空间的区别：匿名命名空间可以包含类定义。
- `extern` 是声明，不是定义。
- 命名空间别名要放在使用之前。

<br>

<br>

## 项目用途
***
- 多文件编译是项目基础，CMake 就是管理这个的。
- 每个模块用自己的命名空间，避免冲突。
- 匿名命名空间隐藏文件内部实现。
