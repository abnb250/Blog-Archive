## 一句话概括
***
**一句话**：类将数据表示和操作封装在一起；接口与实现分离，数据隐藏。

<br>

<br>

## 核心概念
***
- 类声明：`private` / `public`，数据成员，成员函数。
- 封装：数据私有，公有方法访问。
- 成员函数定义：`返回类型 类名::函数名(参数) { }`，类内定义自动内联。
- 构造函数：初始化对象，与类同名，无返回类型。默认构造函数、初始化列表。
- 析构函数：`~类名()`，释放资源。
- `const` 成员函数：不修改对象，`void show() const;`
- `this` 指针：指向调用对象。
- 对象数组。
- 类作用域：`类名::成员`。
- 作用域内枚举：`enum class`。

<br>

<br>

## 最小代码
***
```cpp
class Stock {
private:
    std::string company;
    long shares;
    double share_val;
    double total_val;
    void set_tot() { total_val = shares * share_val; }
public:
    Stock();
    Stock(const std::string& co, long n = 0, double pr = 0.0);
    ~Stock();
    void buy(long num, double price);
    void sell(long num, double price);
    void update(double price);
    void show() const;
};
```

<br>

<br>

## 易错点
***
- 构造函数无返回类型。
- 默认构造函数：如果定义了其他构造函数，必须提供默认构造函数。
- 析构函数在对象销毁时自动调用。
- `const` 对象只能调用 `const` 成员函数。
- 类内定义成员函数自动内联。

<br>

<br>

## 项目用途
***
- 用类封装数据和行为，接口稳定。
- RAII：构造函数获取资源，析构函数释放。
