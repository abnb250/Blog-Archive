你是不是也写过这样的代码：几个变量分别存公司名、股数、单价、总价值，然后一堆函数传来传去。买卖股票的时候，你手动更新股数、更新单价，结果忘了更新总价值——数据就打架了。

```cpp
std::string company = "Apple";
long shares = 100;
double share_val = 150.0;
double total_val = shares * share_val;

// 买 50 股
shares += 50;
share_val = 160.0;
// total_val 忘了更新，数据不一致了
```

更麻烦的是，如果你有 100 只股票，每个变量都得单独维护，函数参数一长串，改一个地方得翻半天。

能不能把数据和操作绑在一起？能不能让“买”这个动作自动更新总价值？这就是**类**要解决的问题。

## 知识点 1：用类把数据和操作封装在一起
***

<br>

### 问题

刚才那堆散落的变量，能不能打包成一个整体？外面想买卖股票，只能通过公开接口操作，不能直接乱改数据。

<br>

### 方案

用 **类（class）**。类把数据表示和操作封装在一起。数据通常放 `private`，外面不能直接碰；操作放 `public`，作为对外接口。这就是 **封装** 和 **数据隐藏**。

成员函数可以在类内定义，也可以在类外定义。**类内定义的成员函数自动内联**。类外定义要写 `返回类型 类名::函数名(参数) { }`，其中 `::` 是**类作用域**限定符。

<br>

### 最小示例

```cpp
#include <iostream>
#include <string>

class Stock {
private:
    std::string company;
    long shares;
    double share_val;
    double total_val;

    void set_tot() { total_val = shares * share_val; }  // 类内定义，自动内联

public:
    void set(const std::string& co, long n, double pr) {
        company = co;
        shares = n;
        share_val = pr;
        set_tot();
    }

    void show() const {
        std::cout << "Company: " << company
                  << ", Shares: " << shares
                  << ", Share Price: " << share_val
                  << ", Total: " << total_val << std::endl;
    }
};

int main() {
    Stock s;
    s.set("Apple", 100, 150.0);
    s.show();
    return 0;
}
```

运行结果：

```text
Company: Apple, Shares: 100, Share Price: 150, Total: 15000
```

注意 `set_tot` 放在 `private` 里，外面调不到，但 `set` 和 `show` 能调。这样**总价值永远不会被外部乱改**。

<br>

### 一句话总结

**类就是给数据找个家，把操作也搬进去，外面只能通过公开接口访问，数据不再裸奔。**

## 知识点 2：构造函数——对象出生时自动初始化
***

<br>

### 问题

刚才的 `Stock s;` 创建完对象后，`company`、`shares` 都是随机值，必须再调用 `set` 才能用。能不能创建对象时就自动初始化？

<br>

### 方案

用 **构造函数**。构造函数与类同名，**没有返回类型**（连 `void` 都不要写），在对象创建时自动调用。可以重载，也可以带默认参数。

初始化数据成员推荐用 **初始化列表**，写在构造函数参数列表后面，用冒号开头。初始化列表在对象创建时直接初始化成员，效率更高，也更清晰。

这里有个大坑：**如果你定义了任何其他构造函数，编译器就不再自动提供默认构造函数了**。这时如果你还想写 `Stock s;`，必须自己提供一个默认构造函数，否则编译报错。

<br>

### 最小示例

```cpp
#include <iostream>
#include <string>

class Stock {
private:
    std::string company;
    long shares;
    double share_val;
    double total_val;

    void set_tot() { total_val = shares * share_val; }

public:
    // 默认构造函数
    Stock() : company("no name"), shares(0), share_val(0.0), total_val(0.0) {}

    // 带参数的构造函数，使用初始化列表
    Stock(const std::string& co, long n = 0, double pr = 0.0)
        : company(co), shares(n), share_val(pr) {
        set_tot();
    }

    void show() const {
        std::cout << "Company: " << company
                  << ", Shares: " << shares
                  << ", Share Price: " << share_val
                  << ", Total: " << total_val << std::endl;
    }
};

int main() {
    Stock s1;                       // 调用默认构造函数
    Stock s2("Apple", 100, 150.0);  // 调用带参构造函数
    s1.show();
    s2.show();
    return 0;
}
```

运行结果：

```text
Company: no name, Shares: 0, Share Price: 0, Total: 0
Company: Apple, Shares: 100, Share Price: 150, Total: 15000
```

**易错点**：构造函数没有返回类型，写了 `void` 或 `int` 都会报错。如果你只写了 `Stock(const std::string& co, long n, double pr)` 而没写默认构造函数，`Stock s;` 就会编译失败。

<br>

### 一句话总结

**构造函数就是对象的“出生仪式”，负责把数据成员初始化好，没有返回类型，推荐用初始化列表。**

<br>

## 知识点 3：析构函数——对象销毁时自动清理
***

<br>

### 问题

对象用完销毁时，如果它占了资源（比如动态内存、文件句柄），谁来释放？总不能每次都手动写清理代码吧？

<br>

### 方案

用 **析构函数**。析构函数名是 `~类名()`，**没有参数、没有返回类型、不能重载**。对象生命周期结束时自动调用。这就是 **RAII**（资源获取即初始化）的雏形：构造函数获取资源，析构函数释放资源。

<br>

### 最小示例

```cpp
#include <iostream>
#include <string>

class Stock {
private:
    std::string company;
public:
    Stock(const std::string& co) : company(co) {
        std::cout << "Stock " << company << " created." << std::endl;
    }

    ~Stock() {
        std::cout << "Stock " << company << " destroyed." << std::endl;
    }
};

int main() {
    Stock s1("Apple");
    {
        Stock s2("Google");
    }  // s2 在这里销毁
    std::cout << "End of main." << std::endl;
    return 0;
}
```

运行结果：

```text
Stock Apple created.
Stock Google created.
Stock Google destroyed.
End of main.
Stock Apple destroyed.
```

对象销毁的顺序和创建相反：`s2` 先创建后销毁，`s1` 后创建最后销毁。

**易错点**：析构函数不能有参数，不能重载，也不能写返回类型。一个类只能有一个析构函数。另外，析构函数里不要抛异常，否则可能导致程序终止。

<br>

### 一句话总结

**析构函数就是对象的“临终遗言”，对象销毁时自动调用，用来释放资源。**

<br>

## 知识点 4：`const` 成员函数——`const` 对象只能调用 `const` 方法
***

<br>

### 问题

你有一个 `const Stock` 对象，想调用 `show()` 打印信息，结果编译器报错：

```text
error: passing 'const Stock' as 'this' argument discards qualifiers
```

为什么？

<br>

### 方案

因为 `show()` 没有标记 `const`，编译器认为它可能会修改对象。`const` 对象只能调用 **`const` 成员函数**。在成员函数参数列表后面加 `const`，表示这个函数不会修改对象。

写法：`void show() const;`

<br>

### 最小示例

```cpp
#include <iostream>
#include <string>

class Stock {
private:
    std::string company;
    long shares;
public:
    Stock(const std::string& co, long n) : company(co), shares(n) {}

    void show() const {   // const 成员函数
        std::cout << company << ": " << shares << std::endl;
    }

    void buy(long num) {  // 非 const 成员函数，会修改对象
        shares += num;
    }
};

int main() {
    const Stock s("Apple", 100);
    s.show();     // 正确：const 对象调用 const 成员函数
    // s.buy(10); // 错误：const 对象不能调用非 const 成员函数
    return 0;
}
```

运行结果：

```text
Apple: 100
```

**易错点**：`const` 成员函数内部不能修改数据成员（除非成员被声明为 `mutable`）。另外，非 `const` 对象既可以调用 `const` 成员函数，也可以调用非 `const` 成员函数；但 `const` 对象只能调用 `const` 成员函数。

<br>

### 一句话总结

**`const` 成员函数就是向编译器保证“我不改对象”，这样 `const` 对象才敢调用你。**

<br>

## 知识点 5：`this` 指针——成员函数怎么知道操作的是哪个对象？
***

<br>

### 问题

你写 `s1.show()` 和 `s2.show()`，同一个 `show()` 函数，怎么知道打印的是 `s1` 还是 `s2` 的数据？

<br>

### 方案

每个成员函数都有一个隐藏的 **`this` 指针**，指向调用该函数的对象。在成员函数里写 `shares`，实际上就是 `this->shares`。`this` 让成员函数知道“我在为哪个对象服务”。

`this` 也可以用来返回对象自身，实现链式调用。

<br>

### 最小示例

```cpp
#include <iostream>

class Counter {
private:
    int value;
public:
    Counter(int v = 0) : value(v) {}

    Counter& add(int n) {
        value += n;
        return *this;   // 返回当前对象
    }

    void show() const {
        std::cout << "Value: " << value << std::endl;
    }
};

int main() {
    Counter c;
    c.add(5).add(10).add(20);  // 链式调用
    c.show();
    return 0;
}
```

运行结果：

```text
Value: 35
```

**易错点**：`this` 是指针，不是对象。要返回对象自身用 `*this`。在 `const` 成员函数里，`this` 的类型是 `const 类名*`，不能通过它修改成员。

<br>

### 一句话总结

**`this` 就是成员函数里的“我”，指向当前调用对象，返回 `*this` 就能实现链式调用。**

<br>

## 知识点 6：对象数组、类作用域和 `enum class`
***

<br>

### 问题

你需要管理多只股票，难道要定义 `s1`、`s2`、`s3`……？还有，枚举类型如果名字冲突怎么办？比如两个类里都有 `Red`。

<br>

### 方案

- **对象数组**：像普通数组一样，可以创建对象数组，每个元素都是一个对象。
- **类作用域**：类名本身是一个作用域，成员用 `类名::成员` 访问。类外定义成员函数必须写 `类名::`。
- **作用域内枚举 `enum class`**：枚举值被限制在枚举类型内部，不会污染外层作用域，也避免名字冲突。使用时必须写 `Color::Red`，不能直接写 `Red`。

<br>

### 最小示例

```cpp
#include <iostream>
#include <string>

enum class Color { Red, Green, Blue };

class Stock {
private:
    std::string company;
    long shares;
public:
    Stock() : company("no name"), shares(0) {}
    Stock(const std::string& co, long n) : company(co), shares(n) {}

    void show() const {
        std::cout << company << ": " << shares << std::endl;
    }
};

int main() {
    Stock portfolio[3] = {
        Stock("Apple", 100),
        Stock("Google", 200),
        Stock("Microsoft", 150)
    };

    for (int i = 0; i < 3; ++i) {
        portfolio[i].show();
    }

    Color c = Color::Red;
    if (c == Color::Red) {
        std::cout << "Color is Red" << std::endl;
    }

    return 0;
}
```

运行结果：

```text
Apple: 100
Google: 200
Microsoft: 150
Color is Red
```

**易错点**：`enum class` 的值必须加 `Color::` 前缀，不能直接写 `Red`。普通 `enum` 没有这个限制，但容易造成名字冲突。对象数组的每个元素是**对象**，不是指针，所以 `portfolio[i].show()` 直接用点号。

<br>

### 一句话总结

**对象数组让你批量管理对象；类作用域用 `类名::` 限定成员；`enum class` 让枚举值带上类型前缀，避免污染和冲突。**

<br>

## 完整可运行代码
***

下面是一个完整的 `Stock` 类示例，包含构造函数、析构函数、`const` 成员函数、`this` 指针、对象数组和 `enum class`。你可以直接复制运行。

```cpp
#include <iostream>
#include <string>

enum class StockStatus { Normal, Suspended };

class Stock {
private:
    std::string company;
    long shares;
    double share_val;
    double total_val;

    void set_tot() {
        total_val = shares * share_val;
    }

public:
    // 默认构造函数
    Stock() : company("no name"), shares(0), share_val(0.0), total_val(0.0) {
        std::cout << "Default Stock created." << std::endl;
    }

    // 带参构造函数
    Stock(const std::string& co, long n = 0, double pr = 0.0)
        : company(co), shares(n), share_val(pr) {
        set_tot();
        std::cout << "Stock " << company << " created." << std::endl;
    }

    // 析构函数
    ~Stock() {
        std::cout << "Stock " << company << " destroyed." << std::endl;
    }

    // const 成员函数
    void show() const {
        std::cout << "Company: " << company
                  << ", Shares: " << shares
                  << ", Share Price: " << share_val
                  << ", Total: " << total_val << std::endl;
    }

    // 非 const 成员函数，返回 *this 支持链式调用
    Stock& buy(long num, double price) {
        if (num < 0) {
            std::cout << "Number of shares cannot be negative." << std::endl;
            return *this;
        }
        shares += num;
        share_val = price;
        set_tot();
        return *this;
    }

    Stock& sell(long num, double price) {
        if (num > shares) {
            std::cout << "You cannot sell more than you have." << std::endl;
            return *this;
        }
        shares -= num;
        share_val = price;
        set_tot();
        return *this;
    }

    void update(double price) {
        share_val = price;
        set_tot();
    }
};

int main() {
    std::cout << "=== 创建对象数组 ===" << std::endl;
    Stock portfolio[3] = {
        Stock("Apple", 100, 150.0),
        Stock("Google", 200, 120.0),
        Stock("Microsoft", 150, 200.0)
    };

    std::cout << "\n=== 显示初始状态 ===" << std::endl;
    for (int i = 0; i < 3; ++i) {
        portfolio[i].show();
    }

    std::cout << "\n=== 买卖操作 ===" << std::endl;
    portfolio[0].buy(50, 160.0).sell(30, 170.0);
    portfolio[0].show();

    std::cout << "\n=== enum class 示例 ===" << std::endl;
    StockStatus status = StockStatus::Normal;
    if (status == StockStatus::Normal) {
        std::cout << "Stock status: Normal" << std::endl;
    }

    std::cout << "\n=== 程序结束，对象自动销毁 ===" << std::endl;
    return 0;
}
```

运行结果示例：

```text
=== 创建对象数组 ===
Stock Apple created.
Stock Google created.
Stock Microsoft created.

=== 显示初始状态 ===
Company: Apple, Shares: 100, Share Price: 150, Total: 15000
Company: Google, Shares: 200, Share Price: 120, Total: 24000
Company: Microsoft, Shares: 150, Share Price: 200, Total: 30000

=== 买卖操作 ===
Company: Apple, Shares: 120, Share Price: 170, Total: 20400

=== enum class 示例 ===
Stock status: Normal

=== 程序结束，对象自动销毁 ===
Stock Microsoft destroyed.
Stock Google destroyed.
Stock Apple destroyed.
```
