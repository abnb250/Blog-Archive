你写了一个 `Time` 类，里面有时、分。现在你想写：

```cpp
Time t1(2, 45);
Time t2(1, 30);
Time t3 = t1 + t2;   // 编译器：+ 不认识 Time，报错
std::cout << t1;     // 编译器：<< 不认识 Time，报错
int total = t1;      // 编译器：不能把 Time 转成 int，报错
```

你心想：内置类型 `int` 能加、能输出、能转，为什么我的类不行？

因为编译器只认识内置类型的运算符。想让自定义类也享受这些待遇，就得**运算符重载**。但重载不是万能的，有些情况成员函数搞不定，得请**友元**帮忙；有些转换太危险，得用 `explicit` 拦住；有些数据所有对象共享，得用**静态成员**。

这一章咱们就顺着这些问题，一个个解决。

## 知识点 1：t1 + t2 报错？用成员函数重载 operator+

***
<br>

### 问题

<br>

你写了 `Time` 类，想直接 `t1 + t2`，编译器说 `no operator "+" matches these operands`。怎么办？

<br>

### 方案

<br>

在类里定义一个 **成员函数 `operator+`**。它的名字固定是 `operator` 加运算符符号，比如 `operator+`。成员函数重载时，左操作数必须是本类对象（或本类对象的引用）。`t1 + t2` 会被解释成 `t1.operator+(t2)`。

注意：**运算符重载不能改变优先级和结合性**。`+` 还是先乘除后加减，别指望重载能改。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

class Time {
private:
    int hours;
    int minutes;
public:
    Time(int h = 0, int m = 0) : hours(h), minutes(m) {
        // 处理分钟进位
        while (minutes >= 60) {
            minutes -= 60;
            hours += 1;
        }
    }

    Time operator+(const Time& t) const {
        return Time(hours + t.hours, minutes + t.minutes);
    }

    void show() const {
        std::cout << hours << " hours, " << minutes << " minutes" << std::endl;
    }
};

int main() {
    Time t1(2, 45);
    Time t2(1, 30);
    Time t3 = t1 + t2;   // 调用 t1.operator+(t2)
    t3.show();
    return 0;
}
```

运行结果：

```text
4 hours, 15 minutes
```

<br>

### 一句话总结

<br>

**成员 `operator+` 让对象能像内置类型一样相加，左操作数必须是本类对象。**

<br>

## 知识点 2：`2 * t1` 报错？非成员重载 + 友元来帮忙

***
<br>

### 问题

<br>

你写 `Time t2 = 2 * t1;`，想让时间翻倍。但 `2` 是 `int`，不是 `Time` 对象，所以成员函数 `operator*` 用不了。编译器报错：`no operator "*" matches these operands`。

<br>

### 方案

<br>

用**非成员函数**重载 `operator*`。非成员函数不在类里，左操作数可以是 `double` 或 `int`。但非成员函数不能直接访问 `Time` 的私有成员 `hours` 和 `minutes`。这时需要**友元**：在类里用 `friend` 声明这个函数，给它开个后门，让它能访问私有成员。

友元不是成员，不能被继承。友元可以是函数，也可以是类，还可以是另一个类的成员函数。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

class Time {
private:
    int hours;
    int minutes;
public:
    Time(int h = 0, int m = 0) : hours(h), minutes(m) {
        while (minutes >= 60) {
            minutes -= 60;
            hours += 1;
        }
    }

    // 声明友元函数
    friend Time operator*(double m, const Time& t);

    void show() const {
        std::cout << hours << " hours, " << minutes << " minutes" << std::endl;
    }
};

// 非成员函数，因为声明了友元，可以访问私有成员
Time operator*(double m, const Time& t) {
    int total = static_cast<int>(m * (t.hours * 60 + t.minutes));
    return Time(total / 60, total % 60);
}

int main() {
    Time t1(2, 45);
    Time t2 = 2.5 * t1;   // 调用非成员 operator*
    t2.show();
    return 0;
}
```

运行结果：

```text
6 hours, 52 minutes
```

<br>

### 一句话总结

<br>

**友元就是给外部函数开个后门，让它能访问私有成员；非成员重载解决左操作数不是本类对象的情况。**

<br>

## 知识点 3：友元到底是什么？给外部函数开个后门

***
<br>

### 问题

<br>

上一步的非成员 `operator*` 为什么能访问 `Time` 的私有成员？因为我们在类里写了 `friend`。那友元到底是怎么回事？能用在哪些地方？

<br>

### 方案

<br>

**友元（friend）** 是在类里用 `friend` 关键字声明的一个函数、类或成员函数。声明之后，这个“朋友”就能访问该类的 `private` 和 `protected` 成员。

友元声明可以放在类里的任何位置，`public`、`private`、`protected` 都行，效果一样。常见形式：

- 友元函数：`friend Time operator*(double, const Time&);`
- 友元类：`friend class Timer;`
- 友元成员函数：`friend void Timer::sync(Time&);`

注意：**友元不是成员，不能被继承。** 它只是获得了访问权限，并不属于这个类。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

class Time {
private:
    int hours;
    int minutes;
public:
    Time(int h = 0, int m = 0) : hours(h), minutes(m) {}

    // 友元函数，可以访问私有成员
    friend void print_time(const Time& t);
};

void print_time(const Time& t) {
    std::cout << "Time: " << t.hours << ":" << t.minutes << std::endl;
}

int main() {
    Time t(2, 45);
    print_time(t);   // 友元函数直接访问私有成员
    return 0;
}
```

运行结果：

```text
Time: 2:45
```

<br>

### 一句话总结

<br>

**友元就是给外部函数或类开个后门，让它能访问私有成员；友元不是成员，不能被继承。**

<br>

## 知识点 4：`std::cout << t1` 报错？重载 `<<` 运算符

***
<br>

### 问题

<br>

你想直接 `std::cout << t1;` 输出时间，而不是每次都 `t1.show()`。但编译器报错：`no operator "<<" matches these operands`。

<br>

### 方案

<br>

重载 `operator<<`。注意它**不能是成员函数**，因为左操作数是 `std::ostream` 对象，不是你的类对象。所以必须写成非成员函数，通常声明为友元，以便访问私有成员。

返回类型是 `std::ostream&`，并且返回 `os`。**返回 `os` 是为了支持链式输出**，比如 `std::cout << t1 << t2;`。如果不返回 `os`，链式调用就断了。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

class Time {
private:
    int hours;
    int minutes;
public:
    Time(int h = 0, int m = 0) : hours(h), minutes(m) {
        while (minutes >= 60) {
            minutes -= 60;
            hours += 1;
        }
    }

    friend std::ostream& operator<<(std::ostream& os, const Time& t);
};

std::ostream& operator<<(std::ostream& os, const Time& t) {
    os << t.hours << " hours, " << t.minutes << " minutes";
    return os;   // 返回 os 以支持链式
}

int main() {
    Time t1(2, 45);
    Time t2(1, 30);
    std::cout << t1 << std::endl;
    std::cout << t1 << " and " << t2 << std::endl;
    return 0;
}
```

运行结果：

```text
2 hours, 45 minutes
2 hours, 45 minutes and 1 hours, 30 minutes
```

<br>

### 一句话总结

<br>

**`<<` 重载返回 `ostream&` 是为了支持连续输出，比如 `cout << t1 << t2;`，它必须是非成员函数。**

<br>

## 知识点 5：`int total = t1;` 报错？类型转换与 explicit

***
<br>

### 问题

<br>

你写 `int total = t1;` 想得到总分钟数，编译器报错：`cannot convert 'Time' to 'int'`。反过来，`Time t = 90;` 也想把分钟数自动转成 `Time`，同样报错。

<br>

### 方案

<br>

两种转换方向：

- **其他类型 → 类**：用**构造函数**。比如 `Time(int m)` 可以把 `int` 转成 `Time`。
- **类 → 其他类型**：用**转换函数**。写法是 `operator 类型名() const;`，比如 `operator int() const;`。转换函数没有返回类型，因为类型名已经写在 `operator` 后面了。

隐式转换虽然方便，但可能造成二义性或意外转换。用 **`explicit`** 可以禁止隐式转换，要求必须显式写 `static_cast<int>(t1)` 或 `int(t1)`。

注意：**不能重载的运算符**包括 `::`、`.*`、`?:`、`sizeof`、`typeid`，以及 `static_cast`、`dynamic_cast` 等强制类型转换运算符。但**转换函数**（如 `operator int()`）是可以重载的，原文里“强制转换运算符不能重载”的说法容易让人误解，这里区分一下。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

class Time {
private:
    int hours;
    int minutes;
public:
    Time(int h = 0, int m = 0) : hours(h), minutes(m) {
        while (minutes >= 60) {
            minutes -= 60;
            hours += 1;
        }
    }

    // 转换函数：Time -> int
    operator int() const {
        return hours * 60 + minutes;
    }

    void show() const {
        std::cout << hours << " hours, " << minutes << " minutes" << std::endl;
    }
};

int main() {
    Time t1(2, 45);
    int total = t1;   // 隐式调用 operator int()
    std::cout << "Total minutes: " << total << std::endl;

    // 如果转换函数加了 explicit，下面这行会报错，必须写 int total = static_cast<int>(t1);
    return 0;
}
```

运行结果：

```text
Total minutes: 165
```

如果把 `operator int()` 改成 `explicit operator int() const`，那么 `int total = t1;` 会编译失败，必须写 `int total = static_cast<int>(t1);`。

<br>

### 一句话总结

<br>

**转换函数让类能变成其他类型，构造函数让其他类型能变成类；`explicit` 防止编译器偷偷转换。**

<br>

## 知识点 6：统计对象个数？静态成员必须在类外定义

***
<br>

### 问题

<br>

你想知道程序里一共创建了多少个 `Time` 对象。普通成员变量每个对象一份，各记各的，没法共享。怎么办？

<br>

### 方案

<br>

用**静态数据成员**。在类里写 `static int count;`，它属于类，不属于某个对象，所有对象共享同一份。**静态成员必须在类外定义并初始化**，这是最常见的报错原因：只写了类内声明，链接时会报 `undefined reference`。

**静态成员函数**没有 `this` 指针，所以只能访问静态成员，不能访问非静态成员。调用时用 `类名::函数名()`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

class Time {
private:
    int hours;
    int minutes;
    static int count;   // 静态成员声明
public:
    Time(int h = 0, int m = 0) : hours(h), minutes(m) {
        while (minutes >= 60) {
            minutes -= 60;
            hours += 1;
        }
        count++;   // 每创建一个对象，计数加一
    }

    static int get_count() {   // 静态成员函数
        return count;
    }
};

int Time::count = 0;   // 类外定义并初始化，必须写！

int main() {
    Time t1(2, 45);
    Time t2(1, 30);
    Time t3(0, 90);

    std::cout << "Number of Time objects: " << Time::get_count() << std::endl;
    return 0;
}
```

运行结果：

```text
Number of Time objects: 3
```

<br>

### 一句话总结

<br>

**静态成员属于类，所有对象共享；必须在类外定义，这是最常见报错原因；静态成员函数没有 `this`，只能访问静态成员。**

<br>

## 完整可运行代码
***

下面把这一章的知识点整合到一个完整的 `Time` 类里：成员 `operator+`、友元 `operator*`、友元 `operator<<`、转换函数 `operator int()`、静态成员 `count` 和静态函数 `get_count()`。

```cpp
#include <iostream>

class Time {
private:
    int hours;
    int minutes;
    static int count;   // 静态成员声明

public:
    Time(int h = 0, int m = 0) : hours(h), minutes(m) {
        while (minutes >= 60) {
            minutes -= 60;
            hours += 1;
        }
        count++;
    }

    // 成员 operator+
    Time operator+(const Time& t) const {
        return Time(hours + t.hours, minutes + t.minutes);
    }

    // 友元 operator*：支持 double * Time
    friend Time operator*(double m, const Time& t);

    // 友元 operator<<
    friend std::ostream& operator<<(std::ostream& os, const Time& t);

    // 转换函数：Time -> int
    operator int() const {
        return hours * 60 + minutes;
    }

    // 静态成员函数
    static int get_count() {
        return count;
    }
};

int Time::count = 0;   // 类外定义

Time operator*(double m, const Time& t) {
    int total = static_cast<int>(m * (t.hours * 60 + t.minutes));
    return Time(total / 60, total % 60);
}

std::ostream& operator<<(std::ostream& os, const Time& t) {
    os << t.hours << " hours, " << t.minutes << " minutes";
    return os;
}

int main() {
    Time t1(2, 45);
    Time t2(1, 30);

    Time t3 = t1 + t2;          // 成员 operator+
    std::cout << "t1 = " << t1 << std::endl;
    std::cout << "t2 = " << t2 << std::endl;
    std::cout << "t1 + t2 = " << t3 << std::endl;

    Time t4 = 2.5 * t1;         // 友元 operator*
    std::cout << "2.5 * t1 = " << t4 << std::endl;

    int total_minutes = t1;     // 转换函数
    std::cout << "t1 in minutes = " << total_minutes << std::endl;

    std::cout << "Number of Time objects created: " << Time::get_count() << std::endl;
    return 0;
}
```

运行结果：

```text
t1 = 2 hours, 45 minutes
t2 = 1 hours, 30 minutes
t1 + t2 = 4 hours, 15 minutes
2.5 * t1 = 6 hours, 52 minutes
t1 in minutes = 165
Number of Time objects created: 4
```

## 一句话总结全章
***

**运算符重载让类用起来像内置类型，友元给外部函数开后门，类型转换让类和内置类型互操作，静态成员让所有对象共享数据——但静态成员记得在类外定义。**
