## 一句话概括
***
**一句话**：运算符重载、友元、类型转换让类用起来像内置类型。

<br>

<br>

## 核心概念
***
- 运算符重载：`operator+` 等，至少一个操作数是用户定义类型。
- 不能重载的运算符：`::`、`.*`、`?:`、`sizeof`、`typeid`、强制转换运算符。
- 成员函数 vs 非成员函数：`a + b` 若 a 是对象，成员函数；若左操作数不是对象，需要友元。
- 友元：`friend` 声明，可访问私有成员。友元函数、友元类、友元成员函数。
- 重载 `<<`：`ostream& operator<<(ostream& os, const T& obj);` 返回 os 以支持链式。
- 类型转换：构造函数（其他类型→类），转换函数（类→其他类型）`operator int() const;`。`explicit` 禁止隐式转换。
- 静态成员：类共享，`static int num;` 类外初始化。
- 静态成员函数：无 `this`，只能访问静态成员。

<br>

<br>

## 最小代码
***
```cpp
class Time {
private:
    int hours, minutes;
public:
    Time operator+(const Time& t) const;
    friend Time operator*(double m, const Time& t);
    friend std::ostream& operator<<(std::ostream& os, const Time& t);
    operator int() const; // 转换函数
};
```

<br>

<br>

## 易错点
***
- 运算符重载不能改变优先级和结合性。
- 友元不是成员，不能继承。
- 转换函数可能导致二义性，用 `explicit`。
- 静态成员必须在类外定义。

<br>

<br>

## 项目用途
***
- 重载 `<<` 方便调试输出。
- 友元用于对称运算符（如 `2 * obj`）。
- 类型转换让类与内置类型互操作。
