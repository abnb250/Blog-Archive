你写了一个 `String` 类，里面用 `new` 分配了一块字符数组。程序跑起来，创建对象、复制对象、赋值对象……然后突然崩了：

```text
free(): double free detected in tcache 2
```

或者内存越用越多，最后卡死。你打开调试器，发现同一个指针被 `delete` 了两次，或者旧内存根本没释放。

问题出在：**类里用了 `new`，但你没定义析构函数、复制构造函数、赋值运算符**。编译器自动生成的那几个函数，只会做“浅拷贝”——把指针地址复制一份，结果两个对象指向同一块内存。一个对象销毁时 `delete` 了，另一个对象再销毁时又 `delete` 一次，直接 double free。

这一章咱们就顺着这个坑，把“Rule of 3”讲清楚：**析构函数、复制构造函数、赋值运算符**，一个都不能少。

<br>
<br>

## 知识点 1：构造函数 new 了，析构函数必须 delete

***
<br>

### 问题

<br>

你写了这样一个类：

```cpp
class String {
private:
    char* str;
public:
    String(const char* s) {
        str = new char[std::strlen(s) + 1];
        std::strcpy(str, s);
    }
    // 没有析构函数
};
```

创建对象后，`str` 指向动态内存。对象销毁时，编译器生成的默认析构函数什么都不做，**这块内存就泄漏了**。如果反复创建销毁，内存很快耗尽。

<br>

### 方案

<br>

**只要构造函数里用了 `new`，就必须定义析构函数，在里面用 `delete`（或 `delete[]`）释放。** 这是 RAII 的基本要求：构造函数获取资源，析构函数释放资源。

注意配对：`new[]` 配 `delete[]`，`new` 配 `delete`，不能混。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <cstring>

class String {
private:
    char* str;
public:
    String(const char* s) {
        str = new char[std::strlen(s) + 1];
        std::strcpy(str, s);
        std::cout << "Constructor: " << str << std::endl;
    }

    ~String() {
        std::cout << "Destructor: " << str << std::endl;
        delete[] str;   // 释放 new[] 分配的内存
    }

    void show() const {
        std::cout << "String: " << str << std::endl;
    }
};

int main() {
    String s("hello");
    s.show();
    return 0;
}
```

运行结果：

```text
Constructor: hello
String: hello
Destructor: hello
```

<br>

### 一句话总结

<br>

**构造函数里 `new` 了，析构函数里就必须 `delete`，而且 `new[]` 要配 `delete[]`。**

<br>

## 知识点 2：复制对象时，默认复制构造函数是浅拷贝

***
<br>

### 问题

<br>

你写：

```cpp
String s1("hello");
String s2 = s1;   // 复制构造
```

编译器会自动生成一个复制构造函数，它做的事情是**逐成员复制**。对于指针 `str`，它只复制指针地址，不复制指向的内容。结果 `s1.str` 和 `s2.str` 指向同一块内存。

当 `s2` 先销毁时，`delete[] str` 释放了那块内存。然后 `s1` 销毁时，又 `delete[]` 一次，直接 double free，程序崩溃。

<br>

### 方案

<br>

**自己定义复制构造函数，做深拷贝。** 复制构造函数的形式是 `类名(const 类名&)`。在里面为新对象分配一块新内存，再把原对象的内容复制过来。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <cstring>

class String {
private:
    char* str;
    int len;
public:
    String(const char* s) {
        len = std::strlen(s);
        str = new char[len + 1];
        std::strcpy(str, s);
        std::cout << "Constructor: " << str << std::endl;
    }

    // 复制构造函数：深拷贝
    String(const String& st) {
        len = st.len;
        str = new char[len + 1];
        std::strcpy(str, st.str);
        std::cout << "Copy constructor: " << str << std::endl;
    }

    ~String() {
        std::cout << "Destructor: " << str << std::endl;
        delete[] str;
    }

    void show() const {
        std::cout << "String: " << str << std::endl;
    }
};

int main() {
    String s1("hello");
    String s2 = s1;   // 调用复制构造函数
    s1.show();
    s2.show();
    return 0;
}
```

运行结果：

```text
Constructor: hello
Copy constructor: hello
String: hello
String: hello
Destructor: hello
Destructor: hello
```

两个对象各自拥有独立的内存，销毁时互不影响。

<br>

### 一句话总结

<br>

**默认复制构造函数只复制指针地址，做深拷贝必须自己定义复制构造函数，给新对象分配新内存。**

<br>

## 知识点 3：赋值运算符：释放旧内存，深拷贝，返回 *this

***
<br>

### 问题

<br>

你写：

```cpp
String s1("hello");
String s2("world");
s2 = s1;   // 赋值
```

编译器自动生成的赋值运算符也是浅拷贝：它直接把 `s1.str` 的地址赋给 `s2.str`。但 `s2.str` 原来指向的那块内存还没释放，**内存泄漏**了。然后 `s1` 和 `s2` 又指向同一块内存，销毁时 double free。

<br>

### 方案

<br>

**自己定义赋值运算符 `operator=`。** 标准写法：

1. 检查自赋值（下一节讲）。
2. `delete[]` 释放旧内存。
3. 分配新内存，深拷贝。
4. 返回 `*this`，支持链式赋值。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <cstring>

class String {
private:
    char* str;
    int len;
public:
    String(const char* s = "") {
        len = std::strlen(s);
        str = new char[len + 1];
        std::strcpy(str, s);
        std::cout << "Constructor: " << str << std::endl;
    }

    String(const String& st) {
        len = st.len;
        str = new char[len + 1];
        std::strcpy(str, st.str);
        std::cout << "Copy constructor: " << str << std::endl;
    }

    ~String() {
        std::cout << "Destructor: " << str << std::endl;
        delete[] str;
    }

    // 赋值运算符
    String& operator=(const String& st) {
        if (this == &st) {
            return *this;   // 自赋值直接返回
        }
        std::cout << "Assignment: " << str << " = " << st.str << std::endl;
        delete[] str;       // 释放旧内存
        len = st.len;
        str = new char[len + 1];
        std::strcpy(str, st.str);
        return *this;
    }

    void show() const {
        std::cout << "String: " << str << std::endl;
    }
};

int main() {
    String s1("hello");
    String s2("world");
    s2 = s1;   // 调用赋值运算符
    s1.show();
    s2.show();
    return 0;
}
```

运行结果：

```text
Constructor: hello
Constructor: world
Assignment: world = hello
String: hello
String: hello
Destructor: hello
Destructor: hello
```

注意 `s2` 原来的 `"world"` 被释放了，没有内存泄漏。

<br>

### 一句话总结

<br>

**赋值运算符要先释放旧内存，再深拷贝，最后返回 `*this` 支持链式赋值。**

<br>

## 知识点 4：自赋值：`s = s;` 必须检查

***
<br>

### 问题

<br>

如果有人写：

```cpp
String s("hello");
s = s;   // 自赋值
```

你的赋值运算符会先 `delete[] str;` 释放自己的内存，然后去读 `st.str`——但 `st` 就是自己，内存已经释放了，读到的是野指针，程序崩溃。

<br>

### 方案

<br>

在 `operator=` 开头加一句：

```cpp
if (this == &st) return *this;
```

判断传进来的引用是不是自己。如果是，直接返回，什么都不做。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <cstring>

class String {
private:
    char* str;
    int len;
public:
    String(const char* s = "") {
        len = std::strlen(s);
        str = new char[len + 1];
        std::strcpy(str, s);
    }

    String(const String& st) {
        len = st.len;
        str = new char[len + 1];
        std::strcpy(str, st.str);
    }

    ~String() {
        delete[] str;
    }

    String& operator=(const String& st) {
        std::cout << "operator= called" << std::endl;
        if (this == &st) {
            std::cout << "Self-assignment detected, skipping." << std::endl;
            return *this;
        }
        delete[] str;
        len = st.len;
        str = new char[len + 1];
        std::strcpy(str, st.str);
        return *this;
    }

    void show() const {
        std::cout << "String: " << str << std::endl;
    }
};

int main() {
    String s("hello");
    s = s;   // 自赋值
    s.show();
    return 0;
}
```

运行结果：

```text
operator= called
Self-assignment detected, skipping.
String: hello
```

<br>

### 一句话总结

<br>

**自赋值检查就是先问一句“你是不是我自己？”，是的话直接返回，别释放自己的内存。**

<br>

## 知识点 5：返回对象还是引用？返回 const 引用避免修改

***
<br>

### 问题

<br>

你写了一个函数，想返回一个 `String` 对象。应该返回引用还是对象？如果返回引用，什么时候会出问题？

<br>

### 方案

<br>

- **返回引用**：效率高，不会复制。但**不能返回局部对象的引用**，因为函数结束后局部对象就销毁了，引用悬空。
- **返回对象**：安全，但会调用复制构造函数，有开销。
- **返回 `const` 引用**：避免调用者修改返回的对象。

成员函数 `operator=` 返回 `*this` 的引用，因为 `*this` 是当前对象，函数结束后依然存在，安全且高效。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <cstring>

class String {
private:
    char* str;
    int len;
public:
    String(const char* s = "") {
        len = std::strlen(s);
        str = new char[len + 1];
        std::strcpy(str, s);
    }

    String(const String& st) {
        len = st.len;
        str = new char[len + 1];
        std::strcpy(str, st.str);
    }

    ~String() {
        delete[] str;
    }

    // 返回 const 引用，避免修改
    const String& get_self() const {
        return *this;
    }

    // 返回对象（安全，但有复制开销）
    String get_copy() const {
        return *this;
    }

    void show() const {
        std::cout << "String: " << str << std::endl;
    }
};

int main() {
    String s("hello");
    const String& ref = s.get_self();
    ref.show();   // 只能调用 const 成员函数

    String copy = s.get_copy();
    copy.show();
    return 0;
}
```

运行结果：

```text
String: hello
String: hello
```

<br>

### 一句话总结

<br>

**返回引用效率高，但不能返回局部对象的引用；返回对象安全但有复制开销；返回 `const` 引用防止调用者乱改。**

<br>

## 知识点 6：指向对象的指针：`new` 创建，`delete` 释放

***
<br>

### 问题

<br>

你想动态创建一个 `String` 对象，用完再释放。怎么写才不会泄漏？

<br>

### 方案

<br>

用 `new` 创建对象，它会自动调用构造函数；用 `delete` 释放，它会自动调用析构函数。注意配对：`new` 配 `delete`，`new[]` 配 `delete[]`。

现代 C++ 更推荐用智能指针（`std::unique_ptr`、`std::shared_ptr`）替代裸 `new/delete`，但理解裸指针的配对是基础。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <cstring>

class String {
private:
    char* str;
public:
    String(const char* s = "") {
        str = new char[std::strlen(s) + 1];
        std::strcpy(str, s);
        std::cout << "Constructor: " << str << std::endl;
    }

    ~String() {
        std::cout << "Destructor: " << str << std::endl;
        delete[] str;
    }

    void show() const {
        std::cout << "String: " << str << std::endl;
    }
};

int main() {
    String* p = new String("dynamic");
    p->show();
    delete p;   // 自动调用析构函数

    return 0;
}
```

运行结果：

```text
Constructor: dynamic
String: dynamic
Destructor: dynamic
```

<br>

### 一句话总结

<br>

**`new` 创建对象会自动调构造函数，`delete` 释放会自动调析构函数；记得配对，`new[]` 配 `delete[]`。**

<br>

## 知识点 7：静态成员在动态内存类中的用途——统计对象个数

***
<br>

### 问题

<br>

你想知道程序里一共创建了多少个 `String` 对象，但普通成员变量每个对象一份，没法共享。怎么办？

<br>

### 方案

<br>

用**静态数据成员**，所有对象共享同一份。在类里声明 `static int num_strings;`，**必须在类外定义并初始化**。每次构造函数里 `num_strings++`，析构函数里 `num_strings--`。静态成员函数没有 `this`，只能访问静态成员。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <cstring>

class String {
private:
    char* str;
    int len;
    static int num_strings;   // 静态成员声明
public:
    String(const char* s = "") {
        len = std::strlen(s);
        str = new char[len + 1];
        std::strcpy(str, s);
        num_strings++;
    }

    String(const String& st) {
        len = st.len;
        str = new char[len + 1];
        std::strcpy(str, st.str);
        num_strings++;
    }

    ~String() {
        num_strings--;
        delete[] str;
    }

    static int how_many() {   // 静态成员函数
        return num_strings;
    }
};

int String::num_strings = 0;   // 类外定义，必须写

int main() {
    String s1("hello");
    String s2 = s1;
    {
        String s3("temp");
        std::cout << "Inside block: " << String::how_many() << std::endl;
    }
    std::cout << "Outside block: " << String::how_many() << std::endl;
    return 0;
}
```

运行结果：

```text
Inside block: 3
Outside block: 2
```

<br>

### 一句话总结

<br>

**静态成员属于类，所有对象共享；必须在类外定义，这是最常见报错原因；静态成员函数没有 `this`，只能访问静态成员。**

<br>

## 完整可运行代码
***

下面是一个完整的 `String` 类，包含了 Rule of 3：析构函数、复制构造函数、赋值运算符，还演示了自赋值、返回 `*this`、指向对象的指针和静态成员计数。

```cpp
#include <iostream>
#include <cstring>

class String {
private:
    char* str;
    int len;
    static int num_strings;   // 静态成员声明

public:
    // 构造函数
    String(const char* s = "") {
        len = std::strlen(s);
        str = new char[len + 1];
        std::strcpy(str, s);
        num_strings++;
        std::cout << "Constructor: " << str << " created. Total: " << num_strings << std::endl;
    }

    // 复制构造函数（深拷贝）
    String(const String& st) {
        len = st.len;
        str = new char[len + 1];
        std::strcpy(str, st.str);
        num_strings++;
        std::cout << "Copy constructor: " << str << " copied. Total: " << num_strings << std::endl;
    }

    // 析构函数
    ~String() {
        std::cout << "Destructor: " << str << " destroyed. ";
        num_strings--;
        std::cout << "Remaining: " << num_strings << std::endl;
        delete[] str;
    }

    // 赋值运算符
    String& operator=(const String& st) {
        if (this == &st) {
            std::cout << "Self-assignment detected, skipping." << std::endl;
            return *this;
        }
        std::cout << "Assignment: " << str << " = " << st.str << std::endl;
        delete[] str;               // 释放旧内存
        len = st.len;
        str = new char[len + 1];    // 分配新内存
        std::strcpy(str, st.str);   // 深拷贝
        return *this;
    }

    void show() const {
        std::cout << "String: " << str << std::endl;
    }

    static int how_many() {
        return num_strings;
    }
};

int String::num_strings = 0;   // 类外定义

int main() {
    String s1("hello");
    String s2 = s1;            // 复制构造
    String s3;
    s3 = s1;                   // 赋值
    s3 = s3;                   // 自赋值

    {
        String s4("temp");
    }                          // s4 析构

    std::cout << "Total objects: " << String::how_many() << std::endl;

    // 指向对象的指针
    String* p = new String("dynamic");
    p->show();
    delete p;

    return 0;
}
```

运行结果示例：

```text
Constructor: hello created. Total: 1
Copy constructor: hello copied. Total: 2
Constructor:  created. Total: 3
Assignment:  = hello
Self-assignment detected, skipping.
Constructor: temp created. Total: 4
Destructor: temp destroyed. Remaining: 3
Total objects: 3
Constructor: dynamic created. Total: 4
String: dynamic
Destructor: dynamic destroyed. Remaining: 3
Destructor: hello destroyed. Remaining: 2
Destructor: hello destroyed. Remaining: 1
Destructor:  destroyed. Remaining: 0
```

***

**类里用了 `new`，就必须遵守 Rule of 3：析构函数释放内存，复制构造函数深拷贝，赋值运算符先释放旧内存再深拷贝并处理自赋值——这样才能避免 double free 和内存泄漏。**
