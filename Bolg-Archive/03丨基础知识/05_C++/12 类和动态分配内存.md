## 一句话概括
***
**一句话**：类中使用 `new` 必须定义析构函数、复制构造函数、赋值运算符（Rule of 3）。

<br>

<br>

## 核心概念
***
- 动态内存：构造函数 `new`，析构函数 `delete`。
- 静态类成员：所有对象共享，类外初始化。
- 复制构造函数：`类名(const 类名&)`，深拷贝。
- 赋值运算符：`类名& operator=(const 类名&)`，释放旧内存，深拷贝，返回 `*this`，处理自赋值。
- 返回对象：返回引用（效率高）或对象（局部对象必须返回值）。
- 返回 `const` 引用：避免修改。
- 指向对象的指针：`new` 创建对象，`delete` 释放。
- 定位 `new`（跳过）。
- 队列模拟（跳过）。

<br>

<br>

## 最小代码
***
```cpp
class String {
private:
    char* str;
    int len;
    static int num_strings;
public:
    String(const char* s);
    String(const String& st);
    ~String();
    String& operator=(const String& st);
};

String::String(const String& st) {
    len = st.len;
    str = new char[len + 1];
    std::strcpy(str, st.str);
}

String& String::operator=(const String& st) {
    if (this == &st) return *this;
    delete[] str;
    len = st.len;
    str = new char[len + 1];
    std::strcpy(str, st.str);
    return *this;
}
```

<br>

<br>

## 易错点
***
- 浅拷贝导致 double free。
- 自赋值不检查会释放自身内存。
- `new[]` 配 `delete[]`。
- 返回局部对象的引用是悬空引用。

<br>
