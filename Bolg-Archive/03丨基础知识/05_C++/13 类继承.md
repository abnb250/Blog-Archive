## 一句话概括
***
**一句话**：公有继承表达 is-a 关系；虚函数实现多态；基类指针/引用可指向派生类对象。

<br>

<br>

## 核心概念
***
- 公有继承：`class Derived : public Base`。
- 派生类构造函数必须调用基类构造函数（初始化列表）。
- 派生类不能直接访问基类私有成员，可通过保护成员或基类方法。
- 多态：虚函数 `virtual`，动态联编。
- 虚析构函数：基类析构函数应为 `virtual`。
- 抽象基类：纯虚函数 `virtual void f() = 0;`，不能实例化。
- 访问控制：`public`、`protected`、`private`。
- 继承与动态内存：派生类若使用 `new`，需定义析构、复制构造、赋值，并调用基类对应函数。
- 类设计回顾：is-a、has-a、私有继承、包含。

<br>

<br>

## 最小代码
***
```cpp
class Brass {
protected:
    std::string fullName;
    long acctNum;
    double balance;
public:
    Brass(const std::string& s = "null", long an = -1, double bal = 0.0);
    virtual void Withdraw(double amt);
    virtual void ViewAcct() const;
    virtual ~Brass() {}
};

class BrassPlus : public Brass {
private:
    double maxLoan;
    double rate;
    double owesBank;
public:
    BrassPlus(const std::string& s = "null", long an = -1, double bal = 0.0,
              double ml = 500, double r = 0.11125);
    virtual void ViewAcct() const;
    virtual void Withdraw(double amt);
};
```

<br>

<br>

## 易错点
***
- 基类析构函数不是 `virtual`，`delete` 基类指针时派生类析构不调用。
- 派生类重新定义虚函数，签名必须一致。
- 构造函数不能是虚函数。
- 友元不能是虚函数。
- 抽象基类不能创建对象。

<br>

<br>

## 项目用途
***
- 接口与实现分离，用基类指针管理不同派生类。
- 多态实现插件式架构。
- 抽象基类定义接口。
