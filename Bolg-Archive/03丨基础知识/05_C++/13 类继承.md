## 知识点 1：代码重复太多？公有继承表达 is-a

***
<br>

### 问题

<br>

你写了一个 `Brass` 类，现在要加 `BrassPlus`。你不想把 `fullName`、`acctNum`、`balance` 和那些函数再写一遍。能不能让 `BrassPlus` 直接拥有 `Brass` 的所有功能，再加自己的？

<br>

### 方案

<br>

用**公有继承**：`class BrassPlus : public Brass`。这表示 `BrassPlus` **是一种** `Brass`（is-a 关系）。`BrassPlus` 自动拥有 `Brass` 的公有成员和受保护成员，不用重新写一遍。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <string>

class Brass {
protected:
    std::string fullName;
    long acctNum;
    double balance;

public:
    Brass(const std::string& s = "null", long an = -1, double bal = 0.0)
        : fullName(s), acctNum(an), balance(bal) {}

    void ViewAcct() const {
        std::cout << "Name: " << fullName << ", Acct: " << acctNum
                  << ", Balance: " << balance << std::endl;
    }
};

class BrassPlus : public Brass {
public:
    BrassPlus(const std::string& s = "null", long an = -1, double bal = 0.0)
        : Brass(s, an, bal) {}   // 调用基类构造函数
};

int main() {
    BrassPlus bp("Alice", 12345, 1000.0);
    bp.ViewAcct();   // 继承自 Brass
    return 0;
}
```

运行结果：

```text
Name: Alice, Acct: 12345, Balance: 1000
```

<br>

### 一句话总结

<br>

**公有继承就是“是一种”的关系，派生类自动拥有基类的功能，不用复制粘贴。**

<br>

## 知识点 2：派生类构造函数必须调用基类构造函数

***
<br>

### 问题

<br>

`BrassPlus` 的构造函数怎么写？`fullName`、`acctNum`、`balance` 是基类的私有或保护成员，`BrassPlus` 不能直接初始化它们。怎么办？

<br>

### 方案

<br>

在派生类构造函数的**初始化列表**里调用基类构造函数。如果没写，编译器会尝试调用基类的**默认构造函数**；如果基类没有默认构造函数，编译就报错。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <string>

class Brass {
protected:
    std::string fullName;
    long acctNum;
    double balance;

public:
    Brass(const std::string& s, long an, double bal)
        : fullName(s), acctNum(an), balance(bal) {
        std::cout << "Brass constructor" << std::endl;
    }

    void ViewAcct() const {
        std::cout << fullName << ", " << acctNum << ", " << balance << std::endl;
    }
};

class BrassPlus : public Brass {
private:
    double maxLoan;
    double rate;

public:
    BrassPlus(const std::string& s, long an, double bal,
              double ml, double r)
        : Brass(s, an, bal), maxLoan(ml), rate(r) {   // 调用基类构造函数
        std::cout << "BrassPlus constructor" << std::endl;
    }

    void ShowLoan() const {
        std::cout << "Max loan: " << maxLoan << ", Rate: " << rate << std::endl;
    }
};

int main() {
    BrassPlus bp("Alice", 12345, 1000.0, 500.0, 0.11125);
    bp.ViewAcct();
    bp.ShowLoan();
    return 0;
}
```

运行结果：

```text
Brass constructor
BrassPlus constructor
Alice, 12345, 1000
Max loan: 500, Rate: 0.11125
```

**易错点**：如果基类没有默认构造函数，而派生类构造函数没在初始化列表里调用基类构造函数，编译器会报错：`no matching function for call to 'Brass::Brass()'`。

<br>

### 一句话总结

<br>

**派生类构造函数必须在初始化列表里调用基类构造函数，否则编译器会去找基类的默认构造函数，找不到就报错。**

<br>

## 知识点 3：派生类不能直接访问基类私有成员？用 protected

***
<br>

### 问题

<br>

`BrassPlus::ViewAcct` 想直接读 `balance`，但 `balance` 是 `Brass` 的 `private` 成员。编译报错：

```text
error: 'double Brass::balance' is private within this context
```

怎么办？

<br>

### 方案

<br>

把基类中希望派生类访问的成员声明为 **`protected`**。`protected` 成员在派生类里可以像 `public` 一样访问，但对外部仍然是不可见的。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <string>

class Brass {
protected:              // 派生类可以访问
    std::string fullName;
    long acctNum;
    double balance;

public:
    Brass(const std::string& s, long an, double bal)
        : fullName(s), acctNum(an), balance(bal) {}

    void ViewAcct() const {
        std::cout << fullName << ", " << acctNum << ", " << balance << std::endl;
    }
};

class BrassPlus : public Brass {
public:
    BrassPlus(const std::string& s, long an, double bal)
        : Brass(s, an, bal) {}

    void ViewAcct() const {
        // 直接访问基类 protected 成员
        std::cout << "[Plus] " << fullName << ", " << acctNum
                  << ", " << balance << std::endl;
    }
};

int main() {
    BrassPlus bp("Alice", 12345, 1000.0);
    bp.ViewAcct();
    return 0;
}
```

运行结果：

```text
[Plus] Alice, 12345, 1000
```

<br>

### 一句话总结

<br>

**`protected` 是给派生类开的“内部通道”，派生类能访问，外部仍然不能碰。**

<br>

## 知识点 4：基类指针调不到派生类函数？虚函数和多态

***
<br>

### 问题

<br>

你想用基类指针统一管理不同账户：

```cpp
Brass* p = new BrassPlus("Alice", 12345, 1000.0);
p->ViewAcct();   // 结果调用了 Brass::ViewAcct，而不是 BrassPlus::ViewAcct
```

为什么？怎么让它根据实际对象类型调用对应的函数？

<br>

### 方案

<br>

把基类中的函数声明为 **`virtual`**。虚函数实现**动态联编**（运行时多态）：通过基类指针或引用调用时，实际调用哪个版本由对象的真实类型决定。

派生类重写虚函数时，**函数签名必须完全一致**（函数名、参数列表、返回类型、`const` 限定都要一样）。否则只是隐藏，不是覆盖。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <string>

class Brass {
protected:
    std::string fullName;
    double balance;

public:
    Brass(const std::string& s, double bal)
        : fullName(s), balance(bal) {}

    virtual void ViewAcct() const {
        std::cout << "Brass: " << fullName << ", " << balance << std::endl;
    }

    virtual ~Brass() {}   // 后面讲为什么
};

class BrassPlus : public Brass {
public:
    BrassPlus(const std::string& s, double bal)
        : Brass(s, bal) {}

    void ViewAcct() const override {   // override 可选，但推荐
        std::cout << "BrassPlus: " << fullName << ", " << balance << std::endl;
    }
};

int main() {
    Brass* p1 = new Brass("Alice", 1000.0);
    Brass* p2 = new BrassPlus("Bob", 2000.0);

    p1->ViewAcct();   // 调用 Brass::ViewAcct
    p2->ViewAcct();   // 调用 BrassPlus::ViewAcct（多态）

    delete p1;
    delete p2;
    return 0;
}
```

运行结果：

```text
Brass: Alice, 1000
BrassPlus: Bob, 2000
```

<br>

### 一句话总结

<br>

**虚函数让基类指针在运行时根据对象真实类型调用对应的函数，这就是多态。**

<br>

## 知识点 5：delete 基类指针，派生类析构没调用？虚析构函数

***
<br>

### 问题

<br>

你用基类指针 `new` 了一个派生类对象，然后 `delete` 它：

```cpp
Brass* p = new BrassPlus("Bob", 2000.0);
delete p;
```

结果只调用了 `Brass` 的析构函数，`BrassPlus` 的析构函数没执行。如果 `BrassPlus` 里有动态分配的内存，就泄漏了。为什么？怎么办？

<br>

### 方案

<br>

**基类的析构函数必须声明为 `virtual`。** 这样通过基类指针 `delete` 时，会先调用派生类析构函数，再调用基类析构函数，保证资源正确释放。

**构造函数不能是虚函数**，因为虚函数依赖虚表，而对象还没构造完。**友元函数也不能是虚函数**，因为友元不是成员。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <string>

class Brass {
protected:
    std::string fullName;

public:
    Brass(const std::string& s) : fullName(s) {
        std::cout << "Brass constructor" << std::endl;
    }

    virtual ~Brass() {
        std::cout << "Brass destructor" << std::endl;
    }
};

class BrassPlus : public Brass {
private:
    double* extra;

public:
    BrassPlus(const std::string& s) : Brass(s) {
        extra = new double(100.0);
        std::cout << "BrassPlus constructor" << std::endl;
    }

    ~BrassPlus() {
        delete extra;
        std::cout << "BrassPlus destructor" << std::endl;
    }
};

int main() {
    Brass* p = new BrassPlus("Bob");
    delete p;   // 虚析构保证两个析构都调用
    return 0;
}
```

运行结果：

```text
Brass constructor
BrassPlus constructor
BrassPlus destructor
Brass destructor
```

如果基类析构不是 `virtual`，运行结果只会打印 `Brass destructor`，`BrassPlus` 的 `extra` 就泄漏了。

<br>

### 一句话总结

<br>

**基类析构函数必须是 `virtual`，否则 `delete` 基类指针时派生类析构不调用，资源就泄漏了。**

<br>

## 知识点 6：不想让别人创建基类对象？抽象基类与纯虚函数

***
<br>

### 问题

<br>

你想定义一个“账户”接口，规定所有账户都必须有 `ViewAcct` 和 `Withdraw`，但“账户”本身太抽象，不想让人创建 `Brass` 对象。怎么办？

<br>

### 方案

<br>

用**纯虚函数**：`virtual void ViewAcct() const = 0;`。包含纯虚函数的类是**抽象基类**，**不能实例化**。派生类必须实现所有纯虚函数，否则它也是抽象类。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <string>

class AbstractAccount {   // 抽象基类
public:
    virtual void ViewAcct() const = 0;   // 纯虚函数
    virtual void Withdraw(double amt) = 0;
    virtual ~AbstractAccount() {}
};

class Savings : public AbstractAccount {
private:
    std::string name;
    double balance;

public:
    Savings(const std::string& n, double b) : name(n), balance(b) {}

    void ViewAcct() const override {
        std::cout << "Savings: " << name << ", " << balance << std::endl;
    }

    void Withdraw(double amt) override {
        if (amt <= balance) balance -= amt;
        else std::cout << "Insufficient funds" << std::endl;
    }
};

int main() {
    // AbstractAccount acc;   // 错误：抽象类不能实例化
    Savings s("Alice", 1000.0);
    s.ViewAcct();
    s.Withdraw(200.0);
    s.ViewAcct();
    return 0;
}
```

运行结果：

```text
Savings: Alice, 1000
Savings: Alice, 800
```

<br>

### 一句话总结

<br>

**纯虚函数就是“必须实现，但基类不管”的接口；有纯虚函数的类是抽象基类，不能创建对象。**

<br>

## 知识点 7：派生类有动态内存，复制和赋值怎么处理基类部分？

***
<br>

### 问题

<br>

`BrassPlus` 里有一个 `char*` 动态分配的备注。复制构造和赋值时，基类部分的 `fullName`、`balance` 怎么复制？如果只复制派生类自己的成员，基类部分就丢了。

<br>

### 方案

<br>

派生类的复制构造函数要在初始化列表里调用基类的复制构造函数；派生类的赋值运算符要显式调用基类的赋值运算符。如果派生类自己用了 `new`，同样要遵守 Rule of 3：析构、复制构造、赋值运算符都要定义。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <cstring>
#include <string>

class Brass {
protected:
    std::string fullName;
    double balance;

public:
    Brass(const std::string& s = "", double bal = 0.0)
        : fullName(s), balance(bal) {}

    Brass(const Brass& b) : fullName(b.fullName), balance(b.balance) {
        std::cout << "Brass copy constructor" << std::endl;
    }

    Brass& operator=(const Brass& b) {
        if (this == &b) return *this;
        fullName = b.fullName;
        balance = b.balance;
        std::cout << "Brass assignment" << std::endl;
        return *this;
    }

    virtual ~Brass() {}
};

class BrassPlus : public Brass {
private:
    char* note;

public:
    BrassPlus(const std::string& s, double bal, const char* n)
        : Brass(s, bal) {
        note = new char[std::strlen(n) + 1];
        std::strcpy(note, n);
    }

    // 复制构造函数：调用基类复制构造，再深拷贝自己的 note
    BrassPlus(const BrassPlus& bp)
        : Brass(bp) {
        note = new char[std::strlen(bp.note) + 1];
        std::strcpy(note, bp.note);
        std::cout << "BrassPlus copy constructor" << std::endl;
    }

    // 赋值运算符：调用基类赋值，再处理自己的 note
    BrassPlus& operator=(const BrassPlus& bp) {
        if (this == &bp) return *this;
        Brass::operator=(bp);   // 显式调用基类赋值
        delete[] note;
        note = new char[std::strlen(bp.note) + 1];
        std::strcpy(note, bp.note);
        std::cout << "BrassPlus assignment" << std::endl;
        return *this;
    }

    ~BrassPlus() {
        delete[] note;
    }

    void Show() const {
        std::cout << fullName << ", " << balance << ", " << note << std::endl;
    }
};

int main() {
    BrassPlus bp1("Alice", 1000.0, "VIP");
    BrassPlus bp2 = bp1;   // 复制构造
    BrassPlus bp3("Bob", 2000.0, "Normal");
    bp3 = bp1;             // 赋值
    bp2.Show();
    bp3.Show();
    return 0;
}
```

运行结果：

```text
Brass copy constructor
BrassPlus copy constructor
Brass assignment
BrassPlus assignment
Alice, 1000, VIP
Alice, 1000, VIP
```

<br>

### 一句话总结

<br>

**派生类有动态内存时，复制构造要调用基类复制构造，赋值要显式调用基类赋值，自己的 `new` 自己管。**

<br>

## 知识点 8：到底该用继承还是包含？is-a 和 has-a

***
<br>

### 问题

<br>

你想让 `BrassPlus` 拥有一个 `Brass` 对象，而不是继承它。什么时候该用继承，什么时候该用包含？

<br>

### 方案

<br>

- **公有继承**表达 **is-a**：`BrassPlus` 是一种 `Brass`。
- **包含（成员对象）**表达 **has-a**：`BrassPlus` 有一个 `Brass`。
- **私有继承**也表达 has-a，但通常用包含更清晰。

如果你只是想让一个类使用另一个类的功能，而不是“是一种”关系，就用包含。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <string>

class Brass {
public:
    void ViewAcct() const {
        std::cout << "Brass account" << std::endl;
    }
};

// has-a：包含一个 Brass 成员
class Customer {
private:
    std::string name;
    Brass account;   // Customer 有一个 Brass

public:
    Customer(const std::string& n) : name(n) {}

    void Show() const {
        std::cout << "Customer: " << name << std::endl;
        account.ViewAcct();
    }
};

int main() {
    Customer c("Alice");
    c.Show();
    return 0;
}
```

运行结果：

```text
Customer: Alice
Brass account
```

<br>

### 一句话总结

<br>

**“是一种”用公有继承，“有一个”用包含；别为了复用代码强行继承，关系不对会很难受。**

<br>

## 完整可运行代码
***

下面是一个完整的例子，包含抽象基类、虚函数、虚析构、派生类、动态内存和多态。

```cpp
#include <iostream>
#include <string>
#include <cstring>

// 抽象基类
class AbstractAccount {
public:
    virtual void ViewAcct() const = 0;
    virtual void Withdraw(double amt) = 0;
    virtual ~AbstractAccount() {}
};

// 基类 Brass
class Brass : public AbstractAccount {
protected:
    std::string fullName;
    long acctNum;
    double balance;

public:
    Brass(const std::string& s = "null", long an = -1, double bal = 0.0)
        : fullName(s), acctNum(an), balance(bal) {}

    virtual void ViewAcct() const override {
        std::cout << "Brass: " << fullName << ", Acct: " << acctNum
                  << ", Balance: " << balance << std::endl;
    }

    virtual void Withdraw(double amt) override {
        if (amt <= balance) balance -= amt;
        else std::cout << "Insufficient funds" << std::endl;
    }

    virtual ~Brass() {}
};

// 派生类 BrassPlus
class BrassPlus : public Brass {
private:
    double maxLoan;
    double rate;
    double owesBank;
    char* note;

public:
    BrassPlus(const std::string& s = "null", long an = -1, double bal = 0.0,
              double ml = 500, double r = 0.11125, const char* n = "")
        : Brass(s, an, bal), maxLoan(ml), rate(r), owesBank(0.0) {
        note = new char[std::strlen(n) + 1];
        std::strcpy(note, n);
    }

    BrassPlus(const BrassPlus& bp)
        : Brass(bp), maxLoan(bp.maxLoan), rate(bp.rate), owesBank(bp.owesBank) {
        note = new char[std::strlen(bp.note) + 1];
        std::strcpy(note, bp.note);
    }

    BrassPlus& operator=(const BrassPlus& bp) {
        if (this == &bp) return *this;
        Brass::operator=(bp);
        maxLoan = bp.maxLoan;
        rate = bp.rate;
        owesBank = bp.owesBank;
        delete[] note;
        note = new char[std::strlen(bp.note) + 1];
        std::strcpy(note, bp.note);
        return *this;
    }

    ~BrassPlus() {
        delete[] note;
    }

    virtual void ViewAcct() const override {
        std::cout << "BrassPlus: " << fullName << ", Acct: " << acctNum
                  << ", Balance: " << balance
                  << ", MaxLoan: " << maxLoan
                  << ", Rate: " << rate
                  << ", Note: " << note << std::endl;
    }

    virtual void Withdraw(double amt) override {
        if (amt <= balance) {
            balance -= amt;
        } else if (amt <= balance + maxLoan - owesBank) {
            double advance = amt - balance;
            owesBank += advance * (1.0 + rate);
            balance = 0.0;
        } else {
            std::cout << "Credit limit exceeded" << std::endl;
        }
    }
};

int main() {
    AbstractAccount* accounts[2];
    accounts[0] = new Brass("Alice", 12345, 1000.0);
    accounts[1] = new BrassPlus("Bob", 67890, 2000.0, 500.0, 0.11125, "VIP");

    for (int i = 0; i < 2; ++i) {
        accounts[i]->ViewAcct();
        accounts[i]->Withdraw(1500.0);
        accounts[i]->ViewAcct();
        std::cout << "---" << std::endl;
    }

    for (int i = 0; i < 2; ++i) {
        delete accounts[i];   // 虚析构保证正确释放
    }

    return 0;
}
```
