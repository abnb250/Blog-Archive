## 知识点 1：包含（组合）——has-a 关系

***
<br>

### 问题

<br>

你有一个 `Engine` 类，里面有 `start()`、`stop()`。现在写 `Car` 类，想让 `Car` 拥有一个引擎，但 `Car` 不是一种 `Engine`。用公有继承 `class Car : public Engine` 显然不对。怎么办？

<br>

### 方案

<br>

用**包含（组合）**：把 `Engine` 对象作为 `Car` 的成员。这叫 **has-a** 关系。`Car` 有一个 `Engine`，通过成员对象复用 `Engine` 的功能。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

class Engine {
public:
    void start() const {
        std::cout << "Engine started" << std::endl;
    }
    void stop() const {
        std::cout << "Engine stopped" << std::endl;
    }
};

class Car {
private:
    Engine engine;   // Car 有一个 Engine
    std::string model;

public:
    Car(const std::string& m) : model(m) {}

    void drive() const {
        std::cout << model << ": ";
        engine.start();
    }

    void park() const {
        std::cout << model << ": ";
        engine.stop();
    }
};

int main() {
    Car c("Toyota");
    c.drive();
    c.park();
    return 0;
}
```

运行结果：

```text
Toyota: Engine started
Toyota: Engine stopped
```

<br>

### 一句话总结

<br>

**包含就是“有一个”，把另一个类的对象作为成员，复用它的实现，关系是 has-a。**

<br>

## 知识点 2：私有继承——用继承实现 has-a

***
<br>

### 问题

<br>

包含很好，但有时候你想复用某个类的实现，又想访问它的 `protected` 成员，或者想重写它的虚函数。用包含的话，只能访问 `public` 成员。怎么办？

<br>

### 方案

<br>

用**私有继承**：`class Derived : private Base`。基类的 `public` 和 `protected` 成员在派生类里都变成 `private`。外部不能把派生类对象当基类用，但派生类内部可以访问基类的 `public` 和 `protected` 成员，也可以重写虚函数。这也是一种 **has-a** 关系，只是用继承语法实现。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

class Base {
protected:
    int value;
public:
    Base(int v = 0) : value(v) {}
    void show() const {
        std::cout << "Base value: " << value << std::endl;
    }
};

class Derived : private Base {   // 私有继承
public:
    Derived(int v) : Base(v) {}

    void show_derived() const {
        // 可以访问基类的 protected 成员
        std::cout << "Derived access value: " << value << std::endl;
        // 可以调用基类的 public 成员
        show();
    }
};

int main() {
    Derived d(42);
    d.show_derived();

    // 下面这行会报错：'Base' is a private member of 'Base'
    // d.show();

    return 0;
}
```

运行结果：

```text
Derived access value: 42
Base value: 42
```

<br>

### 一句话总结

<br>

**私有继承就是“借用实现，不暴露接口”，外部不能把派生类当基类用，但派生类内部可以访问基类的 protected 成员。**

<br>

### 自测

<br>

## 知识点 3：保护继承——介于公有和私有之间

***
<br>

### 问题

<br>

如果想让派生类的派生类还能访问基类的 `public` 和 `protected` 成员，但外部不能访问，怎么办？

<br>

### 方案

<br>

用**保护继承**：`class Derived : protected Base`。基类的 `public` 和 `protected` 成员在派生类里都变成 `protected`。这样，`Derived` 的派生类还能继续访问，但外部不能把 `Derived` 对象当 `Base` 用。保护继承在实际中很少用，知道有这回事就行。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

class Base {
public:
    void show() const {
        std::cout << "Base show" << std::endl;
    }
};

class Derived : protected Base {   // 保护继承
public:
    void call_show() const {
        show();   // 在派生类内部可以调用
    }
};

class Further : public Derived {
public:
    void call_show_again() const {
        show();   // 继续派生，仍然可以调用
    }
};

int main() {
    Derived d;
    d.call_show();

    Further f;
    f.call_show_again();

    // 下面这行会报错：'show' is a protected member of 'Base'
    // d.show();

    return 0;
}
```

运行结果：

```text
Base show
Base show
```

<br>

### 一句话总结

<br>

**保护继承让基类的公有成员在派生类里变成 protected，只有后续派生类能访问，外部不能访问。**

<br>

## 知识点 4：多重继承与虚基类——解决菱形继承

***
<br>

### 问题

<br>

你有一个基类 `Animal`，派生类 `Mammal` 和 `Bird`，然后 `Platypus` 同时继承 `Mammal` 和 `Bird`。结果 `Platypus` 里有两份 `Animal` 的成员，调用 `Animal` 的方法时编译器说“二义性”。怎么办？

<br>

### 方案

<br>

用**虚基类**。让 `Mammal` 和 `Bird` 虚继承 `Animal`：

```cpp
class Mammal : virtual public Animal { ... };
class Bird : virtual public Animal { ... };
```

这样 `Platypus` 只保留一份 `Animal` 成员，二义性消失。虚基类的构造函数需要由最派生类显式调用。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

class Animal {
protected:
    int age;
public:
    Animal(int a = 0) : age(a) {
        std::cout << "Animal constructor" << std::endl;
    }
    void show_age() const {
        std::cout << "Age: " << age << std::endl;
    }
};

class Mammal : virtual public Animal {
public:
    Mammal(int a = 0) : Animal(a) {
        std::cout << "Mammal constructor" << std::endl;
    }
};

class Bird : virtual public Animal {
public:
    Bird(int a = 0) : Animal(a) {
        std::cout << "Bird constructor" << std::endl;
    }
};

class Platypus : public Mammal, public Bird {
public:
    // 最派生类显式调用虚基类构造函数
    Platypus(int a) : Animal(a), Mammal(a), Bird(a) {
        std::cout << "Platypus constructor" << std::endl;
    }
};

int main() {
    Platypus p(3);
    p.show_age();   // 没有二义性，只有一份 Animal
    return 0;
}
```

运行结果：

```text
Animal constructor
Mammal constructor
Bird constructor
Platypus constructor
Age: 3
```

<br>

### 一句话总结

<br>

**虚基类让菱形继承中公共基类只保留一份，避免二义性和数据重复；最派生类要显式调用虚基类构造函数。**

<br>

### 自测

<br>

## 知识点 5：类模板——类型参数化

***
<br>

### 问题

<br>

你写了一个 `Stack` 类，只能存 `int`。想存 `double`、`std::string`，难道复制多份？改一个 bug，所有副本都得改。怎么办？

<br>

### 方案

<br>

用**类模板**。在类定义前写 `template <class T>`，把具体类型换成 `T`。使用时用 `Stack<int>`、`Stack<double>` 实例化。**模板定义通常放在头文件中**，因为编译器需要看到完整定义才能实例化。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

template <class T>
class Stack {
private:
    enum { MAX = 10 };
    T items[MAX];
    int top;
public:
    Stack() : top(0) {}

    bool push(const T& item) {
        if (top >= MAX) return false;
        items[top++] = item;
        return true;
    }

    bool pop(T& item) {
        if (top <= 0) return false;
        item = items[--top];
        return true;
    }
};

int main() {
    Stack<int> si;
    si.push(1);
    si.push(2);
    int x;
    si.pop(x);
    std::cout << "Popped: " << x << std::endl;

    Stack<std::string> ss;
    ss.push("hello");
    std::string s;
    ss.pop(s);
    std::cout << "Popped: " << s << std::endl;

    return 0;
}
```

运行结果：

```text
Popped: 2
Popped: hello
```

<br>

### 一句话总结

<br>

**类模板就是给类加个类型参数，用的时候指定具体类型，一套代码适配多种类型。**

<br>

## 知识点 6：模板参数——非类型参数和默认参数

***
<br>

### 问题

<br>

`Stack` 的大小写死是 10。你想让用户自己指定大小，比如 `Stack<int, 20>`。怎么办？

<br>

### 方案

<br>

用**非类型模板参数**。`template <class T, int n>`，其中 `n` 是一个整数常量。还可以给模板参数加默认值，比如 `template <class T, int n = 10>`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>

template <class T, int n = 10>
class Stack {
private:
    T items[n];
    int top;
public:
    Stack() : top(0) {}

    bool push(const T& item) {
        if (top >= n) return false;
        items[top++] = item;
        return true;
    }

    bool pop(T& item) {
        if (top <= 0) return false;
        item = items[--top];
        return true;
    }

    int capacity() const { return n; }
};

int main() {
    Stack<int, 5> s5;
    std::cout << "Capacity: " << s5.capacity() << std::endl;

    Stack<double> s_default;   // 默认 n = 10
    std::cout << "Default capacity: " << s_default.capacity() << std::endl;

    return 0;
}
```

运行结果：

```text
Capacity: 5
Default capacity: 10
```

<br>

### 一句话总结

<br>

**模板参数不一定是类型，也可以是整数等非类型参数，用来定制大小等；模板参数还能有默认值。**

<br>

## 知识点 7：模板具体化——给特定类型开小灶

***
<br>

### 问题

<br>

你的通用模板对大多数类型都适用，但比较 `char*` 时，你希望比较字符串内容，而不是指针地址。通用模板做不到，怎么办？

<br>

### 方案

<br>

用**显式具体化**。对于函数模板，写 `template <> bool compare<char*>(char* const& a, char* const& b)`。对于类模板，可以写 `template <> class Stack<char*> { ... };`。还有**部分具体化**，比如对指针类型特殊处理。**显式实例化**是告诉编译器“给我生成这个类型的版本”，语法是 `template class Stack<int>;`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <cstring>

template <typename T>
bool is_equal(T a, T b) {
    return a == b;
}

// 显式具体化：针对 const char* 比较内容
template <>
bool is_equal<const char*>(const char* a, const char* b) {
    return std::strcmp(a, b) == 0;
}

int main() {
    std::cout << std::boolalpha;
    std::cout << is_equal(1, 1) << std::endl;             // 通用版本
    std::cout << is_equal("hello", "hello") << std::endl; // 具体化版本，比较内容
    return 0;
}
```

运行结果：

```text
true
true
```

如果不写具体化，`is_equal("hello", "hello")` 比较的是指针地址，结果可能是 `false`。

<br>

### 一句话总结

<br>

**具体化就是给模板的特定类型开小灶，写一份特殊版本；显式实例化是让编译器生成指定类型的代码。**

<br>

## 知识点 8：模板别名——用 using 给模板起短名字

***
<br>

### 问题

<br>

`std::array<int, 12>` 写起来太长，每次都要写一遍。能不能起个短名字？

<br>

### 方案

<br>

用 **`using` 模板别名**：`template<typename T> using arrtype = std::array<T, 12>;`。之后 `arrtype<int>` 就等价于 `std::array<int, 12>`。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <array>

template <typename T>
using arrtype = std::array<T, 12>;   // 模板别名

int main() {
    arrtype<int> a;
    a[0] = 42;
    std::cout << "a[0] = " << a[0] << std::endl;
    std::cout << "Size: " << a.size() << std::endl;
    return 0;
}
```

运行结果：

```text
a[0] = 42
Size: 12
```

<br>

### 一句话总结

<br>

**模板别名就是给模板起个短名字，用 `using` 定义，比 `typedef` 更清晰，还支持模板参数。**

<br>

## 完整可运行代码
***

下面把这一章的主要知识点整合到一个程序里：类模板 `Stack`（带非类型参数和默认参数）、包含、私有继承、多重继承与虚基类。你可以直接复制运行。

```cpp
#include <iostream>
#include <string>

// 类模板：带非类型参数和默认参数
template <class T, int n = 10>
class Stack {
private:
    T items[n];
    int top;
public:
    Stack() : top(0) {}

    bool push(const T& item) {
        if (top >= n) return false;
        items[top++] = item;
        return true;
    }

    bool pop(T& item) {
        if (top <= 0) return false;
        item = items[--top];
        return true;
    }

    int capacity() const { return n; }
};

// 包含：has-a
class Engine {
public:
    void start() const { std::cout << "Engine started" << std::endl; }
};

class Car {
private:
    Engine engine;
    std::string model;
public:
    Car(const std::string& m) : model(m) {}
    void drive() const {
        std::cout << model << ": ";
        engine.start();
    }
};

// 私有继承：借用实现，不暴露接口
class Base {
protected:
    int value;
public:
    Base(int v = 0) : value(v) {}
    void show() const { std::cout << "Base value: " << value << std::endl; }
};

class Derived : private Base {
public:
    Derived(int v) : Base(v) {}
    void show_derived() const {
        std::cout << "Derived value: " << value << std::endl;
        show();
    }
};

// 多重继承与虚基类
class Animal {
protected:
    int age;
public:
    Animal(int a = 0) : age(a) {}
    void show_age() const { std::cout << "Age: " << age << std::endl; }
};

class Mammal : virtual public Animal {
public:
    Mammal(int a = 0) : Animal(a) {}
};

class Bird : virtual public Animal {
public:
    Bird(int a = 0) : Animal(a) {}
};

class Platypus : public Mammal, public Bird {
public:
    Platypus(int a) : Animal(a), Mammal(a), Bird(a) {}
};

int main() {
    std::cout << "=== 类模板 ===" << std::endl;
    Stack<int, 5> si;
    si.push(1);
    si.push(2);
    int x;
    si.pop(x);
    std::cout << "Popped: " << x << ", Capacity: " << si.capacity() << std::endl;

    Stack<std::string> ss;
    ss.push("hello");
    std::string s;
    ss.pop(s);
    std::cout << "Popped: " << s << ", Default capacity: " << ss.capacity() << std::endl;

    std::cout << "\n=== 包含 ===" << std::endl;
    Car c("Toyota");
    c.drive();

    std::cout << "\n=== 私有继承 ===" << std::endl;
    Derived d(42);
    d.show_derived();

    std::cout << "\n=== 多重继承与虚基类 ===" << std::endl;
    Platypus p(3);
    p.show_age();

    return 0;
}
```

运行结果示例：

```text
=== 类模板 ===
Popped: 2, Capacity: 5
Popped: hello, Default capacity: 10

=== 包含 ===
Toyota: Engine started

=== 私有继承 ===
Derived value: 42
Base value: 42

=== 多重继承与虚基类 ===
Age: 3
```
