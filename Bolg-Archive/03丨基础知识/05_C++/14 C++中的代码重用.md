## 一句话概括
***
**一句话**：包含、私有继承、多重继承、类模板都是代码重用手段。

<br>

<br>

## 核心概念
***
- 包含（组合）：has-a 关系，成员对象。
- 私有继承：has-a 关系，继承实现，不继承接口。
- 保护继承：介于公有和私有之间。
- 多重继承：多个基类，可能产生二义性，用虚基类解决菱形继承。
- 类模板：`template <class T> class Stack { ... };`，实例化时指定类型。
- 模板参数：类型参数、非类型参数（如 `int n`）。
- 模板具体化：隐式实例化、显式实例化、显式具体化、部分具体化。
- 模板别名：`template<typename T> using arrtype = std::array<T,12>;`。

<br>

<br>

## 最小代码
***
```cpp
template <class T>
class Stack {
private:
    enum { MAX = 10 };
    T items[MAX];
    int top;
public:
    Stack();
    bool push(const T& item);
    bool pop(T& item);
};
```

<br>

<br>

## 易错点
***
- 模板定义通常放在头文件中。
- 多重继承中同名成员需用类名限定。
- 虚基类构造函数需显式调用。
- 模板具体化语法容易混淆。

<br>

<br>

## 项目用途
***
- 泛型容器、算法。
- 组合优于继承。
- 多重继承少用，虚基类更少。
