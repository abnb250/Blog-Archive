## 一句话概括
***
**一句话**：友元类/成员函数扩展访问权限；异常处理分离错误检测与处理；类型转换运算符更安全。

<br>

<br>

## 核心概念
***
- 友元类：`friend class Remote;`。
- 友元成员函数：`friend void Remote::set_chan(Tv&, int);`，需前向声明。
- 嵌套类：类中定义类，作用域限制。
- 异常：`try`、`throw`、`catch`。
- 异常类：从 `std::exception` 派生，重写 `what()`。
- 栈解退：异常抛出后，栈中对象析构。
- 异常规范：C++11 用 `noexcept`。
- 类型转换运算符：`dynamic_cast`、`const_cast`、`static_cast`、`reinterpret_cast`。

<br>

<br>

## 最小代码
***
```cpp
#include <exception>
class BadHmean : public std::exception {
public:
    const char* what() const noexcept override {
        return "bad hmean arguments";
    }
};

double hmean(double a, double b) {
    if (a == -b) throw BadHmean();
    return 2.0 * a * b / (a + b);
}

int main() {
    try {
        double z = hmean(10, -10);
    } catch (const std::exception& e) {
        std::cout << e.what() << std::endl;
    }
}
```

<br>

<br>

## 易错点
***
- 异常被抛出后，栈解退会析构局部对象，但裸指针不会自动 `delete`。
- `catch` 按引用捕获，避免切片。
- 不要抛出裸指针。
- `noexcept` 用于不抛异常的函数。
