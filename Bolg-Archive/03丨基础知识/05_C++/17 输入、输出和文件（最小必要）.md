## 一句话概括
***
**一句话**：用 `fstream` 读写文件，`stringstream` 做字符串与数字转换。

<br>

<br>

## 核心概念
***
### 文件写入
```cpp
#include <fstream>

std::ofstream outFile("output.txt");
if (!outFile.is_open()) {
    std::cerr << "无法打开文件" << std::endl;
    return 1;
}

outFile << "hello" << std::endl;
outFile << 123 << std::endl;

outFile.close();
```

<br>

### 文件读取
```cpp
std::ifstream inFile("input.txt");
if (!inFile.is_open()) {
    std::cerr << "无法打开文件" << std::endl;
    return 1;
}

std::string line;
while (std::getline(inFile, line)) {
    std::cout << line << std::endl;
}

// 或逐词读取
int num;
while (inFile >> num) {
    std::cout << num << std::endl;
}

inFile.close();
```

<br>

### 同时读写
```cpp
std::fstream file("data.txt", std::ios::in | std::ios::out);
```

<br>

### stringstream
```cpp
#include <sstream>

// 数字转字符串
std::stringstream ss;
ss << 123 << " " << 456;
std::string s = ss.str(); // "123 456"

// 字符串转数字
std::stringstream ss2("123 456");
int a, b;
ss2 >> a >> b; // a=123, b=456
```

## 最小代码
***
```cpp
#include <iostream>
#include <fstream>
#include <string>
#include <sstream>

int main() {
    // 写入
    std::ofstream out("demo.txt");
    if (!out) {
        std::cerr << "open failed" << std::endl;
        return 1;
    }
    out << "line1" << std::endl;
    out << 42 << std::endl;
    out.close();

    // 读取
    std::ifstream in("demo.txt");
    if (!in) {
        std::cerr << "open failed" << std::endl;
        return 1;
    }
    std::string line;
    while (std::getline(in, line)) {
        std::cout << line << std::endl;
    }
    in.close();

    // stringstream
    std::stringstream ss("100 200");
    int x, y;
    ss >> x >> y;
    std::cout << x + y << std::endl;

    return 0;
}
```

<br>

<br>

## 易错点
***
- 打开文件后必须检查 `is_open()` 或 `!inFile`。
- `getline` 读取的行不包含换行符。
- 文件流对象在析构时会自动关闭，但显式 `close()` 更好。
- `stringstream` 重复使用前要 `clear()` 和 `str("")`。

<br>

<br>

## 项目用途
***
- 读写配置文件、日志、数据文件。
- `stringstream` 做类型转换和格式化。
- 处理 CSV、JSON 等文本数据的基础。
