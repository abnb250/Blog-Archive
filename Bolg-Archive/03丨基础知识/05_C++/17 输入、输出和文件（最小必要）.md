## 知识点 1：把数据写到文件里——ofstream

***
<br>

### 问题

<br>

你在程序里算出了结果，比如 `"hello"` 和 `42`，想保存到 `output.txt`，下次还能打开看。怎么办？

<br>

### 方案

<br>

用 **`std::ofstream`**（output file stream）。它就像文件版的 `std::cout`，你可以用 `<<` 把数据写进去。需要包含 `<fstream>` 头文件。

**打开文件后必须检查是否成功**，用 `is_open()` 或直接判断 `if (!outFile)`。如果文件打不开（比如路径不对、没权限），后面写入都会失败。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <fstream>

int main() {
    std::ofstream outFile("output.txt");

    if (!outFile.is_open()) {
        std::cerr << "无法打开文件" << std::endl;
        return 1;
    }

    outFile << "hello" << std::endl;
    outFile << 123 << std::endl;

    outFile.close();

    std::cout << "写入完成" << std::endl;
    return 0;
}
```

运行结果（屏幕）：

```text
写入完成
```

同时当前目录下会生成 `output.txt`，内容为：

```text
hello
123
```

<br>

### 一句话总结

<br>

**`ofstream` 就是文件版的 `cout`，用 `<<` 写数据，打开后记得检查是否成功。**

<br>

## 知识点 2：从文件读数据——ifstream 和 getline

***
<br>

### 问题

<br>

你有一个 `input.txt`，里面有几行文字和数字，想读进来逐行打印，或者逐个词解析。怎么办？

<br>

### 方案

<br>

用 **`std::ifstream`**（input file stream）。它就像文件版的 `std::cin`。

- **逐行读取**：用 `std::getline(inFile, line)`，每次读一行，**读到的字符串不包含换行符**。
- **逐词读取**：用 `inFile >> num`，像 `cin` 一样按空白分割。

同样，打开后要检查是否成功。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <fstream>
#include <string>

int main() {
    // 先准备一个文件
    {
        std::ofstream out("input.txt");
        out << "line1" << std::endl;
        out << "line2" << std::endl;
        out << 100 << " " << 200 << std::endl;
    }

    // 逐行读取
    std::ifstream inFile("input.txt");
    if (!inFile.is_open()) {
        std::cerr << "无法打开文件" << std::endl;
        return 1;
    }

    std::string line;
    std::cout << "逐行读取：" << std::endl;
    while (std::getline(inFile, line)) {
        std::cout << line << std::endl;
    }
    inFile.close();

    // 逐词读取数字
    std::ifstream inFile2("input.txt");
    int a, b;
    std::string word1, word2;
    inFile2 >> word1 >> word2;   // 读 "line1" "line2"
    inFile2 >> a >> b;           // 读 100 200
    std::cout << "逐词读取数字：" << a << ", " << b << std::endl;
    inFile2.close();

    return 0;
}
```

运行结果：

```text
逐行读取：
line1
line2
100 200
逐词读取数字：100, 200
```

<br>

### 一句话总结

<br>

**`ifstream` 是文件版的 `cin`，`getline` 读一行（不含换行符），`>>` 读一个词，打开后要检查。**

<br>

## 知识点 3：同时读写同一个文件——fstream

***
<br>

### 问题

<br>

你想打开一个文件，既能读又能写，比如修改某些内容。`ofstream` 只能写，`ifstream` 只能读，怎么办？

<br>

### 方案

<br>

用 **`std::fstream`**。打开时用按位或指定模式：

```cpp
std::fstream file("data.txt", std::ios::in | std::ios::out);
```

这样文件同时具备读和写的能力。注意：如果文件不存在，默认可能不会创建，需要加 `std::ios::trunc` 或 `std::ios::app` 等模式。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <fstream>
#include <string>

int main() {
    // 先创建一个文件
    {
        std::ofstream out("data.txt");
        out << "hello" << std::endl;
    }

    // 同时读写
    std::fstream file("data.txt", std::ios::in | std::ios::out);
    if (!file.is_open()) {
        std::cerr << "无法打开文件" << std::endl;
        return 1;
    }

    std::string line;
    std::getline(file, line);
    std::cout << "读到: " << line << std::endl;

    // 移动到开头，写入新内容（会覆盖）
    file.seekp(0);
    file << "world" << std::endl;

    file.close();

    // 验证
    std::ifstream in("data.txt");
    std::getline(in, line);
    std::cout << "现在文件内容: " << line << std::endl;

    return 0;
}
```

运行结果：

```text
读到: hello
现在文件内容: world
```

<br>

### 一句话总结

<br>

**`fstream` 同时具备读写能力，打开模式用 `ios::in | ios::out` 指定，注意文件位置指针的移动。**

## 知识点 4：字符串和数字互相转换——stringstream

***
<br>

### 问题

<br>

你想把数字 `123` 和 `456` 拼成一个字符串 `"123 456"`，或者反过来，把字符串 `"123 456"` 解析成两个整数。用 `sprintf` 或 `atoi` 太麻烦，有没有更 C++ 的方式？

<br>

### 方案

<br>

用 **`std::stringstream`**。它就像内存里的流，你可以像用 `cout` 和 `cin` 一样往里面写、从里面读。

- **数字转字符串**：`ss << 123 << " " << 456;` 然后 `ss.str()` 得到字符串。
- **字符串转数字**：`std::stringstream ss("123 456"); ss >> a >> b;`

**重复使用同一个 `stringstream` 前，必须调用 `clear()` 和 `str("")`**，否则状态和内容还在，会出错。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <sstream>
#include <string>

int main() {
    // 数字转字符串
    std::stringstream ss;
    ss << 123 << " " << 456;
    std::string s = ss.str();
    std::cout << "数字转字符串: " << s << std::endl;

    // 字符串转数字
    std::stringstream ss2("123 456");
    int a, b;
    ss2 >> a >> b;
    std::cout << "字符串转数字: a = " << a << ", b = " << b << std::endl;
    std::cout << "相加: " << a + b << std::endl;

    // 重复使用要 clear 和 str("")
    ss.str("");
    ss.clear();
    ss << 789;
    std::cout << "重复使用: " << ss.str() << std::endl;

    return 0;
}
```

运行结果：

```text
数字转字符串: 123 456
字符串转数字: a = 123, b = 456
相加: 579
重复使用: 789
```

**易错点**：`stringstream` 重复使用前不 `clear()` 和 `str("")`，可能会读到旧数据或状态错误。

<br>

### 一句话总结

<br>

**`stringstream` 就是内存里的流，方便做数字和字符串的互相转换，重复使用前记得 `clear()` 和 `str("")`。**

<br>

## 知识点 5：文件流对象的生命周期与显式关闭

***
<br>

### 问题

<br>

文件流对象什么时候关闭文件？我需要手动调用 `close()` 吗？如果忘了会怎样？

<br>

### 方案

<br>

文件流对象在**析构时会自动关闭文件**，所以不手动 `close()` 通常也不会泄漏。但**显式 `close()` 更好**：能及时释放文件句柄，也能让你清楚知道文件什么时候写完。另外，`close()` 之后再写入会失败。

<br>

### 最小示例

<br>

```cpp
#include <iostream>
#include <fstream>

int main() {
    {
        std::ofstream out("auto_close.txt");
        out << "自动关闭测试" << std::endl;
        // 离开作用域时 out 析构，自动关闭
    }

    std::cout << "文件已自动关闭" << std::endl;

    std::ofstream out2("manual_close.txt");
    out2 << "手动关闭测试" << std::endl;
    out2.close();   // 显式关闭

    if (out2.is_open()) {
        std::cout << "文件还开着" << std::endl;
    } else {
        std::cout << "文件已手动关闭" << std::endl;
    }

    return 0;
}
```

运行结果：

```text
文件已自动关闭
文件已手动关闭
```

<br>

### 一句话总结

<br>

**文件流对象析构时会自动关闭文件，但显式 `close()` 更清晰、更及时；关闭后不要再写入。**

<br>

## 完整可运行代码
***

下面把这一章的主要知识点整合到一个程序里：写文件、读文件、`getline`、`stringstream` 转换。你可以直接复制运行。

```cpp
#include <iostream>
#include <fstream>
#include <string>
#include <sstream>

int main() {
    // 1. 写入文件
    std::ofstream out("demo.txt");
    if (!out) {
        std::cerr << "open failed" << std::endl;
        return 1;
    }
    out << "line1" << std::endl;
    out << 42 << std::endl;
    out << "100 200" << std::endl;
    out.close();

    // 2. 逐行读取
    std::ifstream in("demo.txt");
    if (!in) {
        std::cerr << "open failed" << std::endl;
        return 1;
    }
    std::string line;
    std::cout << "文件内容：" << std::endl;
    while (std::getline(in, line)) {
        std::cout << line << std::endl;
    }
    in.close();

    // 3. stringstream 转换
    std::stringstream ss("100 200");
    int x, y;
    ss >> x >> y;
    std::cout << "x + y = " << x + y << std::endl;

    // 4. 数字转字符串
    std::stringstream ss2;
    ss2 << 3.14 << " " << 42;
    std::string result = ss2.str();
    std::cout << "转换结果: " << result << std::endl;

    return 0;
}
```

运行结果示例：

```text
文件内容：
line1
42
100 200
x + y = 300
转换结果: 3.14 42
```
