## 痛点引入
***
线上服务变慢，到底是带宽打满、延迟升高，还是丢包重传？**网络性能不能靠猜，得看指标。** 带宽、延时、吞吐率、PPS 是四个基本指标；`ip` 看网口配置和收发错误，`ss` 看 socket 队列，`sar` 看吞吐和 PPS，`ethtool` 看带宽，`ping` 看连通和延时。**先分清看哪一层，再选对应命令。**

<br>

<br>

## 知识点 1：四个基本性能指标
***
### 问题
***
说“网络慢”太模糊，到底该量什么？

<br>

### 方案
***
**带宽**：链路最大传输速率（b/s）；**延时**：请求到响应的耗时；**吞吐率**：单位时间成功传输的数据量，受带宽限制；**PPS**：每秒包数，衡量转发能力。辅助指标还有可用性、并发连接数、丢包率、重传率。**带宽看上限，延时看快慢，吞吐看实际，PPS 看转发。**

<br>

### 最小示例
***
```cpp
#include <iostream>
#include <fstream>
#include <string>

int main() {
    std::ifstream f("/proc/net/dev");
    std::string line;
    std::getline(f, line);
    std::getline(f, line);
    while (std::getline(f, line)) {
        if (line.find("eth0") != std::string::npos ||
            line.find("lo:") != std::string::npos) {
            std::cout << line << "\n";
        }
    }
}
```
编译运行：
```bash
g++ net1.cpp -o net1
./net1
```
输出类似：
```text
  eth0: 123456 789 0 0 0 0 0 0 654321 456 0 0 0 0 0 0
```
**易错点：** `/proc/net/dev` 给的是累计收发字节/包数，算吞吐和 PPS 要两次采样求差再除以时间。

<br>

### 一句话总结
***
**带宽是上限，延时是快慢，吞吐是实际流量，PPS 是包转发能力。**

<br>

***

## 知识点 2：用 ip/ifconfig 看网口配置和错误
***
### 问题
***
网口通没通、MTU 多大、有没有丢包错误，去哪看？

<br>

### 方案
***
`ip addr` / `ifconfig eth0` 看 IP、掩码、MAC、MTU、网口状态和收发统计。`RUNNING` / `LOWER_UP` 表示物理连通；MTU 默认 1500，过大要分片；`errors/dropped/overruns/carrier/collisions` 不为 0 说明收发有问题。**ip 比 ifconfig 更推荐，net-tools 维护少。**

<br>

### 最小示例
***
```bash
ip -s link show eth0
```
输出类似：
```text
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 ...
    RX: bytes  packets  errors  dropped overrun mcast
    ...
    TX: bytes  packets  errors  dropped carrier collsns
    ...
```
**易错点：** `dropped` 可能是 Ring Buffer 满或内存不足；`overruns` 是收得太快来不及处理；`carrier` 常查双工/网线。

<br>

### 一句话总结
***
**ip 看网口状态、MTU 和收发错误，errors/dropped/overruns/carrier 非 0 就要查。**

<br>

## 知识点 3：用 ss/netstat 看 socket 队列
***
### 问题
***
连接建没建上、应用读没读走、全连接队列满没满，怎么看？

<br>

### 方案
***
`ss -lnt` / `ss -tn` 看 socket 状态、Recv-Q、Send-Q、本地/远端地址、进程。**Established 时**：Recv-Q 是应用没读走的字节，Send-Q 是远端没确认的字节。**Listen 时**：Recv-Q 是全连接队列当前长度，Send-Q 是最大长度。半连接队列放未完成三次握手的连接，全连接队列放已完成握手等 `accept` 的连接。**生产优先用 ss，netstat 较重。**

<br>

### 最小示例
***
```bash
ss -lnt
ss -tn state established
```
输出类似：
```text
State  Recv-Q Send-Q Local Address:Port Peer Address:Port
LISTEN 0      128    0.0.0.0:80         0.0.0.0:*
ESTAB  0      0      10.0.0.1:80        10.0.0.2:54321
```
**易错点：** Listen 的 Recv-Q 不是“没读的数据”，而是全连接队列长度；队列满会丢新连接或触发 SYN 重传。

<br>

### 一句话总结
***
**Established 看应用读没读、远端确认没确认；Listen 看全连接队列当前长度和上限。**

<br>

## 知识点 4：用 sar/ethtool 看吞吐、PPS 和带宽
***
### 问题
***
实时吞吐率、PPS 和网卡带宽上限怎么量？

<br>

### 方案
***
`sar -n DEV 1` 看 `rxpck/s`、`txpck/s`（PPS）和 `rxkB/s`、`txkB/s`（吞吐）；`sar -n EDEV` 看错误；`sar -n TCP` 看 TCP 统计。`ethtool eth0 | grep Speed` 看带宽上限，单位是 Mb/s（比特）。**sar 看实际流量，ethtool 看链路能力。**

<br>

### 最小示例
***
```bash
sar -n DEV 1 3
ethtool eth0 | grep Speed
```
输出类似：
```text
IFACE  rxpck/s txpck/s rxkB/s txkB/s
eth0   1200    980     800    600
Speed: 1000Mb/s
```
**易错点：** `Mb/s` 是兆比特，不是兆字节；算利用率要把字节吞吐换算成比特再除以带宽。

<br>

### 一句话总结
***
**sar 看实际 PPS 和吞吐，ethtool 看网卡带宽上限，单位别把比特当字节。**

<br>

### 自测
***
自测：`rxkB/s` 是 100000，千兆网卡利用率大概多少？

## 知识点 5：用 ping 看连通和延时
***
### 问题
***
本机到目标通不通、往返延迟多少、丢不丢包？

<br>

### 方案
***
`ping` 基于 ICMP，看 `icmp_seq`、`TTL`、`time` 和最后 `packet loss`。**ping 不通不代表 HTTP 不通**，防火墙可能禁 ICMP。**ping 测网络层连通和 RTT，不测应用层。**

<br>

### 最小示例
***
```bash
ping -c 4 192.168.12.20
```
输出类似：
```text
4 packets transmitted, 4 received, 0% packet loss
rtt min/avg/max/mdev = 0.5/0.8/1.2/0.2 ms
```
**易错点：** 目标禁 ICMP 时 ping 失败但服务正常；高延迟要看是链路、拥塞还是对端处理慢。

<br>

### 一句话总结
***
**ping 用 ICMP 测连通和往返延时，ping 不通不等于服务不通。**

<br>

### 自测
***
自测：`packet loss` 非 0 说明什么？一定影响 TCP 吗？

## 完整可运行/可复现示例
***
```cpp
#include <iostream>
#include <fstream>
#include <string>

int main() {
    std::ifstream f("/proc/net/dev");
    std::string line;
    std::getline(f, line);
    std::getline(f, line);

    while (std::getline(f, line)) {
        if (line.find("eth0") != std::string::npos) {
            std::cout << "raw: " << line << "\n";
        }
    }

    std::ifstream s("/proc/sys/net/core/somaxconn");
    std::string v;
    std::getline(s, v);
    std::cout << "somaxconn=" << v << "\n";
}
```
编译运行：
```bash
g++ net_all.cpp -o net_all
./net_all
```
**注意：** 依赖 Linux `/proc`；实际排查配合 `ip`、`ss`、`sar`、`ping` 一起看。

***
