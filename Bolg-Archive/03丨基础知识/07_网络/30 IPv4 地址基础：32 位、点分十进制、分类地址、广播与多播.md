## 优先级说明
***
这篇是 IPv4 地址的基础，面试常问，项目里算子网、配地址、排查“同网段不通”也会用到。先分清主次：

**必须掌握（面试常问、项目真用得上）：**
- IPv4 本质是 32 位二进制，点分十进制只是给人看
- 每一段 8 位，范围 0~255
- A/B/C 类由前几位分类号区分，网络号 + 主机号
- 主机号全 0 是网络地址，全 1 是广播地址，普通主机不能占
- C 类可用主机数是 \(2^8 - 2 = 254\)，不是 256
- 广播通常局限在本链路，多播发给特定组，可跨网段
- 一台主机可以有多张网卡、多个 IP，不是“一台电脑只能一个 IP”
- NAT 缓解 IPv4 耗尽，但不是无限扩展

**了解即可（知道大概，不展开）：**
- D 类、E 类的完整地址范围
- 分类地址和 CIDR 的历史关系
- 直接广播和受限广播的区别
- IPv4 地址耗尽和 IPv6 过渡

**主线**：IPv4 是 32 位 → 点分十进制只是翻译 → 地址分网络号和主机号 → 全 0 是网络、全 1 是广播 → 所以可用主机数要减 2 → D 类多播、E 类保留。

## 知识点 1：IPv4 是 32 位，点分十进制只是方便人看
***
### 问题

IPv4 地址本质是什么？为什么写成四段数字？32 位理论上约 43 亿个地址，为什么实际可用的更少？一台电脑只能有一个 IP 吗？

**你可能会想**：`192.168.1.1` 就是四个数字用点隔开，背下来不就行了？

但计算机不认“点分十进制”，它只认二进制。**点分十进制只是给人看的翻译，底层是 32 个比特。** 不理解这一点，后面算子网、算广播地址都会卡。

<br>

### 核心概念与方案

先把 IPv4 地址换成你熟悉的场景：**IPv4 像一张 32 位的身份证，点分十进制只是把 32 位切成四段、每段翻译成十进制，方便人读。**

IPv4 地址本质是 **32 位正整数**，计算机按二进制处理。人类用**点分十进制**：每 8 位一组，共 4 组，每组转十进制，用点隔开。所以 `192.168.1.1` 只是给人看的“翻译”，底层是 32 个比特。

理论上 32 位可表示约 43 亿个地址，但实际可分配主机数更少，原因有几层：

- 地址分**网络号 + 主机号**，每个网络的主机号全 0 和全 1 有特殊用途，不能分配给普通主机。
- 地址按网卡配置，服务器、路由器常有多网卡多 IP，不是“一台电脑只能一个 IP”。
- NAT 让很多设备共享公网 IP，缓解了 IPv4 耗尽，但也让“可全局直接寻址”的地址更紧张。

<br>

### 最小实验：只看点分十进制每一段是不是 0~255

环境前提：Linux/macOS，或 Windows WSL；已安装 `g++` 且支持 C++17。下面只做本地解析，不联网。

保存为 `ipv4_bits.cpp`：

````cpp
#include <arpa/inet.h>

#include <cstdint>
#include <iostream>
#include <string>

int main() {
    const char* ip_str = "192.168.1.1";

    in_addr addr{};
    if (inet_pton(AF_INET, ip_str, &addr) != 1) {
        std::cerr << "非法 IPv4 地址\n";
        return 1;
    }

    uint32_t ip = ntohl(addr.s_addr);

    std::cout << ip_str << " 的 32 位二进制：\n";
    for (int i = 31; i >= 0; --i) {
        std::cout << ((ip >> i) & 1u);
        if (i % 8 == 0 && i != 0) std::cout << ".";
    }
    std::cout << "\n";

    return 0;
}
````

编译运行：

````bash
g++ -std=c++17 -O2 ipv4_bits.cpp -o ipv4_bits
./ipv4_bits
````

**这次只看一件事**：输出里是不是四组 8 位二进制，用点隔开。

预期输出：

````text
192.168.1.1 的 32 位二进制：
11000000.10101000.00000001.00000001
````

四组 8 位，正好 32 位。**每一段对应 8 位，所以范围是 0~255。** 如果看到某段超过 255 的写法，那不是合法 IPv4 点分十进制。

如果输出不是四组 8 位，先检查 `inet_pton` 是否解析成功、字节序有没有搞错。

<br>

### 易错点与边界

坑一：**IP 配在网卡上，不是“一台电脑只能一个 IP”**；一台主机可以有多张网卡、多个 IP。

坑二：**43 亿不是实际可分配主机数**，网络地址、广播地址、保留地址、NAT 都会影响实际可用数量。

坑三：**NAT 缓解了 IPv4 耗尽**，但不是无限扩展；大量设备共享一个公网 IP，外部无法直接主动连入。

坑四：**每一段是 8 位，范围 0~255**；看到某段超过 255 的写法，那不是合法 IPv4 点分十进制。

<br>

### 一句话本质

**IPv4 是 32 位二进制地址，点分十进制只是给人看的“翻译”；每段 8 位，四段正好 32 位。**

<br>

### 自测

`192.168.1.1` 的每一段对应多少位二进制？为什么 32 位地址的理论数量和实际可分配主机数不是一回事？

<details><summary>答案</summary>每一段对应 8 位二进制，四段共 32 位。32 位理论上约 43 亿个地址，但实际可分配主机数更少：每个网络的主机号全 0 和全 1 有特殊用途，不能分配给普通主机；地址按网卡配置，一台主机可有多个 IP；NAT 让很多设备共享公网 IP，也影响可全局直接寻址的地址数量。</details>

## 知识点 2：A/B/C/D/E 类地址与特殊主机号——全 0 是网络，全 1 是广播
***
### 问题

分类地址怎么分？A/B/C 类各有多少主机号位？主机号全 0 和全 1 分别干什么？为什么 C 类一个网络最多 254 台主机？广播和多播差在哪？

**你可能会想**：C 类有 8 位主机号，\(2^8 = 256\)，那不就是 256 台主机吗？

不是 256，是 254。**主机号全 0 表示网络地址，全 1 表示广播地址，这两个不能分配给普通主机。** 所以 \(256 - 2 = 254\)。

<br>

### 核心概念与方案

先把分类地址换成你熟悉的场景：**地址像“小区名 + 门牌号”，网络号是小区名，主机号是门牌号；门牌号全 0 是小区本身，全 1 是小区广播，不能住人。**

A/B/C 类由前几位分类号区分，地址包含**网络号 + 主机号**：

- **A 类**：首位 0，网络号 8 位，主机号 24 位，主机号多。
- **B 类**：前两位 10，网络号 16 位，主机号 16 位，中等。
- **C 类**：前三位 110，网络号 24 位，主机号只有 8 位。

主机号**全 0** 表示网络地址；主机号**全 1** 表示该网络的广播地址。所以每个网络可用主机数要减 2，C 类就是 \(2^8 - 2 = 254\)。

**D 类**（前四位 1110）用于**多播**，E 类（前四位 1111）保留。多播是把包发给特定组内主机，可跨网段；广播通常局限在本链路，直接广播有安全风险，路由器常不转发。

注意：现代网络常用 CIDR 代替分类地址，分类地址更多是历史和基础概念；但主机号全 0/全 1 的特殊含义仍然适用。

<br>

### 最小实验：只看 C 类网段可用主机数是不是 254

环境前提：同上。下面只做本地计算，不联网。

保存为 `c_class_hosts.cpp`：

````cpp
#include <arpa/inet.h>

#include <cstdint>
#include <iostream>
#include <string>

int main() {
    const char* cidr = "192.168.1.0/24";

    std::string s = cidr;
    auto slash = s.find('/');
    std::string ip_str = s.substr(0, slash);
    int prefix = std::stoi(s.substr(slash + 1));

    in_addr addr{};
    if (inet_pton(AF_INET, ip_str.c_str(), &addr) != 1) {
        std::cerr << "非法 IPv4 地址\n";
        return 1;
    }

    uint32_t ip = ntohl(addr.s_addr);
    uint32_t mask = (prefix == 0) ? 0u : (0xFFFFFFFFu << (32 - prefix));
    uint32_t network = ip & mask;
    uint32_t broadcast = network | ~mask;

    uint64_t total = 1ULL << (32 - prefix);
    uint64_t usable = (total > 2) ? (total - 2) : 0;

    auto to_str = [](uint32_t v) {
        in_addr a{};
        a.s_addr = htonl(v);
        char buf[INET_ADDRSTRLEN];
        inet_ntop(AF_INET, &a, buf, sizeof(buf));
        return std::string(buf);
    };

    std::cout << "网段: " << cidr << "\n";
    std::cout << "网络地址: " << to_str(network) << "\n";
    std::cout << "广播地址: " << to_str(broadcast) << "\n";
    std::cout << "总地址数: " << total << "\n";
    std::cout << "可用主机数: " << usable << "\n";

    return 0;
}
````

编译运行：

````bash
g++ -std=c++17 -O2 c_class_hosts.cpp -o c_class_hosts
./c_class_hosts
````

**这次只看一件事**：`可用主机数` 是不是 254。

预期输出：

````text
网段: 192.168.1.0/24
网络地址: 192.168.1.0
广播地址: 192.168.1.255
总地址数: 256
可用主机数: 254
````

总地址 256，可用 254，少的两个就是网络地址 `.0` 和广播地址 `.255`。

**关键观察点**：网络地址主机号全 0，广播地址主机号全 1，普通主机从 `.1` 到 `.254`。

如果可用主机数不是 254，先检查前缀是不是 24、计算逻辑有没有减 2。

<br>

### 易错点与边界

坑一：**C 类最大主机数不是 256，而是 254**，网络地址和广播地址各占一个。

坑二：**广播不能随便穿路由**，通常局限在本链路；直接广播有安全风险，路由器常不转发。

坑三：**多播地址不是给网卡配的主机 IP**，而是表示一组接收者；主机通过加入多播组来接收。

坑四：**A/B/C 类边界容易记混**：A 类首位 0，B 类前两位 10，C 类前三位 110，D 类前四位 1110，E 类前四位 1111。

坑五：**分类地址不是现代分配的主要方式**，CIDR 更常用；但特殊主机号规则仍然要掌握。

<br>

### 一句话本质

**分类地址靠前几位分网络规模；全 0 是网络本身，全 1 是广播，普通主机不能占；所以 C 类可用主机是 254，不是 256。**

<br>

### 自测

为什么 C 类地址一个网络最多 254 台主机？广播和多播在“接收者范围”上有什么区别？

<details><summary>答案</summary>C 类主机号 8 位，总共有 \(2^8 = 256\) 个组合；主机号全 0 是网络地址，全 1 是广播地址，这两个不能分配给普通主机，所以可用主机数是 \(256 - 2 = 254\)。广播通常局限在本链路，发给链路上所有主机；多播发给特定组内主机，可跨网段，主机通过加入多播组来接收。</details>

## 完整可复现示例：用 C++ 计算网络地址、广播地址和可用主机数
***
你需要 Linux/macOS 或 WSL，已安装 `g++`。下面把前面的地址解析和主机数计算串起来，每个步骤只看一个观察点。

````bash
g++ -std=c++17 -O2 ipv4_cidr.cpp -o ipv4_cidr
./ipv4_cidr 172.20.0.0/16
````

````cpp
#include <arpa/inet.h>

#include <cstdint>
#include <iostream>
#include <string>

bool parse_ipv4(const std::string& s, uint32_t& out) {
    in_addr addr{};
    if (inet_pton(AF_INET, s.c_str(), &addr) != 1) return false;
    out = ntohl(addr.s_addr);
    return true;
}

std::string ipv4_to_string(uint32_t ip) {
    in_addr addr{};
    addr.s_addr = htonl(ip);
    char buf[INET_ADDRSTRLEN];
    if (inet_ntop(AF_INET, &addr, buf, sizeof(buf)) == nullptr) return "invalid";
    return std::string(buf);
}

int main(int argc, char* argv[]) {
    std::string cidr = (argc > 1) ? argv[1] : "172.20.0.0/16";

    auto slash = cidr.find('/');
    if (slash == std::string::npos) {
        std::cerr << "用法: " << argv[0] << " 172.20.0.0/16\n";
        return 1;
    }

    std::string ip_str = cidr.substr(0, slash);
    int prefix = std::stoi(cidr.substr(slash + 1));

    if (prefix < 0 || prefix > 32) {
        std::cerr << "前缀长度必须在 0~32\n";
        return 1;
    }

    uint32_t ip = 0;
    if (!parse_ipv4(ip_str, ip)) {
        std::cerr << "非法 IPv4 地址\n";
        return 1;
    }

    uint32_t mask = (prefix == 0) ? 0u : (0xFFFFFFFFu << (32 - prefix));
    uint32_t network = ip & mask;
    uint32_t broadcast = network | ~mask;

    uint64_t total = 1ULL << (32 - prefix);
    uint64_t usable = (total > 2) ? (total - 2) : 0;

    std::cout << "网段: " << cidr << "\n";
    std::cout << "网络地址: " << ipv4_to_string(network) << "\n";
    std::cout << "广播地址: " << ipv4_to_string(broadcast) << "\n";
    std::cout << "总地址数: " << total << "\n";
    std::cout << "可用主机数: " << usable << "\n";

    std::cout << "前 3 个主机: ";
    for (uint64_t i = 1; i <= 3 && i < total - 1; ++i) {
        std::cout << ipv4_to_string(network + static_cast<uint32_t>(i)) << " ";
    }
    std::cout << "\n";

    return 0;
}
````

预期输出：

````text
网段: 172.20.0.0/16
网络地址: 172.20.0.0
广播地址: 172.20.255.255
总地址数: 65536
可用主机数: 65534
前 3 个主机: 172.20.0.1 172.20.0.2 172.20.0.3
````

**关键观察点**：网络地址主机号全 0，广播地址主机号全 1，可用主机数 = 总地址数 − 2。

验证结果：`/16` 有 65536 个地址，可用 65534 个；普通主机从 `.1` 开始，到广播地址前一个结束。

注意：这个程序假设输入是标准 CIDR 形式，没有校验输入地址的主机位是否为 0；如果输入 `172.20.1.5/16`，网络地址仍会算成 `172.20.0.0`，这是按掩码计算的正常行为。`/31` 和 `/32` 是特殊场景，可用主机数不能简单减 2，示例里对 `total <= 2` 返回 0，只是教学简化，**需按实际场景核实**。

## 常见误区
***
- **以为点分十进制就是地址本质**：底层是 32 位二进制，点分十进制只是给人看。
- **以为 32 位地址都能分配给主机**：网络地址、广播地址、保留地址、NAT 都会影响实际可用数量。
- **以为 C 类有 256 台主机**：主机号全 0 和全 1 不能用，可用 254 台。
- **把网络地址和广播地址配给主机**：会报错或导致通信异常。
- **以为广播能跨路由**：广播通常局限在本链路，路由器常不转发。
- **以为多播地址是配在网卡上的普通 IP**：多播表示一组接收者，主机通过加入多播组接收。
- **以为一台电脑只能一个 IP**：一台主机可以有多张网卡、多个 IP。

## 自测三问
***
1. IPv4 地址为什么用点分十进制？每一段对应多少位？
2. 主机号全 0 和全 1 分别代表什么？为什么 C 类一个网络最多 254 台主机？
3. 广播和多播有什么区别？多播地址为什么不是给网卡配的普通主机 IP？

<details><summary>参考答案</summary>1. IPv4 本质是 32 位二进制，点分十进制把 32 位切成四段、每段 8 位转十进制，方便人读；每段对应 8 位，范围 0~255。2. 主机号全 0 是网络地址，全 1 是广播地址，都不能分配给普通主机。C 类主机号 8 位，总共有 256 个组合，减去网络地址和广播地址，可用 254 台主机。3. 广播通常局限在本链路，发给链路上所有主机；多播发给特定组内主机，可跨网段。多播地址表示一组接收者，不是配在网卡上的普通主机 IP，主机通过加入多播组来接收。</details>

<br>

<br>

## 总结
***
**IPv4 是 32 位地址，点分十进制只是人类可读形式；A/B/C 类按网络规模划分，主机号全 0 是网络地址、全 1 是广播地址，所以可用主机数要减 2；D 类用于多播，E 类保留；广播通常局限本链路，多播发给特定组。**
