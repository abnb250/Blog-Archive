## 05 使用代码测试
***
最小必要理论（只讲今天用到的）：
- socket(AF_INET, SOCK_STREAM, 0)：买一台 TCP 电话，返回 fd（编号）。
- bind：把电话插到 8888 端口。
- listen：开机等电话。
- accept：电话响，接起来，返回一个新的 fd 专门和这个客户端通话。
- recv：从连接读数据。
- send：往连接写数据。
- close：挂电话。
- 阻塞：accept/recv 没数据时程序停在那里等。今天就是要你亲手感受这个“停”。

建 examples/echo_blocking_hand.cpp，照下面敲，并理解，每行后面写中文注释。敲完编译跑通。  
```cpp
// ============================================================
// 文件：examples/echo_blocking_hand.cpp
// 作用：手写一个阻塞 TCP echo 服务器
// 今天目标：看懂每一行，能指出哪两行会阻塞
// ============================================================

// include 就是“把别人写好的声明拿进来”，不 include 就不认识这些函数
#include <arpa/inet.h>    // sockaddr_in 结构体、htons、htonl、inet_ntoa
#include <cstdio>         // printf、perror
#include <cstring>        // memset（这里没直接用，但常配套）
#include <sys/socket.h>   // socket、bind、listen、accept、recv、send
#include <unistd.h>       // close、read、write

int main() {
    // --------------------------------------------------------
    // 第 1 步：买电话
    // socket() 创建一个 TCP socket，返回一个整数，叫 fd（文件描述符）
    // 参数 1：AF_INET      —— 用 IPv4 地址
    // 参数 2：SOCK_STREAM  —— 用 TCP（可靠的字节流）
    // 参数 3：0            —— 协议默认，TCP 就填 0
    // 返回值：>=0 是 fd 编号；<0 表示失败
    // --------------------------------------------------------
    int listenfd = socket(AF_INET, SOCK_STREAM, 0);

    // 如果失败，perror 会打印“socket: 具体原因”，然后 return 1 退出
    // return 0 表示正常结束，return 非 0 表示出错
    if (listenfd < 0) {
        perror("socket");   // perror 的参数是前缀，输出形如 "socket: Permission denied"
        return 1;
    }

    // --------------------------------------------------------
    // 第 2 步：允许端口复用
    // 不加这个，服务器重启时经常报 "Address already in use"
    // setsockopt 的参数：
    //   listenfd          —— 对哪个 socket 设置
    //   SOL_SOCKET        —— 套接字层通用选项
    //   SO_REUSEADDR      —— 允许复用本地地址
    //   &on               —— 选项值的地址
    //   sizeof(on)        —— 选项值多大
    // --------------------------------------------------------
    int on = 1;
    setsockopt(listenfd, SOL_SOCKET, SO_REUSEADDR, &on, sizeof(on));

    // --------------------------------------------------------
    // 第 3 步：准备地址
    // sockaddr_in 是“IPv4 地址 + 端口”的结构体
    // {} 表示全部字段清零，防止垃圾值
    // --------------------------------------------------------
    sockaddr_in addr{};
    addr.sin_family = AF_INET;                 // 地址族：IPv4
    addr.sin_addr.s_addr = htonl(INADDR_ANY);  // IP：INADDR_ANY 表示本机所有网卡
                                               // htonl = host to network long，转成网络字节序
    addr.sin_port = htons(8888);               // 端口 8888
                                               // htons = host to network short，转成网络字节序

    // --------------------------------------------------------
    // 第 4 步：把电话插到 8888 端口
    // bind 的参数：
    //   listenfd              —— 哪个 socket
    //   (sockaddr*)&addr      —— 地址结构体的指针，要强转成通用 sockaddr*
    //   sizeof(addr)          —— 地址结构体多大
    // --------------------------------------------------------
    if (bind(listenfd, (sockaddr*)&addr, sizeof(addr)) < 0) {
        perror("bind");
        return 1;
    }

    // --------------------------------------------------------
    // 第 5 步：开机等电话
    // listen 的参数：
    //   listenfd   —— 监听哪个 socket
    //   128        —— backlog，等待队列最大长度，先给 128
    // --------------------------------------------------------
    if (listen(listenfd, 128) < 0) {
        perror("listen");
        return 1;
    }
    printf("listening on 8888, listenfd=%d\n", listenfd);

    // --------------------------------------------------------
    // 第 6 步：死循环，一直接电话
    // --------------------------------------------------------
    while (true) {
        // cli 用来接收客户端的地址信息（IP、端口）
        sockaddr_in cli{};
        // len 是“传入传出参数”：传入 cli 的大小，accept 返回后是实际大小
        socklen_t len = sizeof(cli);

        // ----------------------------------------------------
        // 第 7 步：接电话 —— 【这里会阻塞】
        // 没有客户端连接时，程序停在这一行，不往下走
        // accept 返回一个新的 fd，叫 connfd，专门和这个客户端通话
        // listenfd 还是电话机，connfd 是接起来的这条通话
        // ----------------------------------------------------
        int connfd = accept(listenfd, (sockaddr*)&cli, &len);
        if (connfd < 0) {
            perror("accept");
            continue;   // 接失败就回去继续等下一个
        }
        printf("client connected, connfd=%d\n", connfd);

        // ------------------------------------------------
        // 第 8 步：和这个客户端循环说话
        // ------------------------------------------------
        char buf[4096];   // 收数据的缓冲区，一次最多 4096 字节
        while (true) {
            // --------------------------------------------
            // 第 9 步：收数据 —— 【这里也会阻塞】
            // 客户端不发数据时，程序停在这一行
            // recv 返回值：
            //   >0  读到的字节数
            //    0  对端关闭了连接（收到 FIN）
            //   -1  出错（阻塞模式下一般就是真错误）
            // --------------------------------------------
            ssize_t r = recv(connfd, buf, sizeof(buf), 0);

            if (r > 0) {
                // 读到 r 个字节，原样发回去
                // send 的参数和 recv 类似：fd、缓冲区、字节数、标志位
                send(connfd, buf, r, 0);
            } else if (r == 0) {
                // 客户端正常关闭
                printf("client closed, connfd=%d\n", connfd);
                break;   // 跳出内层 while，去 close 这个连接
            } else {
                // r < 0，出错
                perror("recv");
                break;
            }
        }

        // ------------------------------------------------
        // 第 10 步：挂电话
        // 关闭 connfd，但 listenfd 还开着，继续接下一个
        // ------------------------------------------------
        close(connfd);
    }

    // 正常不会走到这里，因为上面是死循环
    close(listenfd);
    return 0;
}
```

## 06 编译
***
你写的 .cpp 是文本，CPU 不认识。g++ 是翻译官，把文本翻译成机器能执行的二进制文件。就这三步：  
```text
echo_blocking.cpp  --(g++)-->  build/echo_blocking  --(./)--> 跑起来
   源代码文本                      可执行二进制                  进程
```

我们把命令拆开看：  
```bash
g++ -std=c++17 -Wall -Wextra -g -O0 -fsanitize=address,undefined examples/echo_blocking_hand.cpp -o build/echo_blocking_hand
```
- g++：翻译官。
- -std=c++17：按 C++17 标准翻译。
- -Wall -Wextra：把所有警告打开，警告往往是 bug 前兆。
- -g：带调试信息，以后 GDB 用。
- -O0：不优化，调试友好。
- -fsanitize=address：开 ASan，查内存越界、use-after-free、内存泄漏。
- -fsanitize=undefined：开 UBSan，查未定义行为，比如整数溢出、空指针解引用。
- examples/echo_blocking.cpp：输入文件。
- -o build/echo_blocking：输出到 build/echo_blocking。

## 07 理论解释
***
你看到终端 C 输入 second 后卡住没反应，这就是最直观的阻塞（Blocking）。  

为什么会卡住？  
服务端的代码在执行完第一个客户端的 accept 后，进入了内层的 while(true) 循环。  
此时，服务端在第一个连接上执行 recv 等待数据。因为它是阻塞的，如果没有收到数据，它就死死地等在这里，绝对不往下走。  
它根本没有机会回到最外层的 accept 去接待第二个客户端。哪怕第二个客户端已经建立好 TCP 连接了，服务端也看不见，自然无法回显。  

<br>

顺便科普：阻塞到底发生在哪？  
这段代码里有两个地方会“卡住”（阻塞线程）：  
accept()：如果没有新客户端连进来，它就阻塞在这里等。  
recv()：如果连上的客户端不发数据，它就阻塞在这里等。  
现在的死结是：服务端正卡在第一个客户端的 recv() 上，所以卡死了整个进程。这就是为什么我们要学 epoll 和“非阻塞 IO”。epoll 就是一个“大堂经理”，它来帮你盯着所有的连接，谁有数据了，才把谁叫过来处理。谁也不会卡死谁。
