## 01 WSL中的环境
***
首先要先安装好自己的wsl，这里是从已有wsl，但是忘记了开始写的。  
按Win + x，选择终端，输入：   
```bash
wsl -l -v
```  
得到类似输出，说明WSL2和Ubantu都在：
```bash
  NAME      STATE           VERSION
* Ubuntu    Running         2
```

<br>

输入`wsl`进入。  
进入后执行：
```bash
uname -a
cat /etc/os-release
g++ --version
cmake --version
nc -h
git --version
```
看看差什么，差什么就装什么。  
安装前先切回家目录：
```bash
cd ~
```
然后执行（装别的可以问问ai捏）：
```bash
sudo apt update
```
验证是否安装成功：
```bash
g++ --version
cmake --version
gdb --version
valgrind --version
```

## 02 创建仓库
***
我们先创建一个放本地仓库的文件夹。
```bash
mkdir -p ~/code
cd ~/code
```

<br>

然后我们给wsl单独配一个SSH密钥。  
```bash
ls -la ~/.ssh
```
如果显示目录为空，就生成一个密钥：
```bash
ssh-keygen -t ed25519 -C "命名"
```
一路回车，然后就可以查看公钥了：
```bash
cat ~/.ssh/id_ed25519.pub
```
形如：
```text
ssh-ed25519 AAAAC... 命名
```
复制整行，去 GitHub：  
右上角头像 → Settings  
左侧 SSH and GPG keys  
New SSH key  
Title 写 WSL2 Ubuntu，Key 粘贴刚才那行  
Add SSH key  
测试连接：  
```bash
ssh -T git@github.com
```
看到 Hi 什么什么，就代表成功了。  

<br>

然后我们就可以克隆了：
```bash
git clone 路径
```
成功后使用下面的命令来确定：
```bash
git remote -v
git log --oneline -3
ls -la
```
能够正常显示该项目内的内容则代表成功了。

## 03 创建目录与写.gitignore
***
这里的话，目录的安排，可以直接抄啊，毕竟是初学者嘛~  
而.gitignore就是指明在上传的时候，哪些文件需要被忽略，就是不被上传，可以看我之前的git系列里面有说。  
创建目录：  
```bash
mkdir -p examples docs build
```
写.gitignore
```bash
cat > .gitignore <<'EOF'
build/
*.o
*.out
EOF
```

## 04 VSCode + Remote-WSL
***
打开windows的vscode，在插件中输入wsl，安装 Microsoft 官方的 WSL 扩展（作者 Microsoft，名字就叫 WSL）。  
装完左下角会出现 >< 小图标。  

<br>

安装完之后检查wsl里有没有code命令：
```bash
which code
```
有输出（类似 /usr/bin/code 或 /mnt/c/.../code）就代表成功了。  
再在vscode中验证终端在wsl里，按Ctrl + ~ 打开终端。
