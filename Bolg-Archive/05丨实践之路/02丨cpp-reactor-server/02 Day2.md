## 01 set_nonblocking 工具函数
***
### 最小必要理论
阻塞 fd：recv/accept 没数据就卡住线程，一个慢客户端拖死整个服务器。  

非阻塞 fd：没数据立即返回 -1，errno == EAGAIN（或 EWOULDBLOCK）。EAGAIN 不是错误，意思是“现在没有，稍后再来”。  

fcntl(F_GETFL) 读当前 flags(文件描述符的状态标志)。

fcntl(F_SETFL, flags | O_NONBLOCK) 在原有基础上追加非阻塞位，变成非阻塞fd。  

<br>

### 代码
插在main（）之前：
```cpp
// 返回 0 成功，-1 失败
static int set_nonblocking(int fd) {
    int flags = fcntl(fd, F_GETFL, 0);          // 读当前 flags
    if (flags == -1) return -1;
    return fcntl(fd, F_SETFL, flags | O_NONBLOCK);  // 追加 O_NONBLOCK
}
```

<br>

### 验收
先编译通过即可。  

<br>

### 常见坑
忘 | flags，直接 F_SETFL, O_NONBLOCK 会把其他 flag 清掉。  

把 fcntl 返回值当 bool，0 是成功、-1 是失败，别写反。

## 02 创建监听 fd 并设非阻塞
***
### 最小必要理论
socket(AF_INET, SOCK_STREAM, 0) → 返回监听 fd。

SO_REUSEADDR：重启服务器不报 Address already in use（TIME_WAIT 残留）。

bind 绑定 IP:端口，listen 转监听态，内核(操作系统的)开始把完成TCP握手的连接放进 accept 队列。

监听 fd 必须设非阻塞，否则节 5 的 accept 循环会在没连接时卡死。

<br>

### 代码
插在`set_nonblocking`之后
```cpp
static int create_listenfd(int port) {
    int listenfd = socket(AF_INET, SOCK_STREAM, 0);
    if (listenfd < 0) { perror("socket"); exit(1); }

    int opt = 1;
    // 重启不报 Address already in use
    setsockopt(listenfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    sockaddr_in addr{};
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = htonl(INADDR_ANY);   // 监听所有网卡
    addr.sin_port = htons(port);                // host → network 字节序

    if (bind(listenfd, (sockaddr*)&addr, sizeof(addr)) < 0) {
        perror("bind"); exit(1);
    }
    if (listen(listenfd, SOMAXCONN) < 0) {
        perror("listen"); exit(1);
    }
    // 关键：监听 fd 非阻塞，accept 循环才安全
    if (set_nonblocking(listenfd) < 0) {
        perror("set_nonblocking"); exit(1);
    }
    return listenfd;
}
```

main也暂时稍作改动：
```cpp
int main() {
    int listenfd = create_listenfd(8888);
    printf("listen on 8888, listenfd=%d\n", listenfd);
    for (;;) sleep(1);   // 占位，节 4 换掉
    return 0;
}
```

## 03 创建 epoll 并注册监听 fd
***
### 最小必要理论
epoll_create1(0) 返回 epfd（一个内核事件表），整个服务器一个。  

struct epoll_event 两个字段：  
events：你关心的事件（EPOLLIN 可读 / EPOLLOUT 可写 / EPOLLERR / EPOLLHUP）。  
data：你的私有数据，通常放 fd，epoll_wait 返回时用它回查是哪个 fd 就绪。  

epoll_ctl(epfd, EPOLL_CTL_ADD, fd, &ev)：把 fd 加入关注列表。  

LT：水平触发（Level-Triggered, LT）：信号处于高电平时，一直触发。  
ET：边沿触发（Edge-Triggered, ET）：只在信号从低变高那一瞬间触发一次。  
ev.events = EPOLLIN; 里没有 EPOLLET 这一位 → epoll 按 LT 工作。  
ev.events = EPOLLIN | EPOLLET; 里设了这一位 → epoll 按 ET 工作。  

<br>

### 代码
main中替换占位：
```cpp
int main() {
    int listenfd = create_listenfd(8888);
    printf("listen on 8888, listenfd=%d\n", listenfd);

    // 1. 建 epoll 实例
    int epfd = epoll_create1(0);
    if (epfd < 0) { perror("epoll_create1"); exit(1); }

    // 2. 把监听 fd 注册进去，只关心可读（有新连接）
    epoll_event ev{};
    ev.events = EPOLLIN;        // 不写 EPOLLET，默认 LT
    ev.data.fd = listenfd;
    if (epoll_ctl(epfd, EPOLL_CTL_ADD, listenfd, &ev) < 0) {
        perror("epoll_ctl add listenfd"); exit(1);
    }

    // 节 4 在这里继续
    return 0;
}
```

<br>

### 验收
编译通过。epoll_ctl 不返回 -1 即成功。

<br>

### 常见坑
epoll_event ev; 不写 {} → events/data 未初始化，随机行为。  

ev.data.fd = listenfd 写成 ev.data.ptr = &listenfd，然后回查时类型错。今天统一用 fd。

## 04 事件循环epoll_wait
***
### 最小必要理论
epoll_wait(epfd, events, maxevents, timeout)：阻塞等事件。  
返回 > 0：就绪事件个数。  
返回 0：超时（timeout 毫秒，-1 永久阻塞）。  
返回 -1 且 errno == EINTR：被信号打断，continue 重试，不是错误。  

返回后遍历 events[0..n-1]，events[i].data.fd 就是就绪的 fd。  

<br>

### 代码
main 里接在节 3 后：
```cpp
constexpr int MAX_EVENTS = 1024;
epoll_event events[MAX_EVENTS];

for (;;) {
    int n = epoll_wait(epfd, events, MAX_EVENTS, -1);
    if (n < 0) {
        if (errno == EINTR) continue;      // 被信号打断，重试
        perror("epoll_wait");
        break;
    }
    for (int i = 0; i < n; ++i) {
        int fd = events[i].data.fd;
        if (fd == listenfd) {
            // 节 5：新连接
        } else {
            // 节 6：连接可读
        }
    }
}
```

<br>

### 验收
能编译，程序挂在 epoll_wait 上不退出。nc 连上去看不到任何打印（因为还没写处理逻辑），但服务端不崩。这就是本节的验收：事件能进来，但你还不会处理。  

<br>

### 常见坑
epoll_wait 返回 -1 就 break，忽略 EINTR → Ctrl+C 一次、某些信号就让服务器退出。  

maxevents 传 0 → epoll_wait 直接返回 EINVAL。  

把 events 数组放在循环内，每次都重新分配 → 栈上 1024 个 epoll_event 反复构造，低效。放在循环外。  

<br>

<br>

## 05 监听 fd 可读 → accept 循环
***
### 最小必要理论
监听 fd 可读 = 至少有一个完成握手的连接在 accept 队列里。  

可能同时来了 N 个，必须循环 accept 直到 EAGAIN，否则连接排队，延迟高。  

accept4(..., SOCK_NONBLOCK)：一个调用同时 accept + 设非阻塞，比 accept + fcntl 少一次系统调用。  

新 connfd 要注册进 epoll，关注 EPOLLIN。  

<br>

### 代码
替换节 4 里的 // 节 5 注释：
```cpp
if (fd == listenfd) {
    // 监听 fd 可读：循环 accept 到 EAGAIN
    for (;;) {
        sockaddr_in cli{};
        socklen_t len = sizeof(cli);
        // accept4 直接带 SOCK_NONBLOCK，省一次 fcntl
        int connfd = accept4(listenfd, (sockaddr*)&cli, &len, SOCK_NONBLOCK);
        if (connfd < 0) {
            if (errno == EAGAIN || errno == EWOULDBLOCK) break;  // 取完了
            if (errno == EINTR) continue;                        // 被打断，重试
            perror("accept4");
            break;
        }
        printf("new conn fd=%d from %s:%d\n", connfd,
               inet_ntoa(cli.sin_addr), ntohs(cli.sin_port));

        // 把新连接注册进 epoll
        epoll_event cev{};
        cev.events = EPOLLIN;
        cev.data.fd = connfd;
        if (epoll_ctl(epfd, EPOLL_CTL_ADD, connfd, &cev) < 0) {
            perror("epoll_ctl add connfd");
            close(connfd);
        }
    }
}
```

<br>

### 验收
开三个终端，三个nc都能看到accept打印，echo还没有，正常
```bash
./build/echo_epoll_lt &
# 三个终端各开一个
nc 127.0.0.1 8888
# 服务端终端应打印 3 行 "new conn fd=... from 127.0.0.1:..."
```

<br>

### 常见坑
accept 不循环 → 一次 epoll_wait 只 accept 一个，其余排队。这就是你 docs/debug-log.md 今天该记的真实 bug。  

把 EAGAIN 当错误 break 并 close listenfd → 服务器直接挂。  

accept4 忘了 SOCK_NONBLOCK → connfd 是阻塞的，节 6 的 recv 循环会卡死。  

epoll_ctl ADD connfd 失败后忘 close(connfd) → fd 泄漏。  

<br>

## 06 连接 fd 可读 → recv 循环 + echo + 关闭
### 最小必要理论
连接 fd 可读 = 有数据可读 或 对端关闭。  

recv 返回值三种情况：  
如果 > 0：读到的字节数。  
== 0：对端关闭（四次挥手完成），你要清理。  
== -1：看 errno，EAGAIN 是读干净了正常退出，其他是错。  

必须循环读到 EAGAIN（LT 下虽然会再通知，但一次读干净减少上下文切换）。  

send 部分写：返回值可能小于请求字节，要循环累加。小数据 echo 一般一次发完，但契约上必须处理。  

recv 返回 0 或错误时，先 epoll_ctl DEL 再 close，顺序不能反。  

SIGPIPE：对端已关你还 send，内核发 SIGPIPE 默认杀进程。signal(SIGPIPE, SIG_IGN) 忽略，send 改返回 EPIPE。  

<br>

### 代码
在`main`之前插入两个函数：
```cpp
// 关闭连接：先从 epoll 摘掉，再 close，顺序不能反
static void close_conn(int epfd, int fd) {
    epoll_ctl(epfd, EPOLL_CTL_DEL, fd, nullptr);
    close(fd);
}

// 处理连接可读事件；返回 false 表示连接该关了
static bool handle_read(int epfd, int fd) {
    char buf[4096];
    for (;;) {
        ssize_t n = recv(fd, buf, sizeof(buf), 0);
        if (n > 0) {
            // echo：简化版直接 send，Day 8 用 Buffer + EPOLLOUT 重做
            ssize_t sent = 0;
            while (sent < n) {
                ssize_t w = send(fd, buf + sent, n - sent, 0);
                if (w < 0) {
                    if (errno == EINTR) continue;
                    if (errno == EAGAIN || errno == EWOULDBLOCK) {
                        // 发送缓冲满（小数据 echo 基本不会出现）
                        // 今天先丢剩余，Day 8 用输出缓冲解决
                        break;
                    }
                    return false;
                }
                sent += w;
            }
        } else if (n == 0) {
            return false;                       // 对端关闭
        } else {
            if (errno == EAGAIN || errno == EWOULDBLOCK) return true;  // 读干净
            if (errno == EINTR) continue;       // 被打断，重试
            return false;                       // 真错误
        }
    }
}
```

`main`开头加一行：
```cpp
signal(SIGPIPE, SIG_IGN);   // 对端关闭后 send 返回 EPIPE 而不是杀进程
```

`main`事件循环里替换节 4 的 // 节 6 注释：
```cpp
} else {
    if (!handle_read(epfd, fd)) {
        close_conn(epfd, fd);
    }
}
```

循环里 continue 用错层级 → 内层 send 循环的 continue 跑到外层 recv 循环。

### 09 完整文件
***
```cpp
// examples/echo_epoll_lt.cpp
// Day 2: 非阻塞 + epoll LT echo server

#include <sys/socket.h>
#include <sys/epoll.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <fcntl.h>
#include <unistd.h>
#include <signal.h>
#include <cerrno>
#include <cstdio>
#include <cstring>
#include <cstdlib>

static int set_nonblocking(int fd) {
    int flags = fcntl(fd, F_GETFL, 0);
    if (flags == -1) return -1;
    return fcntl(fd, F_SETFL, flags | O_NONBLOCK);
}

static int create_listenfd(int port) {
    int listenfd = socket(AF_INET, SOCK_STREAM, 0);
    if (listenfd < 0) { perror("socket"); exit(1); }
    int opt = 1;
    setsockopt(listenfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
    sockaddr_in addr{};
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = htonl(INADDR_ANY);
    addr.sin_port = htons(port);
    if (bind(listenfd, (sockaddr*)&addr, sizeof(addr)) < 0) {
        perror("bind"); exit(1);
    }
    if (listen(listenfd, SOMAXCONN) < 0) {
        perror("listen"); exit(1);
    }
    if (set_nonblocking(listenfd) < 0) {
        perror("set_nonblocking"); exit(1);
    }
    return listenfd;
}

static void close_conn(int epfd, int fd) {
    epoll_ctl(epfd, EPOLL_CTL_DEL, fd, nullptr);
    close(fd);
}

static bool handle_read(int epfd, int fd) {
    (void)epfd;
    char buf[4096];
    for (;;) {
        ssize_t n = recv(fd, buf, sizeof(buf), 0);
        if (n > 0) {
            ssize_t sent = 0;
            while (sent < n) {
                ssize_t w = send(fd, buf + sent, n - sent, 0);
                if (w < 0) {
                    if (errno == EINTR) continue;
                    if (errno == EAGAIN || errno == EWOULDBLOCK) break;
                    return false;
                }
                sent += w;
            }
        } else if (n == 0) {
            return false;
        } else {
            if (errno == EAGAIN || errno == EWOULDBLOCK) return true;
            if (errno == EINTR) continue;
            return false;
        }
    }
}

int main() {
    signal(SIGPIPE, SIG_IGN);

    int listenfd = create_listenfd(8888);
    printf("listen on 8888, listenfd=%d\n", listenfd);

    int epfd = epoll_create1(0);
    if (epfd < 0) { perror("epoll_create1"); exit(1); }

    epoll_event ev{};
    ev.events = EPOLLIN;
    ev.data.fd = listenfd;
    if (epoll_ctl(epfd, EPOLL_CTL_ADD, listenfd, &ev) < 0) {
        perror("epoll_ctl add listenfd"); exit(1);
    }

    constexpr int MAX_EVENTS = 1024;
    epoll_event events[MAX_EVENTS];
    for (;;) {
        int n = epoll_wait(epfd, events, MAX_EVENTS, -1);
        if (n < 0) {
            if (errno == EINTR) continue;
            perror("epoll_wait");
            break;
        }
        for (int i = 0; i < n; ++i) {
            int fd = events[i].data.fd;
            if (fd == listenfd) {
                for (;;) {
                    sockaddr_in cli{};
                    socklen_t len = sizeof(cli);
                    int connfd = accept4(listenfd, (sockaddr*)&cli, &len, SOCK_NONBLOCK);
                    if (connfd < 0) {
                        if (errno == EAGAIN || errno == EWOULDBLOCK) break;
                        if (errno == EINTR) continue;
                        perror("accept4");
                        break;
                    }
                    printf("new conn fd=%d from %s:%d\n", connfd,
                           inet_ntoa(cli.sin_addr), ntohs(cli.sin_port));
                    epoll_event cev{};
                    cev.events = EPOLLIN;
                    cev.data.fd = connfd;
                    if (epoll_ctl(epfd, EPOLL_CTL_ADD, connfd, &cev) < 0) {
                        perror("epoll_ctl add connfd");
                        close(connfd);
                    }
                }
            } else {
                if (!handle_read(epfd, fd)) {
                    close_conn(epfd, fd);
                }
            }
        }
    }
    close(epfd);
    close(listenfd);
    return 0;
}
```
