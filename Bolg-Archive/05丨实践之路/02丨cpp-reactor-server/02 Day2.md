## 01 创建监听 socket 并设非阻塞
***
### 最小必要理论
socket是什么？  
socket 可以理解成“网络通信的插口”。服务器先创建一个 socket，然后绑定地址和端口，开始监听，等客户端来连接。  

fd 是什么？  
fd 是 file descriptor，文件描述符。Linux 里 socket 也会被当成一种 fd。你可以把它理解成内核发给程序的一个编号，程序拿着这个编号说：“我要对这个连接读/写/关闭”。  

阻塞 / 非阻塞  
阻塞：你问内核“有新连接吗？”如果没有，程序就卡在那里等。  
非阻塞：你问一下，没有就立刻返回“现在没有”，程序可以先去干别的。  

系统调用  
程序请内核帮忙做事，叫系统调用。比如 socket()、bind()、listen()、accept4()、fcntl() 都是。  

事件循环  
事件循环就是一个循环：不断问内核“哪些 fd 现在有事情？有连接就 accept，有数据就读，能写就写”。非阻塞 + 事件循环是高性能服务器的常见骨架。  

**`SOCK_NONBLOCK` 可以在 `socket()` 时直接设非阻塞，比 `fcntl` 少一步。**  
创建 socket 常见写法：  
```c
int listen_fd = socket(AF_INET, SOCK_STREAM, 0);
```
`SOCK_STREAM` 表示 TCP。    
如果写成：  
```c
int listen_fd = socket(AF_INET, SOCK_STREAM | SOCK_NONBLOCK, 0);
```
就是在**创建这个 socket 的同时**把它设成非阻塞。  
以前常见做法是：  
```c
int fd = socket(AF_INET, SOCK_STREAM, 0);
fcntl(fd, F_SETFL, O_NONBLOCK);
```
先用 `socket()` 创建，再用 `fcntl()` 改属性。  
`SOCK_NONBLOCK` 的好处是：  
1. 少一次系统调用；
2. 创建出来就是非阻塞，不会出现“刚创建还是阻塞的，过一会儿才改”的中间状态；
3. 代码更直接。
**注意**：`SOCK_NONBLOCK` 是 Linux 常见扩展，不是所有系统都一样。  

**`SO_REUSEADDR` 让服务器重启时不必等 `TIME_WAIT`，调试期必加**
服务器绑定端口：
```c
bind(fd, ... 0.0.0.0:8888 ...);
```
如果你刚关掉服务器，马上重启，可能会遇到：
```text
Address already in use
```
原因之一是 TCP 连接关闭后，主动关闭方可能进入 `TIME_WAIT` 状态。你可以把它理解成：**电话挂断后，线路还要保留一小会儿，确认对方真的收到挂断，并让旧数据包消散。**
设置：
```c
int yes = 1;
setsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &yes, sizeof(yes));
```
作用是：允许重新绑定一个本地地址，即使它还有 `TIME_WAIT` 残留。调试服务器时经常加了再 `bind`，所以叫“调试期必加”。
但要准确理解：**它不是让 `TIME_WAIT` 消失，而是让 bind 更容易成功。** 生产环境要不要加、怎么加，要按场景来。

**监听 fd 非阻塞后，`accept4` 在没有新连接时返回 `-1 + EAGAIN`，不会卡住事件循环**  
`listen_fd` 是“监听 socket”，它不传数据，只负责接收新连接。  
有新客户端来时，用 `accept` 或 `accept4` 取出一个新连接，返回一个新的 fd，代表这条具体连接。  
如果监听 fd 是**阻塞**的，没有新连接时调用 `accept`，程序会卡住等。  
如果监听 fd 是**非阻塞**的，没有新连接时：  
```c
int conn_fd = accept4(listen_fd, ..., SOCK_NONBLOCK);
```
会返回：  
```text
-1
```
并且 `errno == EAGAIN` 或 `EWOULDBLOCK`。意思是：**现在没有新连接，稍后再来。这不是致命错误。**  
事件循环看到 `EAGAIN` 就继续处理别的 fd，不会被卡住。  
`accept4` 比 `accept` 多一个 `flags` 参数，可以顺便把新连接 fd 也设成非阻塞，比如传 `SOCK_NONBLOCK`。所以它常用于非阻塞服务器。  

**`bind` 绑定 `0.0.0.0:8888`，`listen` 的 backlog 先给 128**  
```c
bind(fd, 地址=0.0.0.0, 端口=8888);
listen(fd, 128);
```
`0.0.0.0` 表示：**本机所有 IPv4 网卡地址**。  
也就是说，客户端可以通过 `127.0.0.1:8888`、局域网 IP 的 8888 端口等连进来。  
如果你只绑 `127.0.0.1:8888`，那就只有本机能连。  
`listen(fd, 128)` 把 socket 从“主动 socket”变成“监听 socket”。  
`128` 是 `backlog`，可以粗略理解为：**内核给等待被 accept 的连接准备的排队区大小提示**。它不是“最多只能有 128 个连接”的硬上限，也不是总连接数上限。初学阶段先给 128 是常见起点。  



**一个最小非阻塞 TCP 服务器的骨架是：**  
```text
1. socket(..., SOCK_STREAM | SOCK_NONBLOCK, ...)  创建非阻塞 socket
2. setsockopt(..., SO_REUSEADDR, ...)             调试期允许地址复用
3. bind(..., 0.0.0.0:8888)                        绑定所有网卡的 8888 端口
4. listen(fd, 128)                                开始监听，backlog 128
5. 事件循环：
     如果 listen_fd 可读：
         accept4(listen_fd, ..., SOCK_NONBLOCK)
         如果返回 -1 且 errno 是 EAGAIN：现在没连接，继续循环
         否则得到 conn_fd，处理这条连接
```
